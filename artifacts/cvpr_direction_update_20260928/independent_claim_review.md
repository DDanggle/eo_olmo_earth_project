# 교정–관측 관계 보존 후보: 독립 비판 검토

2026-09-28. decision addendum용 설계 검토. 새 실험·성능 결과·선행 부재 증명·실행 승인이 아니다. 자동화와 학습은 중지 상태를 유지한다.

**판정: 연구할 만한 구체적 가설이지만, 아직 일반적인 관계/대조 학습을 넘어선 방법 기여는 확정되지 않았다.** P2는 5/6 완료·완료 5회 모두 기존 안정성 미충족이며, 두 완료 쌍 평균 +0.047228은 기술 통계다. text_mask_v2의 한 사례 검사는 optimizer update 0인 연결 검사다. 이 코드에서 Qwen은 텍스트만 읽고, 마지막 토큰 벡터를 EO/support 특징과 concat한 head가 mask를 출력한다. 실제 EO token을 읽는 VLM의 학습·생성 효과와 구분해야 한다.

**무엇이 중요할 수 있는가.** C=(양성 영역, 혼동 영역, 관측 가능한 차이, 날짜·품질·출처 참조)를 통해 단순 class 유사도가 아니라 “어떤 관측 아래에서 어떤 구별이 유효한가”를 학습하는 방향은 의미가 있다. 역할 교환에는 적절히 바뀌고, 의미 보존 재서술에는 유지되며, 충분한 근거가 사라지면 보류하는 서로 다른 반응을 하나의 OlmoEarth 표현에 학습하고 새 환경에서 재사용한다는 가설이다. 일반 contrastive는 같은 class의 모든 표현을 가깝게 만드는 과정에서 이런 조건별 차이를 놓칠 수 있다. 그러나 이 실패는 아직 가설이며 재현해야 한다. 최신 일반 episodic/domain meta-learning도 같은 감독을 받으면 해결할 수 있다.

**첫 반론은 ‘새 감독을 넣은 일반 학습’이다.** paired contrastive/relation objective라는 명칭, loss 항 개수, 날짜 token 보존 자체는 신규성 근거가 아니다. 날짜별 token, cross-attention head, VLM connector를 양팔에 동일하게 두고, 일반 SFT+hard negative+domain meta-learning에도 같은 C·개입 쌍·정답·근거·보류 라벨·튜닝 기회를 준다. 일반 CE로 각 개입의 정답을 학습한 조건과 표준 관계/metric loss도 포함한다. 제안군만 시간 token·관측 정답·추가 forward를 받으면 학습 규칙을 귀속할 수 없다. 동일 정보 노출과 실제 계산 비용의 비교를 각각 보고한다.

**개입의 정답 계약이 방법보다 먼저다.** (1) 대상/혼동 역할 교환은 두 대상의 위치 정답에 따른 변환이지 전체 mask의 단순 반전이 아니다. 둘 다 없는 곳은 계속 비대상이다. (2) 배경/환경 변화에 대한 불변성은 개념과 판독 가능성이 보존된 사례에만 적용한다. 계절·환경은 실제 대상 상태나 관측 가능성을 바꿀 수 있다. (3) 한 날짜를 제거해도 다른 날짜가 충분하면 보류를 강제하지 않는다. 필요한 근거 제거, 같은 수의 무관한 관측 제거, 근거가 남는 제거를 비교해 ‘결측이면 보류’라는 지름길을 차단한다. 연간 class mask로 시점별 생육·변화·판독 가능 정답을 만들지 않는다. 모호한 사례는 인간 합의나 독립 자료로 계약을 검증하고 보류한다.

**날짜 token의 중요한 함정.** 현재 native 출력은 공간×날짜 축을 유지한 뒤 mean(dim=(3,4))으로 축약된다. mean 전 token도 인코더 안에서 다른 날짜를 이미 참조했을 수 있다. 따라서 인코딩 뒤 한 날짜 token만 지우는 것은 원관측을 제거한 실험이 아니다. 실제 근거 제거는 해당 raw 관측을 제외/마스킹해 다시 인코딩하고, 원 인코딩 cache가 섞이지 않게 해야 한다. token의 날짜 인덱스와 attention weight만으로 그 날짜가 충분한 근거라고 판정하지 않는다.

**결정적 반증은 세 단계다.** 먼저 충분히 학습한 일반 대조가 같은 정보에서 틀리는 관계 전이 오류를 확인한다. 다음으로 EO 고정/갱신 × 일반/제안 학습을 비교하고, 주 비교는 갱신 EO의 제안 대 일반 학습으로 둔다. 마지막으로 기존 head·connector를 버린 encoder를 동일 예산의 새 head/reader와 독립 EO 평가에 옮긴다. 제안군이 일반 대조와 실용적으로 동등하면 새 학습 규칙 주장은 접는다. 효과가 원 head에만 남으면 encoder 재사용성 주장은 접는다. P2의 일반 B0≈B2만으로 미래의 특정 제안 학습까지 기각하지 않는다. 계산 상한 종료나 불안정한 학습은 동등성 증거가 아니다.

**큰 모델·분야 주장은 유지하되 직접 검증한다.** 하나의 checkpoint와 공통 교정 규칙이 농업·침수의 여러 미관찰 환경에서 작동해야 한다. source-support 재사용과 target-support 적응, 알려진 class의 새 지역과 실제 class-disjoint 전이를 분리한다. 분야별로 독립 재학습한 성공만으로 하나의 모델의 분야 전이를 주장하지 않는다. 비관련 개념 손상, 대상 부재 오탐, 잘못된 배경 설명의 피해, 겨울밀 같은 어려운 대상, 독립 EO 퇴행을 평균 뒤에 숨기지 않는다. 출처 ID는 정답을 암호화할 수 있으므로 가용 관측의 참조로만 쓰고 임의 ID 치환·새 문서/표현·class-disjoint 조건도 검사한다.

**VLM과 사람 예산.** 실제 EO token 경로를 가진 VLM을 text encoder+동일 head 및 specialist+측정 도구+동일 VLM과 비교한다. 같은 predicted mask/count/provenance를 주는 reader 비교에서 역할·시간·다중 영역 질의의 추가 이점을 보여야 VLM 고유 가치를 말할 수 있다. 인간 20개 timed pilot은 교정과 관측 판독의 합의·시간을 검증하는 데 먼저 쓰고, 공개 mask는 개발 규모를 담당하게 한다. 출처 설명은 사람 교정으로 세지 않는다. 지원 예시 작성·검색·재작업 비용과 재사용 횟수를 기록한다. +5%p 또는 같은 품질에서 교정 수 절반은 결과 전 검토할 실용 효과 목표의 예이며 CVPR 기준·예상 결과가 아니다. 지표·비교군·비용·불확실성·보존 조건을 test 전에 정해야 한다.
