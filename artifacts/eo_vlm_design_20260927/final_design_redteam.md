# Final design red-team — 2026-09-27

No fatal flaw in the proposed controlled program. Five conditions must be fixed before running a claim-bearing experiment:

1. **Establish what is new beyond episodic/prototypical learning.** Positive-minus-confusion similarity, an applicability gate, and episodic support conditioning are individually familiar. The 2×2 must include a strong learned generic router/prototype baseline receiving the same positive/negative supports and any utility labels. Predeclare the primary outcome as transfer of the corrected distinction to independent sites; architecture alone is not a discovery. A simple prototype residual may be the winning result and should not be weakened to favor the new system.

2. **Distinguish correction transfer from ordinary fixed-class supervision.** PASTIS annual crop labels can establish geographic crop discrimination, not arbitrary novel ecological concepts or observed seasonal change. Define an episode as a genuine pairwise confusion with fixed target semantics, held-out query parcels, and a specified support origin. Evaluate both same-environment and shifted-environment supports at equal K, and retain an explicit no-correction condition. Claim novel targets only after class/ontology/pretraining exposure audits. Kuro opened in September remains development data until a genuinely unexposed holdout exists; MADOS remains a stress test with preprocessing/domain caveats.

3. **Prevent hidden supervision and budget advantages.** Cross-fitting support-utility labels must exclude the query geography/year/parent—not merely exclude rows. Count labels used to estimate utility, candidate-pool screening, regional-context preparation, model selection, and replay exposure. Give the generic router the same auxiliary targets and hyperparameter-search budget. Keep the 1M KRW / 64 person-hour plan and 200/60/120 train/dev/test allocation as a budget proposal, not a confirmed achievable throughput. Report observed annotation speed before claiming label-efficiency gains.

4. **Make branch attribution testable.** A dense head can solve the task while the VLM merely verbalizes its output; regional text can supply a class prior without using evidence. Measure mask/area or task accuracy separately from explanations. Freeze or replay the same dense-head outputs into both readers, add encoder-only/prototype performance, and test contradictory/shuffled support and context. Any counterfactual must respect image semantics. Persistent independent encoder improvement requires a fixed external EO evaluation protocol, not improvement on another head trained on the same episodes.

5. **Do not let the 2×2 inherit an artificial bottleneck.** Fixed 128→16 averaging is a useful engineering baseline and the CPU operator audit can prove a nullspace for fixed inputs. It does not prove learned EO representations must lose useful information. Include spatial/time-aware equal-token pooling, an ordinary learned resampler, and a larger-token simple baseline. Match or report trainable parameters, input observations, FLOPs/GPU time, token count and tuning budget; equal K alone is not equal compute. A geometry fix that wins only against flattened averaging supports repairing the interface, not a broad new EO learning principle.

**Go condition:** engineering/data validation can proceed now. A scientific transfer claim requires preregistered independent geography/year units and an equal-information generic episodic baseline; no current gradient or CPU operator result meets that condition.
