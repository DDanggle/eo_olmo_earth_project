# EO + VLM architecture prior-art audit — 2026-09-27

Read-only web audit of primary papers and author repositories. This is a bounded search, not proof that an idea has never appeared. The current GPU1 gradient PASS establishes trainability only, not a new scientific result.

## A defensible research direction (hypothesis, not proven gap)

Test whether task-specific positive and contrastive expert examples teach a native spectral-temporal EO model an object/state distinction that transfers across environments, while a VLM can localize and explain that distinction. Regional context should help select relevant observations/examples, while evidence in the image remains decisive.

Candidate mechanism: retain a dense location × observation-time feature path; encode positive and confusing-negative support regions through the same OlmoEarth encoder; condition a compact observation selector on these supports and the question; predict dense mask/measurement from spatial features; let the VLM read the selected evidence and emit structured references plus an explanation. Keep dates, sensor identity, validity masks and coordinates attached throughout. Start with linear alignment versus this minimal support-conditioned variant before adding multi-depth coupling.

The novelty would need a concrete finding: generic alignment loses a recoverable distinction; the proposed learning objective/architecture preserves it and reduces the number of expert corrections required on genuinely held-out regions. Architecture diagrams and extra modalities alone will not establish it.

## Strong comparisons and failure controls

1. Frozen original OlmoEarth + dense supervised/prototype head; proves whether the information is already accessible without a VLM.
2. Same OlmoEarth + same VLM + same images/text/supports/steps using ordinary joint supervised training. This is the decisive equal-information baseline.
3. Spectral/time-preserving token path versus equal-token pooled/linear path; include a larger-budget simple baseline to rule out token count as the cause.
4. RGB render and pseudo-RGB band groups using the same underlying observations; FarSLIP/AlignJEPA-style alignment and distillation comparators, SPEX/TerraScope-style heads for dense grounding, SkySense-VITA if its assets become available.
5. Correct versus shuffled regional text; positive versus confusing-negative/corrupted supports; valid date ordering versus permutation; only physically appropriate masking. Use predictive disagreement under these changes as evidence sensitivity, not language-fluency scores.
6. Split by independent geographic parent/site and year before episode creation; no near-neighbor supports; charge candidate search + labeling + verification time, not just the final support count.
7. Encoder-only held-out EO evaluation and a second reader after training; this distinguishes improving OlmoEarth from teaching one decoder a dataset.

No “first EO→VLM”, “first multispectral VLM”, “first support-conditioned EO segmentation”, or “first Wikipedia-supervised EO” claim is supported. A controlled demonstration of correction-efficient transfer with physically grounded evidence remains a worthwhile hypothesis, subject to direct comparison with these methods.
