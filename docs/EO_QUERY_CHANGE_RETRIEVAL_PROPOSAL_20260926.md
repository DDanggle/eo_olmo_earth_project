# 언어·예시 영상으로 식생 변화 사례를 찾는 EO–VLM 학습 제안

> **구체적인 실험 순서와 CVPR 범위는 [9/26 실험 계획](OLMOEARTH_VLM_EXPERIMENT_PLAN_20260926.md)을 따른다.** 아래는 방향이 구체화된 이력이며 새 학습 결과가 아니다.

## 0. 사용자 정정 — 주 연구 대상은 EO encoder 사전학습

**이후 사용자는 “OlmoEarth 등의 embedding을 처음 사전학습할 때부터 잘 만들고 싶다”고 취지를 바로잡았다.** 앞선 답은 사전학습된 EO encoder를 고정하고 후단 검색 모듈을 학습하는 방향으로 좁혀 해석했다. 아직 어느 모델에도 구현·학습해 사용하지 않은 제안이다. 아래 1–7절은 그 이전의 후단 검색안 및 재사용할 평가 아이디어로 보존하며, encoder 고정 권고를 수정된 주 연구 방향으로 취급하지 않는다.

수정된 연구 질문은 **“EO encoder 사전학습에 언어·공간·시간 변화 감독을 넣으면, 생성되는 표현 자체가 여러 지역의 검색과 VLM 근거 판독에 더 잘 전이되는가?”**다. 검색과 설명은 임베딩의 평가·활용 과제가 된다.

- 기존 E0–E5의 임베딩 판독 실험과 별개로 EO encoder의 가중치를 업데이트한다. 저장된 embedding 파일만 읽는 학습으로는 그 파일을 만든 encoder까지 역전파할 수 없다. 원 관측에서 encoder forward를 계산하거나 적절한 재계산 경로를 마련해야 한다.
- 원래의 EO 학습 목적을 보존하면서 (a) 관측/변화와 검증된 설명의 의미 정렬, (b) 시간 방향·지속/회복 관계, (c) 문장 속 현상과 실제 영역의 대응 목적을 단계별로 추가하는 것이 가설이다. 모든 항을 한꺼번에 넣고 효과 원인을 추정하지 않는다. 해당 정답이 없는 자료에는 목적을 억지로 적용하지 않는다.
- 공식 로컬 v1 config의 patch discrimination과 InfoNCE(.1)는 이미 존재한다. train module의 InfoNCE는 pooled_a/pooled_b 영상 view 사이에서 계산된다. “대조 학습을 처음 도입”하는 기여가 아니라 추가 정렬의 대상·시공간 정보 보존·encoder 업데이트 효과를 검증해야 한다. 버전별 설정을 고정하며 v1과 최신 배포를 혼합하지 않는다.
- 사용자의 ‘처음부터’를 직접 검증하는 소규모 설계는 Nano/Tiny를 같은 랜덤 초기 상태에서 원 사전학습 목적 / 언어 정렬 추가 / 검증된 변화·공간 목적 추가로 비교하는 것이다. 원 관측·문항 노출·업데이트와 별도 계산량을 기록한다. 기존 가중치부터 시작하는 계속 사전학습은 별도의 저비용 가설 검증 경로이며, 처음부터 사전학습한 결과라고 부르지 않는다.
- 사전학습 후 encoder를 고정하고 검색, 공간 근거, VLM 판독, 기본 EO 과제의 보존을 각각 평가한다. VLM 비교에서는 같은 frozen LLM과 같은 구조·초기화·학습 예산의 새 projector를 encoder별로 사용한다. 서로 다른 표현 좌표계에 동일한 기존 projector 가중치를 강제로 붙여 생긴 실패를 표현의 열등함으로 해석하지 않는다. 기존 frozen encoder+검색 정렬은 후단 학습만으로 설명되는 이점을 가르는 대조군이다.
- 기존 loss를 유지해도 원 EO 정보 보존은 자동 보장되지 않는다. 특히 모든 시점의 같은 장소를 무조건 양성으로 묶으면 실제 변화도 지울 수 있다. 변화가 검수된 부분과 유지된 부분의 감독을 구별하고, 자연어 없는 EO 전이 과제도 함께 확인한다. 미확인 원인·고사·영향은 사전학습 caption의 정답으로 만들어 넣지 않는다.

직접 관련 선행연구는 [RemoteCLIP](https://arxiv.org/abs/2306.11029)의 EO 영상–언어 정렬, [GeoMeld-FM](https://arxiv.org/abs/2604.10591)의 masked/JEPA/언어 정렬 공동 사전학습이다. GeoMeld는 논문 메타데이터상 CVPR 2026 workshop 논문이며 본회의로 부르지 않는다. 따라서 “사전학습에 텍스트 추가”만의 신규성은 주장하지 않는다. 위성의 공간·시간 변화 정보와 자연어 의미를 함께 보존하는 구체적 목적 및 전이 효과가 검증 대상이다.

2026-09-26. **연구 방향·첫 실험 설계 초안이며, 실행 완료 결과나 동결된 사전등록이 아니다.** 기존 E0–E5 판정은 유지한다. E6 전송 승인을 받은 것으로 해석하지 않으며 이번 검토에서 새 서버 전송·학습은 하지 않았다.

현재 지지되는 것은 EO 입력에 대한 응답 의존성과 기존 이진 참조 라벨의 학습 가능성이다. 자유로운 검색·공간 근거·시간 변화 이해·고사 원인·기억의 효과는 미검증이다. 특히 EO embedding과 일반 텍스트 embedding이 학습 없이 같은 좌표계를 쓴다는 근거가 없다.

### 0.1. OlmoEarth 중심 범위와 사용자별 VLM 미세조정·배포

사용자는 여러 EO backbone 확장을 필수로 두지 않고 **OlmoEarth 자체의 사전학습 개선**에 집중해도 된다고 명확히 했다. 이어서 그 위에 VLM 기능을 마련하고, 사용자가 지역/현상에 맞게 쉽게 미세조정하여 모델을 올리는 흐름을 제안했다. 여기서 '올리기'는 우선 재사용 가능한 모델 묶음의 저장·공유·서비스 배포로 해석하며, 실제 목적지나 게시를 승인받은 것으로 해석하지 않는다.

2026-09-26 공식 문서 확인:

- [OlmoEarth Studio](https://docs.olmoearth.allenai.org/)는 이미 라벨 입력·미세조정·배포·출력 시각화/내보내기를 제공한다. 쉬운 미세조정/배포 자체를 새로운 기여라고 하지 않는다.
- [공식 기본 태스크](https://docs.olmoearth.allenai.org/config-reference/model/)는 분류·탐지·embedding·회귀·분할 등을 열거한다. 기본 태스크 목록에는 자연어 QA/대화가 없다. 이는 모든 외부 VLM 확장이 부재한다는 전수조사 결과는 아니다.
- [공식 모델 자료](https://github.com/allenai/olmoearth_pretrain)는 Sentinel-1/2·Landsat 및 파생 지도 6종을 학습에 사용했다고 설명한다. '위성 영상만으로 학습'으로 축약하지 않는다.

설계는 공통 단계와 사용자 단계를 나눈다.

1. **공통 표현 학습:** 언어·변화·공간 감독이 OlmoEarth encoder까지 전달되는 사전학습을 비교한다. 이전의 frozen encoder+후단 모듈은 비교 조건이다.
2. **공통 VLM 연결:** 공간·시점 토큰과 질문을 reader에 연결하고, 답변에 해당 위치/관측 구간/근거ID/미확인 사항을 연결하도록 학습·평가한다. 마스크 결과를 문장 템플릿에 넣는 기준선과 직접 EO 근거를 읽는 reader를 구별한다.
3. **사용자별 적응:** 위치·날짜·대상 라벨/영역·설명 또는 질문답 쌍을 가져와, 검증된 학습 recipe로 작은 adapter/LoRA 또는 필요한 encoder 부분을 학습하도록 설계한다. 설명 정답이 없는 클래스 라벨만으로 자유로운 설명의 정답까지 확보했다고 간주하지 않는다. 적은 라벨에서의 성능과 사용자 학습 비용은 실험으로 측정한다.
4. **저장·공유·서비스:** base model revision, 수정 가중치/adapter, 센서별 전처리·날짜·토큰 계약, tokenizer/질문 형식, 평가 기록을 묶어 동일 예측을 재현하는 loader/API를 설계한다. 공식 Studio가 임의의 새 VLM artifact를 그대로 호스팅할 수 있는지는 이번 확인 범위 밖이며, 구체적 배포 경로는 실제 지원 계약 확인 후 정한다.

연구 기여의 초점은 **제안 사전학습이 사용자별 VLM 적응에 필요한 감독·계산 비용을 줄이면서 공간·시간 근거 정확도를 높이는가**다. 시스템의 편리함은 이 효과를 전달하는 산출물이며, UI 구현만으로 가설을 검증하지 않는다. 주 실험은 OlmoEarth로 한정할 수 있고, 다른 VLM은 필요할 때 보조 전이 검증으로 둔다. 다른 EO backbone 전면 확장은 필수 범위가 아니다.

목표 사용자 흐름: 지역/기간과 관심 현상 지정 → 예시·참조 라벨 등록 → 미세조정·새 지역 검증 → 후보 지도/전후 근거/설명 확인 → 모델 묶음 저장 또는 정해진 환경에 배포. 이는 제안된 기능이며 현재 화면은 기존 실험의 저장 결과 조회 수준이다. 이번 작업에서 새로운 VLM 학습·원격 업로드·공개 게시·배포는 수행하지 않았다.

## 1. 권고하는 문제 정의

**“문장 또는 예시 영상을 주면, 관측된 변화가 질의 조건에 맞는 지역을 찾아 전후 영상·위치·관측 구간을 근거로 설명할 수 있는가?”**

첫 대상은 식생 피복 감소/증가·회복 후보 검색이다. 식생 클래스가 다른 클래스로 전환됐다는 것과 개별 나무의 고사, 생리적 스트레스, 가뭄·병해충 원인은 별개 정답이다. 검증되지 않은 원인·영향을 생성 문장으로 보충하지 않는다. 여기서 '회복'도 참조 피복의 재증가가 관측된 범위로 정의하고 생태 기능 회복을 뜻하지 않는다.

사용 예시(모델 결과가 아닌 목표 인터페이스):

- 예시 위성 영상 + “비슷한 식생 배경에서, 식생 피복이 줄어든 후보를 찾아줘.”
- 같은 예시 + “이번에는 줄었다가 다시 증가한 후보를 찾아줘.”
- 등록된 전후 영상 + “어디가 어떻게 달라졌는지, 확인할 수 없는 부분도 표시해줘.”

첫째는 배경 조건과 변화 조건이 있는 검색이다. 둘째는 더 긴 관측열이 필요하다. 셋째는 관측 근거를 읽는 질문이다. 사진 한 장만으로 그 지역의 과거 변화를 확인할 수 없으며, 같은 위치의 과거 영상이 있으면 추가로 조회하고 없으면 상태/유사 사례 검색으로 제한한다. 일반 지상 사진→위성 사진 검색은 별도의 시점·센서 간 정렬 과제이므로 첫 실험에는 섞지 않는다.

## 2. 학습 구조와 각 단계의 책임

`질의(문장/예시) → 검색용 정렬 → 후보 지역·관측열 → VLM의 근거 판독 → 설명·미확인 사항`

1. **검색 정렬:** EO encoder는 먼저 고정하고 공간·시점 특징을 보존한다. 작은 학습 모듈로 EO 특징과 질의를 공통 검색 공간에 옮긴다. 문장, 단일 예시 영상, 전후 예시 쌍은 다른 입력 유형으로 기록하고 성능도 따로 낸다. 전체 영상의 평균 벡터 한 개가 충분한지는 기준선으로 확인한다.
2. **대조 학습:** 질의에 맞는 사례들과 질의를 가깝게, 맞지 않는 사례들을 멀게 배치한다. 여러 지역이 동일한 질의의 정답일 수 있으므로 다른 항목을 무조건 음성으로 취급하지 않는다. 정답은 단순 파일ID 일치가 아니라 변화 방향·영역·배경 조건의 충족이다.
3. **근거 판독:** VLM에는 실제 후보의 전후 영상/EO 공간 토큰, 올바른 날짜·센서 정보, 출처를 준다. 검색 점수는 보정된 확률이나 고사 확신도로 표시하지 않는다. 검색용 벡터가 언어모델 토큰으로 자동 변환되는 것은 아니므로 기존 projector 또는 별도 연결 모듈의 학습/고정 상태를 명시한다.
4. **설명 학습(후속 비교):** 검수된 변화 영역·방향·관측 구간과 미확인 사항을 답하도록 학습한다. 직접 설명 학습만 한 조건과, 검색 정렬을 추가한 조건을 같은 감독·노출 예산에서 비교한다. “SFT가 먼저 필요하다”는 기존 철회 결론을 되살리지 않는다. 검색 정렬의 추가 이점 자체가 검증할 가설이다.

방법 후보는 배경 유사도와 변화 유사도를 분리한 두 표현에 질의 조건을 적용하는 구조다. 예컨대 “비슷한 숲”을 요구하면 배경 조건도 점수에 반영하고, “배경과 관계없이 같은 감소”라면 변화 일치를 우선한다. 구조의 신규성이나 효능은 아직 주장하지 않는다. 동일한 복잡도의 일반 결합 표현과 비교해야 한다.

## 3. 첫 학습 자료에서 반드시 구분할 사례

| 예시 질의: 비슷한 식생 배경에서 피복 감소 | 감독 역할 |
|---|---|
| 비슷한 배경·검증된 피복 감소 | 양성 |
| 비슷한 배경·계절 색 변화만 있고 참조 피복은 유지 | 어려운 음성 후보. 별도 검수 필요 |
| 비슷한 배경·피복 증가 | 변화 방향이 반대인 음성 |
| 다른 배경·같은 감소 | 변화만 요청한 질의에는 양성, 배경 제약 질의에는 관련도를 별도 판정 |
| 구름/그림자/정합 실패로 가려진 영상 | 미확인·판독 불가. 안정 상태 음성으로 만들지 않음 |

“색이 바뀌었으므로 식생 감소”, “피복 라벨이 유지되므로 모든 생태 변화 없음”이라는 자동 정답 생성은 금지한다. 라벨 전환은 가능한 감독의 범위이며, 원인·건강 상태의 정답은 아니다. 예시와 후보가 같은 원영상의 겹치는 crop이면 의미 검색 성공으로 세지 않는다.

## 4. 데이터 후보와 선택 이유

| 우선순위 | 후보 | 이번 제안에 쓸 수 있는 점 | 채택 전 확인할 점 |
|---|---|---|---|
| 1 | DynamicEarthNet | 75개 지역의 일별 다중분광 영상과 월별 피복 라벨. 변화와 안정 사례를 시간순으로 구성할 후보 | 입력 센서/밴드·라이선스·실제 원자료 접근·날짜·정합. 월별 라벨 사이 정확한 변화일은 정답 아님 |
| 2 | deadtrees.earth-aerial | 고해상도 항공 영상의 수관·고사 영역 정답으로 고사 후보 검색을 별도 검증할 후보 | 논문은 2.5–20cm급 자료를 설명. 현재 배포 범위·접근·권리와 시계열 유무는 미확정. 위성 embedding에 그대로 넣는 것으로 대체하지 않음 |
| 3 | MARIDA | Sentinel-2 해양 쓰레기와 해조류·거품·자연 부유물 등을 구분하는 검색 | 혼동·공간 해상도·희소한 정답. 한 시점의 탐지 라벨만으로 축적 증가/이동/원인을 검증할 수 없음 |

DynamicEarthNet의 주 영상과 현재 EO encoder의 센서 계약을 먼저 확인한다. 논문은 같은 지역의 월별 Sentinel-2도 기술하지만, 이 경로의 제공 상태와 날짜 대응은 아직 파일로 확인하지 않았다. 고해상도 라벨을 저해상도 격자에 옮기면 혼합 픽셀 비율과 정합 오차를 보존해야 한다. Planet/RGB 값을 Sentinel-2 밴드로 이름만 바꾸어 넣지 않는다. 필요한 경우 실제 지원 센서 자료와의 연결 또는 해당 센서에 맞는 별도 encoder를 명시적 비교 대상으로 둔다.

권고 근거는 식생 피복 변화가 사용자의 목표와 시계열 평가를 연결하기 쉽다는 연구 판단이다. 해당 자료의 성능이나 실제 이용 가능성을 이번에 재현한 것은 아니다.

## 5. 첫 실험 R0 초안 — 검색 정렬의 효과부터 측정

**가설:** 변화 의미에 맞춘 감독을 추가하면, 같은 배경이지만 변화가 다른 후보를 걸러내면서 미사용 지역의 관련 사례 검색이 개선된다.

먼저 개발 영역의 소규모 사례로 날짜·센서·라벨·품질 계약과 사람이 평가할 수 있는 관련도를 감사한다. 지역 수·훈련/평가 크기·GPU 시간은 실제 자료 접근과 양성 분포를 확인한 후, 평가 결과를 보기 전에 고정한다. 여기서는 규모나 성공 수치를 확정 사전등록처럼 제시하지 않는다.

비교는 두 묶음으로 나눈다.

- **영상 예시 검색:** 고정 EO 특징의 근접 검색 → 두 시점 결합/차이 특징 검색 → 같은 훈련 자료를 사용한 질의 조건부 정렬. 단일 시점·날짜/지역 정보만 사용하는 기준선도 포함한다.
- **언어 검색:** 지원 센서에서 사용할 수 있는 기존 영상–언어 모델 → 통상적인 대조 정렬 → 배경·반대 방향·계절 유사 사례를 포함한 정렬. 미정렬 EO와 텍스트 벡터의 cosine을 유효한 언어 기준선으로 놓지 않는다. 공통 모델 비교는 데이터·노출·용량 차이를 보고한다.

지원 밴드가 있으면 NDVI 등 식생 지표의 계절 대비 변화로 검색하는 간단한 기준선을 포함한다. 계절 기준·정규화는 훈련/개발 기간에서만 정하고 평가 이후 관측을 쓰지 않는다. 해당 지표로 학습 감독을 만들더라도 동일 지표를 독립 평가 정답처럼 쓰지 않는다. 가능하면 RSICRC의 두 시점 검색·설명 방법을 데이터/센서 조건에 맞춰 비교한다. RGB 기반 방법을 다중분광 방법과 비교할 때 제공 정보량의 차이를 숨기지 않는다.

평가는 관련도 정답을 충분히 확인한 작은 고정 후보군에서 시작한다. 복수의 정답을 인정하고 미판정 후보를 자동 음성으로 만들지 않는다. 주지표 후보는 지역별 동일 가중 mAP, 사용성 지표는 Precision@5/Recall@5다. 최종 주지표·허용 효과 폭·중단 기준·표본 크기는 개발 자료 감사 뒤 평가 실행 전에 동결한다. 검색 노출이 없는 지역/AOI·원영상·사건 단위로 분리하고 겹치는 crop과 예시 자체를 제외한다. 같은 지역의 모든 시점을 한 split에 두고, 다른 해 일반화는 별도 시간 분할 실험으로 취급한다. AOI/사건 단위 paired bootstrap 구간을 쓰며 여러 crop·질의·seed를 독립 지역 수로 세지 않는다.

핵심 통제:

1. **질의 조건 변경:** 같은 예시에서 감소/증가/피복 유지 등 의미를 바꾸었을 때, 검수한 관련도에 맞춰 순위가 바뀌는지 본다. 단순 지명 검색이나 식생 분류로 충분한지 비교한다.
2. **시점의 역할:** 각 시점만 사용한 모델과 두 시점을 처음부터 사용한 모델을 같은 학습 예산에서 비교한다. E5처럼 사후 입력 제거 실패만으로 정보의 필요성을 주장하지 않는다. 역순 제시는 명시적인 순서 변환 과제로 기록하고, 불가능한 날짜–영상 조합을 자연 관측으로 취급하지 않는다.
3. **계절·센서 통제:** 같은 계절의 실제 피복 변화, 다른 계절의 피복 유지, 반대 방향 변화의 성능을 각각 보고한다. 구름·수확·해상도·촬영 조건의 차이가 정답을 대신하지 않는지 검수한다. 지속적 감소나 감소 후 회복을 묻는다면 후속 유효 관측을 추가해 해당 이력을 검수한다. 후속 관측을 정답 검수에 사용한 사실과 질의 시점에 모델이 이용 가능한 정보를 구분해 미래 정보 유출을 막는다.
4. **공간 근거와 unknown:** 후속 reader는 영역/방향/관측 구간의 정답과 독립 판독으로 평가한다. attention 그림만으로 위치 이해를 주장하지 않는다. 판독 불가 사례의 오답·기권을 따로 측정하며 기권 임계값은 개발 자료에서 고정한다.
5. **검색과 reader 분리:** 실제 검색 결과, 임의 후보, 정답 후보를 제공한 조건을 구분한다. 검색된 문장을 그대로 읽는 기준선과 EO 근거를 직접 읽는 조건을 비교한다. 영상/embedding 교체 때 donor 정답으로 채점하되 고정 텍스트와 충돌하면 unknown을 허용하는 명시적 과제로 설계한다. 전체 임베딩 교체만으로 특정 속성의 인과 이해를 입증하지 않는다.

검색 성능만 좋아지면 검색 모듈의 개선으로 보고한다. 위치·방향·미확인 사항까지 원 근거에 따라 맞아야 근거 기반 설명의 개선을 주장한다. 개선이 없어도 원인을 보존하며 결과가 나올 때까지 분할·정답·기준을 반복 변경하지 않는다.

## 6. CVPR 관점과 기존 연구 연결

RSICRC는 이미 두 시점 대조 학습과 검색·설명을 결합했다. RSRCC는 위치를 특정한 변화 질문과 검색을 활용하는 데이터 정제 과정을 제시했다. 그러므로 “EO embedding + LLM + 검색” 또는 “검색과 설명을 같이 학습”만으로 신규성을 주장하지 않는다. RSRCC의 검색은 주로 데이터 구축 절차이며, 이를 사용자용 시계열 검색 시스템으로 동일시하지 않는다.

검증할 기여 후보는 **배경·계절 유사도와 질의의 변화 의미가 어긋날 때에도, 새 지역에서 관련 변화를 찾고 실제 공간·시간 근거를 제시하는 정렬 방법**이다. 기존 결합 정렬·소형 모델·직접 설명 학습보다 나은 근거와 재현 가능한 통제가 필요하다. 아직 최초성·채택 가능성·방법 우월성은 확인하지 않았다.

기존 E0–E5는 새 방법의 성능표가 아니라 입력 의존성 통제 설계의 출발점이다. E5의 D 제거 붕괴와 pair 재학습 회복은 새 연구에서도 제거 실험과 동일 예산 재학습을 함께 봐야 하는 이유다. 기존 이진 과제용 E6는 보조 진단으로 보존하되, 식생 검색을 위한 유일한 기준선이나 기여 검증을 대체하지 않는다. 이번 사용자 제안은 E6의 전송 승인 응답이 아니다.

검색·판독이 검증되면 기존 memory 질문과 다시 연결할 수 있다. 동일한 byte/토큰·조회 예산에서 무작위 저장·최신 관측 저장·일반 유사도 저장·변화 사건 저장을 비교하고, 과거 사건 회수와 근거 보존·unknown을 측정한다. 지금 검색 효과를 기억 기여로 바꾸어 부르지 않는다.

## 7. 확인한 1차 출처와 현재 산출물

- [DynamicEarthNet, CVPR 2022](https://arxiv.org/abs/2203.12560) · [논문 PDF](https://openaccess.thecvf.com/content/CVPR2022/papers/Toker_DynamicEarthNet_Daily_Multi-Spectral_Satellite_Dataset_for_Semantic_Change_Segmentation_CVPR_2022_paper.pdf) · [저자 코드](https://github.com/aysim/dynnet): 시계열·피복 라벨 후보. 자료 전체를 내려받아 검증하지 않았다.

- [MARIDA 원 논문, PLOS ONE 2022](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0262247): 해양 쓰레기와 혼동 현상의 다중분광 자료. 누적량·원인의 시계열 정답으로 간주하지 않는다.
- [기존 E5 결과](E5_EQUAL_BUDGET_RESULTS_20260925.md) · [현재 주장 범위](EO_READER_CLAIM_CHAIN_20260925.md).
