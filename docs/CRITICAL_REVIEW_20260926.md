# 비판적 검토 — 9/26 시점에서 무엇이 확인됐고 무엇에 걸어야 하나

2026-09-26. 사용자 요청: "뛰어나지만 나를 아끼는 비판적인 교수"의 관점. 근거는 이 저장소의 측정(MS-156·157, 9/25–26
다른 세션의 E2 감사·C0·C1·E3–E5·T0)과 사용자가 붙여 준 외부 조언. 외부 조언 속 사실 주장 중 이번에 직접 확인하지 않은 것은
**미확인**으로 표시한다(L6).

## 1. 지금 확인된 것과 아닌 것

| 주장 | 상태 | 근거 |
|---|---|---|
| frozen OlmoEarth 임베딩 + projector + LLM reader가 **임베딩 내용을 써서** 답한다 | **확인** (홍수·산사태 유무) | MS-156 교환 통제, MS-157 blind 대비, C1 같은 문구·날짜에서 .8035 vs .5000 (사건 CI [.18, .41]) |

| 프롬프트에 적힌 **날짜**와 맞는 관측을 읽는다 | **아니다** | T0: 홍수 날짜는 −12/−24일 가정. 실제 원 날짜와 둘 다 맞는 쌍 26/902 |

한 줄로: **"읽는다"는 섰고, "무엇을 읽는가(변화·날짜·현상)"는 서지 않았다.** 이건 실패가 아니라 정직한 현 위치다.

## 2. 붙여 준 외부 조언에 대한 평가

**맞는 것 — 그대로 가져간다**
- EO-VLM이 없다는 전제는 틀렸다(EarthDial 등). 신규성은 "연결했다"에서 나올 수 없다.
- 비교 설계의 핵심은 **3번(같은 영역·면적 정답을 일반 보조과제로 학습)**이다. 이게 없으면 "라벨을 더 봤다"와 "새 학습법"을 못 가른다.
- 면적 질문에 **분할 모델 + 계산 + 문장** 기준선을 넣어야 한다는 것. 정직한 설계다.
- 언어를 붙인 뒤 원래 EO 성능(GEO-Bench-2)이 유지되는지 보는 것.

**동의하지 않거나 조건이 필요한 것**
1. **"사전학습을 바꾼다"는 말의 크기.** 1–2장의 공유 H200으로 7주 안에 할 수 있는 것은 사전학습 재수행이 아니라
   **인코더 적응(continued training/fine-tuning, 예: OE1의 Tiny 인코더 갱신)**이다. 논문에서도 그렇게 불러야 한다.
   이름이 과장되면 심사에서 가장 먼저 무너진다.
2. **4번 "우리가 설계한 사전학습"이 아직 정의되지 않았다.** 왜 3번보다 나아야 하는지에 대한 가설(메커니즘)이 없으면,
   가장 가능성 높은 결과는 3번 ≈ 4번이다. 방법을 먼저 한 문장으로 적을 수 있어야 한다.
3. **BigEarthNet.txt의 지름길.** 이 저장소가 직접 잰 값: 국가·계절·기후 객관식 1,390,573개(객관식의 42.7%)가
   메타데이터 필드 조회만으로 100% 풀린다. 이 데이터로 주장하려면 시각 문항만 따로, 같은 예산의 blind 기준선과 함께 보고해야 한다.
   면적 정답은 참조 지도(단일 시점)에서 왔으므로 "면적을 잘 말한다" ≈ "분할을 잘 한다"일 가능성이 높고, 분할+계산 기준선이 이길 수 있다.
4. **범위.** 벤치마크 4개 × 비교 4종 × 외부 모델 × 인코더 학습은 7주에 불가능하다. 하나를 고르고 나머지는 한계로 적는다.
5. **미확인 사실**(이번에 직접 확인 안 함): EarthDial-4B-MS 가중치 공개 여부, BigEarthNet.txt 수동 검수 평가 분할,
   ERA5가 공개 데이터엔 있고 v1–v1.2 학습 설정엔 없다는 것. 쓰기 전에 원문으로 확인한다.

## 3. 교수로서 가장 하고 싶은 말

**방향이 5일 동안 네 번 바뀌었다**(기억 병목 → D1 판독 → 임베딩 reader → 인코더 사전학습). 매번 이유는 있었지만,
바뀔 때마다 앞 단계의 증거가 다음 주장을 떠받치지 못하고 새로 시작한다. 지금 필요한 건 새 아이디어가 아니라
**2주짜리 한 가지 베팅과 그 베팅을 끝낼 기준**이다.

그리고 이미 손에 쥔 가장 값싼 결정 실험이 있다: **E6(LLM 없는 367,361 파라미터 head가 E5 full을 따라잡는가).**
준비는 끝났고 서버 전송 승인만 기다린다. 이 결과가 "VLM이 무엇을 더하나"라는 질문 전체의 바닥을 정한다.
작은 head가 같은 점수를 내면, 지금 과제에서 LLM은 판독기에 말투를 붙인 것에 가깝고, 인코더를 언어용으로 바꾸자는
계획은 **다른 과제(공간·면적·다중 질의)**에서 동기를 찾아야 한다.

## 4. (a) 산사태 안정화, (b) 세 번째 현상 — 원래 계획의 재평가

- **(a)** 산사태 시험은 사실상 hiroshima 1지역(186 타일)이다. 균형 샘플링으로 seed 분산을 줄여도 "한 지역에서 안정"이
  될 뿐이라 얻는 게 작다. **단독 실험으로는 비추천**, 다음 실험의 기본 설정으로 흡수한다(현상별 균형 + 지역별 분리 보고).
- **(b)** 가치가 **올라갔다**. 태양광(Solar Farm)은 S2라서 S2 안에 현상이 둘(산사태·태양광)이 된다 → **센서=현상 결합을
  처음으로 깬다.** 여기에 **엇갈린 질문 통제**(산사태 타일에 "태양광이 있나?", 태양광 타일에 "산사태가 났나?" → 정답 no)를
  넣으면 "무언가 달라 보이면 yes"와 "물은 현상을 읽는다"를 가를 수 있다. 1절의 미확인 항목 하나를 직접 겨냥한다.

## 5. 권고 순서 (2주)

1. **E6 실행**(승인 필요, GPU0, 준비 완료) — LLM이 더하는 것의 바닥.
2. **E7 = (b) 수정판**: 산사태(S2)·태양광(S2)·홍수(S1), 현상별 균형 샘플링(a 흡수), 엇갈린 질문 통제, 같은 예산 blind,

   아니면 **"EO-VLM은 무엇을 읽는가: 통제된 평가 프로토콜과 반례"** 분석 논문으로 CVPR에 낸다. 후자는 지금 증거로도
   뼈대가 선다(교환 통제·blind·날짜 감사·later-only·센서 결합).
