# E5 저장 응답을 지역 근거에 연결 — v12

**새 모델 추론이나 피해 판정이 아니다.** 감사된 E5의 원 문항과 저장 응답을 기존 지역 자료에 연결했다. E5의 등록 주판정은 여전히 `mixed_or_inconclusive`이며, 개별 성공 사례가 이를 바꾸지 않는다.

localhost8774의 최신 v12에서 기존914개 홍수 타일을 선택하면 E2/E3/E4 아래에 E5 입력별 학습 비교를 볼 수 있다. 전체5조건×3seed,13,710개 답이며, 주분석 포함902개와 제외12개를 구분한다. 사전 결과를 보고 타일을 새로 선정하지 않았다.

| 표시 행 | 학습 | 평가 |
|---|---|---|
| 전체 입력으로 학습 | A,B,D | A,B,D |
| 두 관측으로 학습 | A,B,0 | A,B,0 |
| 뒤 관측으로 학습 | 0,B,0 | 0,B,0 |
| 차이로 학습 | 0,0,D | 0,0,D |
| 전체 입력 학습 후 D 제거 | A,B,D | A,B,0 |

첫 네 행은 따로 학습한 모델이다. 마지막 행은 full 모델에 대한 평가 시 개입이며 다섯 번째 학습 모델로 세지 않는다. 모든 모델이192개 EO 토큰 위치를 유지하고0 입력도 projector를 통과한다. D는 두 관측으로 계산되는 차이다.

## 원본 연결과 검사

[빌더](../code/build_eo_v11_e5_cases_20260925.py)는 E5의 완료 상태·유효 점수·CPU tensor 독립 감사와 원 파일 해시를 확인한 뒤5989개 원 문항,5989개 실제 저장 prompt,26325개 전체 응답을 검사한다. 기존 타일의 문항ID·라벨·날짜·슬롯·질문 문구가 E5와 정확히 일치할 때만 연결한다. 문구를 추정해서 같은 질문이라고 주장하지 않는다.

기존 E2/E3/E4 필드는 동일값을 보존하고 `e5_control`만 추가했다. 같은 C1 품질907개 중 양쪽 라벨을 지원하는 층902개가 원 주분석과 일치함도 확인했다. catalog·원 날짜·meta·이미지·연구 집계 카드는 바이트가 동일하다. 결과에 유리하게 원 참조 라벨을 바꾸거나 미실행을 `no`로 채우지 않는다.

- 독립 builder 합성12개, API31개(기존 E2/E3/E4 회귀 포함), 기존·신규 JavaScript UI 검사를 통과했다.
- [실제 연결 검산](../artifacts/eo_evidence_search_v12_20260925/http_readback_checks_v12.json)은914타일의 모든13,710응답과 실제 저장 질문·원 응답 행번호를 독립 대조했다.
- 실제 HTTP에서는 양성·음성·이전 예시·훈련 타일의4사례를 대조했다. 저장 답이 없는 훈련 타일에는 새 답을 만들지 않는다. 원본 이미지2개와 HTML·meta·연구 카드도 대조했다. 전체914개에 대한 HTTP 검사를 했다고 주장하지 않는다.
- 브라우저에서 원 영상이 있는 양성/음성 사례의5행×3seed, 주분석 제외/포함, 원 날짜·불확실성·기존 판독이 함께 표시되는지 확인했다.

각 답은 `e5_cases_v11/case_join_index.json`의1부터 시작하는 JSON record 번호로 원 `predictions.jsonl`에 연결된다. `prompts.jsonl`의 실제 질문도 별도 record 번호로 연결한다. 복제한 원 응답에는26,325행 전부가 있어 표시한13,710개만 골라 원 기록을 줄이지 않았다.

첫 v11 화면은 응답 연결과 API 검사는 통과했지만, 오래된 HTML template을 사용해 T0 날짜 표와 원 영상 품질 설명을 누락했다. 브라우저에서 이 회귀를 발견해 [실패 기록](../artifacts/eo_evidence_search_v11_20260925/browser_regression_v11.json)을 보존했다. v12는 v10 HTML에 E5 renderer와 호출 한 곳만 추가했고, 이 두 부분을 제거하면 v10 원 HTML과 완전히 같음을 확인했다. 동결된 v11 builder를 재사용하므로 내부 manifest/source-package 이름에는 v11이 남아 있다. 모델·응답·라벨·날짜를 수정한 것은 아니다.

## 미리 선택했던 두 사례

두 사례는 E5 결과 열람 전에 원 영상 확인용으로 선택했으며 전체 자료를 대표하지 않는다. 아래는 새 통계 분석이 아니라 연결된 원 답의 readback이다.

| 타일 | 참조 답 / 주분석 | full | pair | later | delta | full에서 D 제거 |
|---|---|---|---|---|---|---|
| ks_06770 | yes / 제외 | yes/yes/yes | yes/yes/yes | yes/yes/yes | yes/yes/yes | no/no/no |
| ks_05265 | no / 포함 | no/no/no | no/no/no | no/no/no | no/no/no | no/no/no |

`ks_06770`은 라벨 확인 불가 영역43.38%여서 주분석에서 제외된다. 이 사례의 재학습 회복을 품질 통제된 주성능의 대표 예라고 부르지 않는다. `ks_05265`는 확인 가능한 비침수 사례다. 두 타일의 문서상 pre₂→post 간격은168일이며 기존 모델은12일 합성 날짜를 사용했다. 이 차이와 미확인 실제 취득시각도 함께 표시한다.

E6는 별도의 다음 실험이며 이 화면에 E6 출력은 없다. 모델 예측·참조 라벨·판독자 A의 SN7 기록·문서상 관측 날짜는 각각의 출처와 한계를 유지한다.
