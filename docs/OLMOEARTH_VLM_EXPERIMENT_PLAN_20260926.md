# OlmoEarth 사전학습 개선과 사용자별 VLM 적응: 실험·CVPR 범위

> **OpenRouter·다중 AI와 논문 검증 설계는 [OE2 최신안](OE2_MULTIMODEL_SUPERVISION_AND_REPRESENTATION_PLAN_20260926.md)을 우선한다.** 동일 corpus의 2×2 비교·새 reader로 encoder 전이·독립 사람 평가를 구체화했다. 총100만 원 중 기존 예비12만 원을 API상한5만+예비7만 원으로 나눴으며 사람64인시 목표는 유지한다. 새 실행 결과나 동결 사전등록은 아니다.

> **현재 유료 라벨링 예산은100만 원이다.** [AI 보조 라벨링·국내 경로 조사](EO_VLM_LABELING_BUDGET_1MKRW_20260926.md)가 아래5,000개/1,500인시 및 추가 검수0/300/1,000/3,000의 초기 규모 제안을 대체한다. 현 계획은 검수자60인시+전문가4인시의 조건부 예산안이며, 학습 corpus 확대 목표는 유지한다.

> **같은 날 사용자 요청으로 규모·전문가 감독 설계를 확장했다:** [대규모 EO VLM·전문가 라벨 계획](EO_VLM_SCALE_AND_EXPERT_DATA_20260926.md). 아래 계획의 동일 감독·encoder 효과·독립 평가 원칙은 유지하고, 새 학습 범위와 데이터 후보는 확장안을 함께 읽는다. 둘 다 실행 결과나 동결 사전등록이 아니다.

2026-09-26. **실행 전 설계안이며, 완료 결과나 동결 사전등록이 아니다.** 초점은 OlmoEarth 한 계열이다. 다른 EO foundation model 전면 재현은 필수 범위가 아니다. 사용자 요청은 실험 방법과 제출 범위 검토이며 이번 작업에서 학습·원격 전송·배포는 하지 않았다.

## 1. 지금 주장할 수 있는 범위

**현재 상태로는 새 사전학습 방법의 CVPR 본회의 기여를 입증하지 못했다.** E0–E5는 동결 EO 특징의 판독과 projector 학습에 대한 진단이다. 제안 사전학습, 새 지역 사용자 적응의 라벨 절감, 공간·시간 설명 정확도는 아직 결과가 없다. E5의 mixed 판정과 D1 H의 두 번째 독립 판독 부재를 바꾸지 않는다.

목표 주장은 다음과 같다.

> OlmoEarth의 공간·시간 근거를 언어와 연결하는 사전학습이, 새로운 지역/주제에 VLM을 적응시킬 때 필요한 감독·연산을 줄이면서 근거 정확도와 기존 EO 능력을 유지한다.

최초 VLM 연결, 언어 loss 추가, 쉽게 학습/배포하는 UI 자체를 신규성으로 삼지 않는다. 기본 OlmoEarth Studio는 이미 일반 미세조정·배포를 제공한다. 학습 방법의 효과와 재현 가능한 적응 도구가 논문의 중심과 산출물이다.

## 2. P0: 모델보다 먼저 원자료 계약을 확인

독립 로컬 확인 결과:

- nano_lab은 실제 Nano 구조의 **합성 S1/S2/SRTM 16×16·3시점 CPU 실습**이다. encoder 업데이트 연결 검증에 재사용할 수 있지만 실제 EO 사전학습 성능 증거가 아니다.
- learning_sources에는 공식 코드/설정이 있으나 전체 사전학습 corpus는 없다. 일부 H5는 테스트 샘플이다.
- E5는 no_grad로 추출한 NumPy 특징을 사용한다. 이 캐시만으로 원 encoder까지 역전파할 수 없다. 로컬 review의 대형 입력·checkpoint도 일부는 생략돼 있다.
- 두 고정 홍수 사례의 원영상은 있지만 전체 7,000타일 원영상과 검증된 전후 변화 정답을 확보한 것은 아니다. T0 문서상 날짜 조인은 실제 센서 영상의 완전한 시간 검증이 아니다.

첫 도메인은 **식생 피복의 감소/증가/유지**로 제한한다. 고사 원인·재난 피해·해양 쓰레기 증가를 한 논문에 모두 포함하지 않는다. 회복/지속을 주장하려면 추가 시점의 독립 근거가 필요하다.

첫 데이터 후보는 DynamicEarthNet이다. 주 Planet 영상의 센서 계약이 OlmoEarth 입력과 같지 않으므로, 논문에 기술된 동지역 Sentinel-2 경로의 실제 제공·밴드·날짜·공간 정합을 확인해야 한다. 실제 파일을 확인하기 전 채택 완료로 부르지 않는다. 필요한 원관측 경로가 없거나 변화 양성이 부족하면 이를 기록하고 데이터 결정을 먼저 다시 한다. RGB 영상을 S2 밴드처럼 취급하거나 합성 날짜로 메우지 않는다.

개발 자료 감사의 목표는 30–50개 관측 묶음 정도의 작고 고정된 점검 집합이다. 이는 표본 규모·예산의 계획값이며 논문 평가셋이나 검정력 근거가 아니다. 다음을 실제 파일과 영상으로 확인한다.

1. 같은 위치의 원 관측, 센서·밴드 순서·정규화·좌표·해상도.
2. 취득일/합성 구간/라벨 유효일을 구분한 시간 출처와 두 시점의 정합.
3. 전후 피복 정답, 변화 영역, 미라벨/구름/그림자/불확실 영역.
4. 사람이 판독 가능한 변화 방향과 영역. 공개 라벨을 토대로 구조화된 설명을 만들되 검수 상태를 기록.
5. 지역·원영상·사건·파생 crop을 묶은 분할, 중복 및 양성/음성의 분포.

최종 시험셋의 인간 근거 검증은 학습 출력과 분리한다. 모델이 만든 caption이나 학습에 쓴 지수로 자기 성능을 채점하지 않는다. 독립 검수자가 없으면 그 한계를 공개하고 단독 검수 pilot을 독립 gold 평가로 부르지 않는다.

**P0 통과 조건:** 원 관측에서 encoder forward/backward가 실행되고, source ID·시간·공간 정답·split이 역추적되며, 평가 가능한 복수 AOI의 양/음성 사례가 확보된다. 불충족이면 실제 성능 실험을 시작하지 않는다. 개발 자료의 소량 step을 프로파일링한 뒤 GPU 메모리·초당 처리량·예상 총시간을 산출한다. 현재 GPU 시간/비용을 추정치로 확정하지 않는다.

## 3. P1: 어떤 사전학습 목적을 비교할 것인가

방법 후보는 **방향을 가진 지역 변화와 언어의 정렬**이다. 전체 장면 caption만 맞추면 놓칠 수 있는 작은 변화 영역과 전후 관계를 직접 학습하는 가설이다. 예컨대 같은 배경의 식생→토양, 토양→식생, 피복 유지가 다른 의미를 갖도록 한다. 의미가 같은 다른 지역은 복수 양성으로 취급한다.

개념적 손실은 `기존 EO 목적 + 전체 장면 언어 정렬 + 영역/전후 관계 언어 정렬`이다. 계수·구조·정답 생성·hard negative 규칙은 개발 자료에서 정한 뒤 평가 전에 고정한다. 이 조합 자체의 신규성은 아직 입증되지 않았다. 구체적 loss와 알고리즘을 먼저 명세하고 인접 방법과 비교해야 한다.

학습 마스크로 region 특징을 모으는 경우, 시험 시 정답 마스크를 입력으로 넣어서는 안 된다. 사용자가 지정한 영역을 입력으로 허용하는 과제와, 모델이 변화 위치를 찾아야 하는 과제를 따로 정의한다. 정답 영역을 준 결과는 oracle 조건으로만 보고한다.

| 조건 | 내용 | 구분하려는 효과 |
|---|---|---|
| F | 동결 OlmoEarth + 학습 가능한 연결/검색 모듈 | encoder를 바꾸지 않아도 얻는 이점 |
| O | 동일 출발점에서 원래 EO 목적으로 학습 | 추가 데이터·학습량 자체의 효과 |
| G | O에 통상적 전체 영상–언어 정렬을 추가 | 일반적인 의미 정렬의 효과 |
| M | G에 동일 공간/변화 정답을 표준 분할·상태/전이 보조 과제로 제공 | 추가 감독 정보 자체의 효과 |
| P | 동일 감독을 사용하는 제안 지역·전후 관계 정렬 | 제안 목적의 추가 이점 |

**주대조 후보는 P−M**, P−G 및 P−O는 해석용 대조다. P가 추가 라벨을 사용할 때 G만 이겨서는 목적함수의 우월성을 주장하지 않는다. 모델 용량, 공통 입력·문장·라벨·유효 영역·배치 순서·노출량·튜닝 예산을 맞추고 추가 head와 loss의 계산량을 기록한다. 필요하면 파라미터 수를 맞춘 대조를 추가한다. 같은 step 수를 같은 FLOPs로 부르지 않는다. 계산 효율 주장은 동일 계산 예산 비교 또는 성능–비용 곡선으로 확인한다.

실행은 단계적으로 한다. 처음에는 O/G/P 한 seed의 소규모 **개발 split** 실행으로 동작·학습 곡선·손실 크기·수치 안정성만 확인한다. 이를 논문 성능으로 세지 않는다. 전체 시험 평가 전에 M 및 F의 필요한 대조까지 완성한다.

### 처음부터 학습과 계속 사전학습

- **기전 확인:** Nano/Tiny를 같은 랜덤 초기 상태에서 O/G/M/P로 학습한다. 사용자가 제안한 ‘처음부터 목적을 바꾸기’를 직접 비교한다. 작은 corpus의 제한 예산 결과를 공개 OlmoEarth 전체 사전학습 재현이나 대형 모델 우월성으로 부르지 않는다.
- **실제 사용자 가치 확인:** 선택한 공개 OlmoEarth checkpoint를 공통 시작점으로 같은 조건의 계속 사전학습을 비교한다. 공개 원본 F도 유지한다. 더 적은 사용자 적응 비용이라는 주장을 하려면 실제로 사용할 원본 모델과도 비교해야 한다.
- 두 경로를 표에서 구분한다. 범위·비용 때문에 하나만 완료되면 주장도 그 경로에 한정한다. 큰 모델 확장은 작은 모델의 유효한 근거가 나온 뒤 결정하며 필수 여러 EO backbone 실험으로 범위를 넓히지 않는다.

### encoder에 개선이 남았는지 확인

사전학습에 쓰던 head를 그대로 재사용한 결과와 별도로, encoder를 동결하고 **새 연결 모듈을 같은 구조·초기화·학습 예산으로 각각 학습**한다. 같은 frozen LLM, 공간 해상도·시점·토큰 예산을 사용한다. 서로 다른 encoder에 기존 projector 가중치 하나를 강제로 공유하는 것은 좌표계 불일치가 섞이므로 공정한 비교가 아니다.

F에서는 동일 의미 감독을 후단 모듈에만 주는 강한 대조를 둔다. 이 대조로 이득이 모두 설명되면 encoder 사전학습의 필요성 주장을 축소한다. 고정 encoder의 중간층/풀링 선택도 개발 자료에서 동일 탐색 예산으로 비교할 수 있다. 출력층 선택 하나로 설명되는 효과를 새 사전학습 효과로 과장하지 않는다.

## 4. P2: 실제 사용자처럼 적은 라벨로 적응시키기

**사용자 과제 = 관심 현상과 지역 범위, 지원 라벨, 미사용 평가 지역의 묶음**으로 정의한다. 문항을 무작위로 나누는 대신 AOI·원영상·사건 단위로 묶는다.

제안하는 사용자 라벨 예산은 **8/32/128개의 고유 관측 묶음**이다. 여러 질문을 만든 같은 묶음은 라벨 여러 개로 세지 않는다. 각 묶음에 들어가는 영역/문장 검수 비용도 별도 보고한다. 예산값은 계획값이며 확보 가능한 자료와 라벨 비용 확인 후 사전 명세에서 확정한다. 0-shot은 가능하면 별도 보고하되 동일 API가 자동 지원된다고 가정하지 않는다.

- 같은 사용자 과제·지원 표본을 모든 방법이 공유하고 예산별 표본은 가능하면 포함 관계로 만든다.
- 공통 추가 사전학습/정렬에는 목표 사용자의 지원·시험 지역을 넣지 않는다. 공식 공개 가중치의 역사적 사전학습 노출을 전부 확인할 수 없다면 ‘추가 사전학습·미세조정에 미사용’이라고 정확히 표현한다.
- 지역 내 적응은 같은 사용자 AOI의 비중첩 지원/시험 구역으로, 지역 간 전이는 지원 AOI와 시험 AOI가 다른 것으로 각각 보고한다. 두 조건을 섞지 않는다.
- 단계적 권장 반복은 사전학습 seed 3개 및 지원 표본 추출 3개다. 이는 CVPR의 규정이나 검정력 보장이 아니다. 개별 결과를 보존하고 seed·질문·crop을 독립 지역 수로 세지 않는다.
- 주 reader 하나를 먼저 고정한다. 다른 reader는 선택적인 전이 검증이며, 추가할 경우 방법/teacher/튜닝에 쓰지 않은 모델로 남긴다. 다른 EO backbone 재현을 필수로 두지 않는다.

**핵심 그림:** x축=고유 라벨 예산, y축=새 지역의 근거 QA 성능. 같은 성능에 도달하는 라벨 수와 적응 시간도 보고한다. 측정 예산 사이를 임의 외삽해 ‘라벨 10배 절감’처럼 표현하지 않는다. 공통 사전학습 비용은 사용자별 비용에서 분리하고 총비용도 제시한다.

## 5. 무엇으로 채점할 것인가

주과제는 단순 yes/no나 문장의 유창함보다 **전후 상태/변화 방향과 그 공간·관측 근거를 함께 답하는 구조화된 QA**로 설계한다. 실제 데이터 라벨의 범위를 넘어 정확한 변화 발생일·고사 원인·피해를 요구하지 않는다.

| 항목 | 평가 초안 |
|---|---|
| 주지표 | 32개 지원 묶음에서 AOI별 동일 가중 근거 QA 정확도. 전후 의미·근거 영역·관측ID의 공동 정답 기준을 평가 전에 명시 |
| 분해 지표 | 변화 방향 macro-F1, 위치 IoU/pointing 정확도, 관측ID 정확도. 공동 점수의 개선 원인을 분해 |
| 검색 | 전체 관련성을 확인한 고정 후보군에서 복수 정답 mAP/Recall@K. 미판정 후보를 자동 음성으로 세지 않음 |
| 미확인 처리 | 답변 coverage와 오답률, 판독 불가 항목의 보류. 모두 보류해 점수를 높이지 못하도록 주 정확도에서는 미응답을 오답 처리 |
| 기존 능력 | 독립 EO 분할/분류 지표 및 필요한 분광·공간 정보의 전이. 원 loss 유지만으로 보존을 가정하지 않음 |
| 사용자 비용 | 실제 학습 시간, 최대 GPU 메모리, 학습 파라미터 수, 사용자별 저장량, 라벨 검수 비용 |

공동 정답 기준의 공간 허용 오차·필드·평가 구현과 주/보조 지표 구분은 P0 이후 성능 결과 전에 확정한다. 숫자가 좋은 항목을 사후 주지표로 바꾸지 않는다. 신뢰구간은 같은 사용자/AOI를 방법 간 함께 재표집하며 지역·사건 단위 변동을 반영한다. 적은 독립 지역에서 넓은 구간이 나오면 미정으로 보고한다.

필수 어려운 비교에는 같은 배경의 반대 변화 방향, 계절 색 변화 속 피복 유지, 이후 모습은 비슷하지만 시작 상태가 다른 쌍, 가림·미라벨 사례를 포함한다. 사후 시점 제거는 진단에만 사용하고, 전후/단일 시점으로 각각 학습한 비교를 따로 둔다. 이는 E5에서 배운 통제다.

### 결과 전 결정 규칙

정확한 효과 폭·EO 보존 허용폭·표본 규모는 개발 자료의 측정 오차·실용 기준으로 정하고 최종 평가 전에 동결한다. 아직 확보하지 않은 자료에 임의의 수치를 확정 사전등록처럼 쓰지 않는다.

- **진행:** P가 동일 감독 M보다 사전 지정 주지표에서 개선되고, 새 AOI와 반복에서 재현되며, EO 보존 기준을 만족한다. 주효과 구간과 최소 유의미 폭을 함께 본다.
- **주장 축소:** F 또는 M으로 이득이 설명되면 encoder 목적의 기여를 주장하지 않는다. 특정 reader/특정 지역에서만 좋아지면 범용 표현 주장을 해당 조건으로 제한한다.
- **유보:** 구간이 넓으면 동등/실패로 단정하지 않는다. 사전 고정한 추가 데이터 예산 안에서만 보강하며 시험 결과를 보고 쉬운 지역으로 교체하지 않는다.
- **중단/전환:** 날짜·정답 계약이 성립하지 않거나 충분한 평가에서 주효과가 지지되지 않으면 현재 방법의 확대 학습을 멈춘다. 재현 가능한 진단 결과는 보존한다. 성공할 때까지 loss/seed/분할을 반복 변경하지 않는다.

## 6. P3: 도구·배포는 좁고 재현 가능하게

최소 산출물은 `train / evaluate / export / predict`의 연결이다. 한 현상·한 데이터 입력 규격으로 사용자가 지원 라벨을 넣고 adapter를 학습한 뒤, 다른 깨끗한 환경에서 같은 원 관측에 동일 결과를 재현하는지 검증한다. 모델 묶음에는 base revision, 수정 가중치, 센서/날짜/전처리/토큰 계약, tokenizer/질문 형식, 평가 기록을 포함한다.

실험 주장이 먼저며 범용 계정·협업·모델 허브·대규모 운영 플랫폼은 이번 논문의 필수 범위로 두지 않는다. 기존 화면은 저장된 결과 조회이므로 실시간 새 지역 판독이나 사용자 미세조정 시스템으로 소개하지 않는다. 공식 Studio가 임의 VLM을 바로 호스팅하는지도 별도 미확인이다.

## 7. CVPR에서 어느 정도까지 가능한가

아래는 연구 판단이며 공식 채택 기준이나 채택 확률이 아니다.

| 확보한 증거 | 적절한 주장/목표 |
|---|---|
| VLM 연결·미세조정 UI·모델 내보내기만 구현 | 유용한 엔지니어링 산출물. 현재 구상만으로 본회의 방법 기여는 약함. 데모 공모 적합성은 해당 연도 공고 확인 필요 |
| 한 과제의 작은 비교, 실패 통제·원자료 계약·재현 코드 | 초기 방법/진단 연구. 주제가 맞는 워크숍을 검토할 수 있으나 채택 보장은 아님 |
| 구체적인 새로운 학습 목적, 동일 감독/연산 대조, 새로운 사용자 AOI의 라벨 효율, 근거 정확도·EO 능력 보존, 재현 가능한 학습/내보내기 | **OlmoEarth 중심의 본회의 제출을 목표로 삼을 만한 증거 묶음**. 신규성·효과·평가 규모에 대한 실제 심사는 별도 |

본회의 권장 증거는 독립 평가 집합 둘 이상(예: 주 식생 변화와 별도 피복 전환/지역 corpus), 작은/큰 OlmoEarth 비교 또는 충분한 단일 규모의 통제, 여러 seed의 핵심 결과, 데이터/학습/평가 계보, 필요한 ablation이다. 숫자상의 ‘데이터셋 2개’가 독립성을 보장하지 않는다. 같은 사건을 다른 이름으로 복제하지 않는다. 다른 VLM은 보조 전이 검증으로 선택할 수 있다.

가까운 선행연구로 RemoteCLIP, SAIL(CVPR2025), Perception Encoder, GeoMeld-FM(CVPR2026 workshop), 시간 변화 검색의 RSICRC를 비교한다. SAIL은 SSL 목적과 언어 정렬 가능성을 이미 다뤘고 GeoMeld는 EO 공동 언어 사전학습을 다룬다. “사전학습 목적이 언어 활용성에 영향을 준다”는 질문만으로 최초성을 주장하지 않는다. 우리의 차별점은 구체적 지역/시간 관계 목적과 사용자 적응에서 확인되는 효과여야 한다.

## 8. 2027 제출을 목표로 한 결정 일정

2026-09-26 기준 공식 CFP의 **등록은 2026-11-10 AoE, 본문은 2026-11-16 AoE**다. 약 7주이며 아래는 자원·데이터 준비를 전제로 한 제안 일정이다. GPU 실행 시간 보장이 아니다.

| 기간 | 완료하거나 결정할 것 |
|---|---|
| 9/26–10/2 | P0 원자료/날짜/영역/분할 감사, 작은 실제 forward/backward와 비용 측정, 명세 동결 준비 |
| 10/3–10/10 | Nano/Tiny 개발 비교, 원 목적·일반 정렬·제안 목적의 구현/동작 확인, 강한 대조 준비. 방법 확대 여부 결정 |
| 10/11–10/24 | 고정 명세의 반복 실험과 새 지역 소량 라벨 적응. 언어/공간 근거 평가·EO 보존 |
| 10/25–11/3 | 필요한 독립 자료/큰 모델/보조 reader 검증 중 주장에 맞는 범위, 내보내기 재현과 논문 표 |
| 11/4–11/9 | 결과 감사·한계·서술과 그림 정리. 유리한 새 실험을 무한 추가하지 않음 |
| 11/10·11/16 | 공식 등록·본문 제출 마감. 제출 실행은 별도 사용자 요청/승인 범위 |

10/2에 원자료와 평가 계약이 없거나 10/10에 유효한 작은 비교조차 없다면, 2027 본회의 방법 논문 일정은 크게 불확실해진다. 그때 기존 진단 성과와 다음 연구를 분리해 제출 범위를 다시 판단한다. 이번 확인에서 2027 워크숍/데모의 구체적인 참가 공고·마감은 확인하지 못했으므로 확정 대안 일정으로 제시하지 않는다.
