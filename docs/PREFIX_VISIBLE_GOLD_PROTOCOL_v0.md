# prefix-visible gold 검수 프로토콜 v0 (추석 검수용 초안)

작성 2026-09-22. 계획 `PLAN_GROUNDED_CHANGE_MEMORY_2026_09_22.md` §9의 검수 예산(사용자 50h, 최대 100h) 안에서 씀.
**G1-lite(silver oracle) 결과가 "headroom_present"로 나오기 전에는 검수를 시작하지 않음.** 시작 여부는 추석 전 결정.

## 1. 검수자가 하는 일

- 한 항목 = (AOI, cutoff 월, 질문). 도구는 **cutoff까지의 월별 영상만** 보여줌. 이후 영상은 차단.
- 질문 유형
  - Q1 "이 사분면에서 최근 6개월 사이 새 건물이 생겼나?" → 예/아니오/판독 불가
  - Q2 "이 사분면에서 새 건설이 처음 분명히 보이는 달은?" → 월 선택/판독 불가
  - Q3 "가장 최근 새 건설이 있는 사분면은?" → NW/NE/SW/SE/판독 불가
- 답과 함께 **근거 프레임**을 표시함. "이 답을 내는 데 충분한 최소 프레임 집합"을 2~4장 고름. 대체 가능한 집합이면 여러 개 표시 가능.
- 도구가 라벨에서 뽑은 후보 프레임을 먼저 제안함(확인/기각). 후보 밖 프레임 추가 가능. 후보를 그대로 받아쓰기만 하면 안 됨.
- 구름·연무·registration 흔들림으로 판독이 안 되면 "판독 불가"를 고르고 어느 프레임이 가렸는지 표시.

## 2. 규칙

- 라벨(polygon)은 보지 않음. 영상만.
- 항목당 목표 3분, 최대 5분. 5분 넘으면 "판독 불가"로 두고 다음.
- 같은 AOI 항목을 연속으로 하지 않음(순서는 도구가 섞음).
- 겹침 20%는 두 검수자가 독립으로 함. 서로 답 공유 금지.

## 3. 규모(예산 100h 기준)

| 세트 | 항목 | 시간 |
|---|---|---|
| G1 gold | 100 + 겹침 20 | 약 25h |
| 본 시험 | 400 + 겹침 80 | 약 50h |
| S2 장기열 | 120 | 약 12h |
| 시범·재검수 | | 약 13h |

50h만 가능하면 본 시험 200 항목, 겹침은 G1 세트만.

## 4. 결과 처리

- 두 검수자 일치도(kappa) G1 세트에서 보고. .6 미달이면 질문 정의를 고치고 재검수.
- 근거 프레임 집합은 "유효 집합들"로 저장(단일 gold frame 강제 안 함).
- 검수 결과는 `spacenet7/gold_v0/annotations.jsonl`에 항목·검수자·시각·소요시간과 함께 저장.

## 5. 도구(2주차 초, 검수 시작 전 완성)

- 정적 HTML 한 장: 프레임 썸네일 격자(cutoff 이후 없음), 확대, 사분면 격자 오버레이, 후보 프레임 표시, 답·근거 체크박스, 소요시간 자동 기록, JSON 다운로드.
- 서버 접속 불필요. 프레임 PNG는 `spacenet7/diag_lite_v0/frames/`에서 512px로 이미 생성됨.
