## 1. 논문의 중심

**지역의 기후·지형·생태 지식과 소수의 전문가 교정을 학습하여, 처음 보는 지역에서도 새로운 대상을 찾고 근거를 설명할 수 있는 OlmoEarth 기반 VLM을 만든다.**

원하는 변화는 새 지역이나 대상이 생길 때마다 많은 정답을 다시 모으는 대신, 축적된 EO 표현과 환경 지식에 소수의 지역 교정을 더해 적용할 수 있게 하는 것이다. 실질적인 적용 범위 확대와 소량 라벨 효율이 논문의 주 효과다. 현재는 검증할 가설이며 기존 방법 대비 향상 수치는 없다.

사용 장면의 예: 전문가가 농경지와 비슷해 보이는 습지의 양성·대조 영역을 몇 개 지정한다. 모델은 대상 지역의 지형과 계절 조건을 참고해 같은 개념을 다른 영상에서 찾는다. 사용자는 자연어로 후보 지역을 검색하고, 확인 가능한 범위의 면적과 근거 영상을 함께 본다. 이후 생태·수면·인공 구조물로 같은 학습 방식을 확장할 수 있는지를 평가한다. 새로운 생태 피해 원인이나 기후 변화의 인과 관계를 이 예시만으로 주장하지 않는다.

## 2. 지금까지의 요소가 맡는 역할

| 요소 | 맡는 일 | 중심 주장과의 연결 |
|---|---|---|
| OlmoEarth의 원 EO 학습 | 공간·분광·시간 정보를 가진 기본 표현 유지 | 지역에 적응해도 원 EO 능력을 잃지 않게 한다 |
| 지역·계절 맥락 | 어떤 환경의 지식과 예시가 적용 가능한지 표현 | 국경·달력만으로 제한되지 않는 전이 |
| 전문가의 양성·대조 교정 | 사용자가 원하는 개념과 혼동 대상을 정의 | 새 대상에 필요한 라벨 수 감소 |
| 공간 근거를 읽는 실제 VLM | 질문을 대상·영역·조건에 연결하고 답을 생성 | 실제 자연어 검색·판독으로 효과 검증 |
| 측정·관측 범위 검사 | 결과가 참조하는 영상·영역·시점 확인 | 잘못된 맥락이나 관측 부족에서 부당한 단정 억제 |

측정·설명은 같은 공간 예측에서 파생될 수 있으므로 독립 능력 세 개로 중복 계산하지 않는다. 지역 맥락과 VLM 연결 각각의 존재만으로 신규성을 주장하지 않는다. 이 요소들이 **같은 수의 교정으로 더 넓은 환경에 적용되는 능력**을 만드는지 평가한다.

## 3. 방법 후보를 하나의 학습 경로로 구현

```text
다중시점 EO 관측 ── OlmoEarth ── 공간·시간 표현 ─────────────┐
                                                        │
지역 문장·기후 계절성·지형 ── 환경 표현 ── support 비교 조건 ┤
                                                        ├─ 위치별 대상 예측
전문가의 양성·대조 영역 ── 사용자가 지정한 개념 ────────────┘
                                                              │
질문·참조 영역 + 실제 VLM의 RGB 경로 ──────────────────────────┤
                                                              └─ 후보·측정·근거 설명
```

학습 episode는 한 지역의 교정 예시(support)와 다른 지역의 판독 대상(query)을 묶는다. 정답 위치와 라벨이 확인된 예시에 한해 지역 맥락을 바꾸거나 제외하는 대조도 구성한다. 환경에 맞는 비교 방법과 위치별 개념 판독을 학습하고 loss가 OlmoEarth encoder까지 전달되게 한다. 공통 원 EO 목적을 유지해 공간·분광 정보가 과도하게 지워지는지 검사한다.

국가가 같다는 이유로 모든 표현을 가깝게 만들지 않는다. 환경 유사성이 도움이 되는 속성은 공유하되, 농경지·습지·도시의 구조와 실제 현재 상태는 구별해야 한다. 지역에 대한 통상적인 설명이 특정 날짜 영상의 사건 라벨을 대신하지 않는다.

**아직 해결해야 할 방법상의 핵심:** 일반적인 context-conditioned episodic learning과 구별되는 이득을 내는 구체적 학습 연산. 기존 listwise contrast 후보는 출발점이며 신규 원리로 확정되지 않았다. 먼저 generic 학습의 실패 양상을 재현하고, 환경 조건을 고려한 support–query 결합이 어떤 실패를 줄였는지를 분해해야 한다. 손실함수나 모듈 수를 늘리는 것만으로 이 문제를 해결했다고 간주하지 않는다.

## 4. 가장 먼저 답할 결정 실험

같은 원 EO, 실제 VLM, 양성·대조 라벨, 질문, support 예산으로 아래 네 조건을 비교한다.

| | 지역 맥락 없음 | 같은 지역 맥락 제공 |
|---|---|---|
| 일반 episodic 학습 G | G0 | G1 |
| 제안 교정 전이 학습 P | P0 | P1 |

- **주 비교 P1−G1:** 같은 맥락과 교정 데이터를 받는 일반 학습보다 제안 방법이 나은가? 두 조건은 source facts·negative pairs·총 forward·조정한 파라미터 예산을 맞춘다.
- **P0−G0:** 맥락이 없어도 제안 학습 자체의 이점이 있는가?
- **보조 상호작용 `(P1−P0)−(G1−G0)`:** 맥락의 이점이 제안 학습에서 더 커지는가? 이는 정한 지표 스케일에서의 상호작용이며, 양수 자체가 주 비교 성공이나 신규성 증거는 아니다.
- 맥락 유무는 정보량을 일부러 바꾸는 비교다. 네 조건 전체가 같은 정보를 받았다고 말하지 않는다. 본문 핵심 기여는 같은 정보를 받는 G1/P1에서 판정한다.

각 모델은 같은 K개 검수된 support를 받아 동일한 query를 평가한다. K의 후보는 1/5/20이며 실제 단위는 독립 라벨링한 관측 묶음이다. 한 영상의 여러 질문이나 crop을 독립 인시·라벨로 중복 계산하지 않는다. 정해진 대상 이름이 있는 응용 과제에서는 K=0도 평가할 수 있다. 이름을 임의 별칭으로 가리고 완전히 새 개념을 정의하는 과제에서는 K=0에 정의 정보가 없으므로 같은 적응곡선의 유효 기준으로 쓰지 않는다.

필수 추가 대조는 충분히 학습한 frozen OlmoEarth+connector, 추론 때만 같은 맥락을 제공하는 모델, 같은 support를 받는 분할 전문 모델+명시적 연산+동일 VLM이다. 공식 목적 추가 학습과 generic contrastive/meta-learning 대조도 유지한다. 모델의 설명 길이나 설득력으로 이 대조의 성능 차이를 대신하지 않는다.

이 네 조건은 개발 단계의 결정 실험이다. 기존 계획의 21 core pipelines에 새 조건들을 무조건 추가하는 실행 약속이 아니다. 효과와 비용이 확인되면 확증 config의 arms·seeds·주지표·판정 기준과 전체 예산을 결과를 보기 전에 다시 고정한다. 기존 test의 사전등록은 변경하지 않는다.

## 5. 큰 기여를 보여 줄 결과 묶음

1. **라벨 효율:** 같은 held-out 지역의 판독 품질에 도달하는 데 필요한 독립 교정 수를 줄인다. 같은 K에서의 품질과 같은 품질에서의 K를 함께 제시한다. '10배 절감' 등 숫자는 실측 전 목표나 결과로 약속하지 않는다.
2. **환경 전이:** 국가명만 가린 조건, 같은 국가의 다른 환경, 다른 국가의 비슷한 환경에서 효과가 유지된다. train/test의 부모 지역·footprint·문서·연도를 감사하고 지역 단위 구간을 보고한다.
3. **OlmoEarth 재사용성:** 새 connector/reader에서도 이점이 남고, 외부 맥락을 제거한 독립 EO 평가에서 실제 표현 개선 또는 사전 지정한 능력 유지가 확인된다. 전체 시스템 개선과 encoder 자체 개선은 별도 주장이다.
4. **근거의 정확성:** 위치별 대상 예측과 실제 VLM 답이 일치하며, 틀린 배경 설명이나 결측 관측에서 검증되지 않은 대상을 단정하지 않는다. 이것은 모델 품질 조건이며 이 항목만으로 새 알고리즘의 신규성이 입증되지 않는다.

논문의 중심 그림은 K에 따른 새 환경의 성능 곡선, 두 학습 요소의 2×2 비교, 새 reader/독립 EO 전이 결과로 구성한다. 실제 사례 그림은 이 수치가 어떤 사용자 문제를 해결했는지 보여 준다. mask 개선에서 파생된 면적·설명을 별도의 독립 전이로 더하지 않는다.

## 6. 어디부터 크게 확장할 것인가

모델 목표는 식생·농업·수면·구조물에 공통으로 쓸 수 있는 적응 경로다. 첫 감독 실험은 crop/식생처럼 공간 라벨과 support를 구성할 수 있는 자료의 계약부터 검증한다. 독립 두 번째 분야로 수면·침수 등을 평가해 특정 작물 데이터셋에만 맞춘 방법인지 확인한다. 구조물과 센서 간 전이는 정합 자료·해상도·라벨이 확보되면 같은 recipe로 확장한다.

PASTIS 등은 완전성·공간 분할·라벨 계약을 확인한 후 채택한다. 한 국가 내의 여러 지역으로 시작했다면 '국가 밖 전이'로 쓰지 않는다. 공식 1k corpus의 999저장좌표는 구현과 맥락 연결 연습에 유용하지만 원 pretraining corpus 노출을 제거해 주지 않고, 독립적인 변화 정답도 자동으로 제공하지 않는다.

순서는 `현재 native/VLM 실행 결과 확인 → 지역 자료·support/query manifest → G1/P1 작은 비교 → 2×2·라벨곡선 → 두 분야·새 reader·학습 규모 확대`다. 최종 평가를 반복해서 좋은 결과가 나올 때까지 방법을 고르지 않고, 개발 자료에서 선택 후 평가를 동결한다.

## 7. 현재 근거와 이번 갱신

현재 확보한 기반은 v1.2-Base와 공식 H5 corpus, 자료 출처와 지역 그룹 감사, CPU 실제 encoder 학습·저장 복원 검증, 실제 Qwen3-VL 연결 구현이다. 지역 맥락과 전문가 교정을 결합한 G/P 비교, 새 환경 전이, 라벨 절감은 아직 실행 결과가 없다. 이번 통합 설계는 이러한 차이를 유지한다.

2026-09-27 11:36 KST 운영 확인: 앞서 등록한 GPU 실행의 최신 로그를 읽으려 했으나 조회가 4분 이상 응답하지 않아 로컬 읽기 전용 SSH 프로세스만 종료했다. 이번에 학습 완료·실패·계속 대기 중 어느 상태인지 새로 확인하지 못했다. OE4 문서의 02:45 KST 대기 기록은 당시 snapshot이며 현재 상태로 재인용하지 않는다. 서버의 학습 프로세스에는 신호를 보내지 않았다.

독립 검토자는 “추가 텍스트와 라벨을 넣은 일반 적응 시스템인데 전문 모델+검색으로도 되지 않는가?”를 핵심 반론으로 제시했다. 같은 정보·같은 비용의 대조와 새 reader 전이를 유지하는 이유다. 검토 의견은 연구 진행의 근거이지 채택 확률이나 성능 보증이 아니다.
