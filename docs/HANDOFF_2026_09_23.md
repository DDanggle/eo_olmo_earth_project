## 5. 다음에 할 일 — 결정 실험 D1

사전등록 `config/decision_experiment_d1_prereg_v0.json` (등록 완료, 결과 보기 전 작성).
대상은 v0.5 팩(6 AOI, 12 episode, 172 프레임). 세 단계이고 **H가 실패하면 L·R은 돌리지 않음**.

### 단계 H — 사람 판독 가능성 (사람 ≤10인시, 상한이지 목표 아님)

두 검수자가 독립으로 `annotator_pack/index.html`을 열어 12 episode를 판독. 힌트·모델 답·polygon 없음.
정답 정의는 "제공된 관측 중 변화가 처음 분명히 보이는 관측"이고 실제 발생일이 아님.

```bash
python3 -m http.server 8766 --bind 127.0.0.1 \
  --directory labeling_pack/visible_contract_v05_20260922/annotator_pack
# 각자 JSON 내려받기 → rater_a.json, rater_b.json
python3 -B code/sn7_visible_pack_v05.py finalize \
  --pack labeling_pack/visible_contract_v05_20260922/annotator_pack/pack.json \
  --annotations /abs/rater_a.json /abs/rater_b.json \
  --output artifacts/sn7_visible_v05_review_01
```

관문: 합의율 ≥ .60 이고 세 범주(change_supported / no_visible_change / insufficient_evidence)가
모두 하나 이상. 실패 시 SN7 기억 노선을 닫음.

### 단계 L — 근거 손실 측정 (모델 없음, 노트북 CPU 수 분)

```bash
python3 code/sn7_evidence_loss_v0.py \
  --pack labeling_pack/visible_contract_v05_20260922/annotator_pack \
  --review artifacts/sn7_visible_v05_review_01 \
  --out artifacts/sn7_evidence_loss_v0
```

최신-K·균등-K·변화량 top-K가 사람이 확인한 근거를 보존하는지 tierA/B/C로 측정. K∈{2,3,4,6}.
읽기: K=4에서 최선 선택기가 tierA를 <.70 보존하면 `loss_present`, ≥.90이면 `no_loss`.

### 단계 R — reader 내용 통제 (GPU, reader당 1시간 미만)

`finalize`가 만든 `diagnostic_matrix.jsonl`을 소비함. 교체(swap) 조건은 **대체 영상 자체의 정답**으로
채점하므로 v0.4의 통제 결함이 고쳐져 있음.

```bash
# 서버에서
./bin/nx push $PWD/code/sn7_d1_reader_run_v0.py olmoearth/code/
CUDA_VISIBLE_DEVICES=1 .venv-master/bin/python code/sn7_d1_reader_run_v0.py run \
  --matrix <review_dir> --pack <pack_dir> --reader qwen  --out spacenet7/d1_reader_v0
CUDA_VISIBLE_DEVICES=1 PYTHONPATH=molmo_deps .venv-master/bin/python code/sn7_d1_reader_run_v0.py run \
  --matrix <review_dir> --pack <pack_dir> --reader molmo --out spacenet7/d1_reader_v0
python3 code/sn7_d1_reader_run_v0.py score --matrix <review_dir> \
  --answers spacenet7/d1_reader_v0/answers_qwen.jsonl --out artifacts/sn7_d1_reader_v0
```

판정: `content_use = swap_vs_donor − swap_vs_source ≥ .30` 이고 CI가 0을 제외해야 "내용을 읽는다".
runner는 review 보고서의 `diagnostic_manifest_ready`가 참일 때만 실행되고, 소비한 matrix의
sha256을 `run_context.json`에 남김.

### 결과에 따른 결정표 (사전 고정)

| 관측 | 다음 |
|---|---|
| H 실패 | SN7 기억 노선 닫음 |
| H 통과, L = no_loss | 새 기억 방법 투자 근거 약함 → 벤치마크·판독 논문으로 축소 |

## 6. 하지 말아야 할 것 (과거 실패에서 나온 규칙)

1. **결과를 본 뒤 관문·기준을 바꾸지 않음.** 여섯 판 동안 지킨 규칙이고, 이것이 매번 설계 결함을 잡았음.
2. **privileged 조건은 내용 통제와 짝으로만 해석.** v0.3의 오판이 여기서 나왔음.
3. **기존 silver(신규 8동 누적 도달월)로 학습하지 않음.** 질문 정의("처음 분명히 보이는 관측")와 어긋남.
4. **v0.5 검수 정답은 평가용.** 여기에 학습하지 않음.
5. **12 episode 개발 표본으로 보편 결론 내지 않음.** 다음 자원 배분 결정용임.
6. 서버 실행은 `./bin/nx`로만, 긴 작업은 `setsid nohup`, 모든 실행은 `env -u PYTHONPATH`로 감쌈.
7. 커밋 메시지에 Claude 공동 저자 줄을 넣지 않음.

## 7. 열린 결정 (사람이 정해야 함)

1. **추석 판독 실행 여부와 상한.** 계획은 ≤10인시, 두 사람 독립. 한 사람만 가능하면 일치도는 못 재고

   입력을 쓰려면 4지역 ±12개월 S2(약 100~150관측/타일)가 필요함. 미착수.
