# CVPR 수준으로 가려면 — 규모·증거·준비 목록 (2026-09-27)

주제(가제): **라벨 없이, 재난 종류를 모르는 상태에서 촬영일 단위 기반모델 임베딩으로 피해를 찾는 도구 — 연간 임베딩 제품·재난별 지표와의 비교**
근거: MS-163(A1, 홍수 7사건에서 T1 +14%p), A1b(26사건, 진행 중). 마감: 등록 11/10, 본문 11/16 AoE.

## 4. 솔직한 위험

1. **홍수 밖에서 안 이길 수 있다.** 산불은 dNBR이 매우 강하다. 그래서 "재난 종류를 모를 때"(섞어서 평가)가 주 무대가 되어야 한다.
2. **구글 맞춤형 임베딩**이 나오면 AlphaEarth와의 격차는 줄어든다. 고전 지표 대비 우위·공개 모델·처리 비용으로 차별화해야 한다.
3. **방법이 단순하다**는 지적 — 평소 변화 보정·확대가 소거 실험에서 실제로 기여해야 한다(A1b가 첫 시험).
4. 7주는 빠듯하다. 3주차 게이트에서 2종 통과가 안 되면 **CVPR 워크숍 또는 다음 학회**로 조정한다.
