# 통제 × 시스템 결과표 (논문 방법·결과 절 뼈대, 2026-09-27)

각 칸은 원 기록(MS 번호·다른 세션 문서)의 수치를 옮긴 것이다. 새 측정이 아니다. "—"는 아직 측정하지 않음.
시스템: **ET** = EarthTalk 단일과제 projector(MS-131/156), **R2** = E2 산사태+홍수 reader(MS-157), **R7** = E7 3현상 reader(진행 중),
**H** = 비LLM head(E6 attention head MS-158 / E7 단순 MLP head), **ED** = 공개 EO-VLM EarthDial_4B_RGB zero-shot(MS-159/160).

## 1. 통제의 정의와 배제하는 설명

| 통제 | 조작 | 답이 이렇게 나오면 | 배제되는 설명 |

| 같은 예산 blind | 같은 연결부·예산, EO 입력 0으로 학습 | reader ≫ blind | "문구·날짜·질문 분포만으로 맞힌다" |

| 작은 head | 같은 특징·같은 노출, LLM 없음 | reader ≈ head | "LLM이 판별에 기여한다" |
| 실제 날짜 감사 | 프롬프트 날짜의 원 출처 대조 | 틀린 날짜에도 성능 유지 | "날짜를 읽는다" |

## 3. 지금 읽을 수 있는 것 / 없는 것

- 읽을 수 있음: 임베딩 reader와 픽셀 EO-VLM 모두 **입력 내용을 쓰고 날짜 문구를 쓰지 않는다**. 쌍 통제에서는 둘 다 **차이에 의존**한다.
- 읽을 수 있음: 이 산사태·홍수 과제는 **사후 영상 하나로도 거의 같은 정확도로 학습**된다 → 전·후 벤치마크 점수는 비교 능력의 증거가 아니다.
- 읽을 수 있음: 이진 판별에서는 **작은 head가 LLM reader와 구분되지 않는다**.
- 아직 없음: 새 지역 일반화(X1 italy 진행 중), 센서=현상 교락 해소(E7 진행 중), 여러 공개 EO-VLM(ED 하나뿐), 다중분광·SAR 입력의 공개 모델.
- 쓰면 안 됨: 두 시스템의 "대비"(9/27 정정), "변화를 이해한다/못한다"의 일반화, "LLM 불필요"(동등성 미검정).
