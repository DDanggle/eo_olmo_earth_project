## E0에서 추가 확인한 범위

[독립 검토](../artifacts/E0_BOUNDED_INDEPENDENT_REVIEW_20260925.json)는 현재 코드 SHA, 기존 응답과 공개 해시, 등록 타일 bootstrap 구간을 대조했다. within/cross swap은 source 질문의 라벨이 아니라 **donor 임베딩 쌍의 원 라벨**로 올바르게 채점했다. `reads_embedding` 판정은 유지한다.

그러나 타일192개 중 Hiroshima186개, Indonesia6개다. Indonesia의 within d는0, cross d는−.1667이다. 두 지역을 동등하게 검증했거나 새 지역에서 안정적으로 읽는다고 표현하면 안 된다. cross384개 배정에는 서로 다른 donor 문항ID246개가 사용돼 첫 사용 이후 반복 배정이138회 있었다. 등록 타일 bootstrap은 이 donor 재사용과 지역 종속성을 따로 반영하지 않는다.

Q3 공간 질문에서 donor 라벨 Jaccard는 .2613, source 라벨은 .3147, 차이는−.0534다. donor의 위치를 따라 읽는다는 양의 기술적 근거가 없다는 뜻이다. 반대로 텍스트를 따른다는 인과 결론도 아니다. 원 장면의 공간 분포와 교체 불일치 등이 통제되지 않았다.

이 검토의 범위에서 과거 MS-131 원 응답 파일은 확보되지 않아 E0에 저장된 재현율384/384를 독립 재계산하지 못했다. E0 manifest는 projector와 코드만 고정했고 최신 E5처럼 QA·cache·LLM·tokenizer의 전체 입력 계보는 남기지 않았다. 현재 해시 기록을 과거의 사전 봉인으로 바꾸지 않는다.

## E1에서 새로 닫은 계보 공백

이번 E1은 **9월25일의 홍수 QA 생성**이며,8월26일의 crop 문맥×decoder factorial E1과 다른 실험이다. 서버 원본 두 파일을 읽기 전용으로 확보했다. 문항 SHA `7c09a6b0336290f3eb765fde5d0483dcb9c5091d8ea4244a5840264966e5255b`는 이전 C0 manifest의 부모 입력 SHA와 일치한다. 현재 생성 코드도 원 summary의 코드 SHA와 일치한다.

[문항 계보 검토](../artifacts/E1_FLOOD_LINEAGE_REVIEW_20260925.json)는 고유ID4,851개, split/kind별 개수, 사건·타일 분리, 원 날짜·슬롯·라벨 계약을 확인했다. E5의 홍수4,569문항은 train3,198/test1,371이며 원 문항의 **모든 필드가 일치**한다. validation282문항은 E5에 포함되지 않는다. 이 검토는 문항을 전달하는 과정의 일관성을 확인하며, 원 라벨이나 사건의 새로움을 보증하지 않는다.

## 사용자가 지역 근거 화면에서 확인할 수 있는 것

전체 점수와 별도로 기존914개 홍수 타일에 E5의5조건×3seed 저장 답을 연결한다. 원 문항ID·참조 라벨·날짜·슬롯을 확인하고 각각의 원 응답 행으로 역추적한다. full/pair/later/delta는 각각 학습한 모델이고, full_no_delta는 학습한 full의 평가 시 개입임을 구분한다. 합의·투표 신뢰도·현재 피해 판정은 만들지 않는다.

원 영상이 있는 두 사례는 E5 결과를 보기 전에 고른 사례이며 전체를 대표하지 않는다. 특히 ks_06770은 라벨 확인 불가 영역43.38%로 주분석에서 제외되고, ks_05265는 확인 가능한 비침수 사례로 주분석에 포함된다. 타일별로 답이 회복되지 않더라도 숨기거나 다른 사례로 대체하지 않는다.
