# 100만 원으로 진행하는 AI 보조 EO 라벨 검수

> **OpenRouter·다중 AI와 논문 검증 설계는 [OE2 최신안](OE2_MULTIMODEL_SUPERVISION_AND_REPRESENTATION_PLAN_20260926.md)을 우선한다.** 동일 corpus의 2×2 비교·새 reader로 encoder 전이·독립 사람 평가를 구체화했다. 총100만 원 중 기존 예비12만 원을 API상한5만+예비7만 원으로 나눴으며 사람64인시 목표는 유지한다. 새 실행 결과나 동결 사전등록은 아니다.

2026-09-26. **국내 공개 자료 조사와 예산 설계안. 채용·견적 확정·유료 발주·API 구매·GPU 실행은 하지 않았다.** 사용자의 총100만 원 제약이 이전5,000개 정밀 라벨/1,500인시 제안을 대체한다. 큰 EO VLM 학습 목표와 동일 감독 비교는 유지한다.

## 1. 추천

큰 학습 자료는 기존 현장·전문 매핑 라벨과 AI 초안으로 만들고, 유료 인시는 작은 독립 평가 자료와 감독 오류를 찾는 데 집중한다. 권장 인력 구성은 **GIS/위성영상 기초 경험이 있고 과제 교육을 받은 판독자2인 + 짧은 원격탐사 전문가 검토**다. 학생이라는 신분이나 일반 라벨링 경력만으로 EO 전문가라고 부르지 않는다. 같은 과제20개 정도를 유료로 판독해 능력·시간·불확실 응답을 먼저 확인한다.

우선 과제는 한 종류의 공간 피복/영역과 면적에 집중한다. 준비된 원 관측·유효 라벨·geometry를 검수하는 범위이며 복잡한 전 장면 segmentation을 처음부터 그리는 견적이 아니다. 식생 건강·고사 원인·기후 귀속 등 여러 전문 분야를 이 예산으로 동시에 라벨링하지 않는다. 충분한 공간 정답이 없는 LUCAS 폴리곤 바깥은 미라벨로 남긴다.

## 2. 100만 원과100시간은 구별

2026년 적용 최저시급은10,320원이다. 인건비만 계산해도100시간은1,032,000원이며,100만 원으로 약96.9시간이다. 해당되는 수당·부대비용·플랫폼 수수료 등을 포함하면 가용 작업시간은 더 줄어든다. 이는 임금 기준의 산술이며 EO 전문 판독의 시장 단가를 의미하지 않는다. [최저임금위원회](https://www.minimumwage.go.kr/main.do), [고용노동부 고시 안내](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18144)

아래 단가는 **우리의 계획 가정이지 수락된 견적이나 확인된 채용 시세가 아니다.** 실제 총비용이 초과하면 물량·시간을 줄이며 총액 상한을 지킨다.

| 항목 | 계획 산식 | 금액 |
|---|---|---:|
| 교육받은 판독자2인 | 각30시간, 합60인시 ×12,000원 | 720,000원 |
| 원격탐사 전문가 | 4시간 ×40,000원 | 160,000원 |
| 부대비용·수수료·재작업 예비 | 정액 상한 | 120,000원 |
| 합계 | 사람 총64인시 + 예비비 | **1,000,000원** |

전문가가 이 조건에 확보되지 않으면 확보됐다고 가정하지 않는다. 실제 자격과 협의된 총 단가를 반영해 재산정하고, 교육받은 판독자 검수를 전수 전문가 gold로 표현하지 않는다. GPU는 기존 연구 자원을 사용하는 전제이며 학습 연산·개발 노동의 총비용은 위100만 원에 포함되지 않는다. 별도 API 사용도 미집행이며 예비비와 중복 지출하지 않는다.

## 4. 60인시 작업표와4인시 전문 검토

| 판독자 업무 | 계획 가정 | 인시 |
|---|---|---:|
| 교육·train측20개 유료 pilot·지침 보정 | 총 배정. pilot은 잠금 test로 이동하지 않음 | 8 |
| 평가120개 독립2인 판독 | 120 ×2 ×8분 /60 | 32 |
| 학습180개 AI 초안 검수 | 180 ×1 ×4분 /60 | 12 |
| 개발60개 AI 초안 검수 | 60 ×1 ×4분 /60 | 4 |
| 오류 점검·재작업 여유 | 총 배정 | 4 |
| 합계 | 두 사람 시간의 합 | **60** |

전문가4인시는 지침 검토1시간, pilot 검토1시간, 어려운 불일치 조정2시간의 가정이다. 마지막2시간은 사례당10분이면12건 정도다. 그 이상으로 전문 조정이 필요하면 예비비/학습 검수 시간을 재배분하거나 unresolved로 기록한다. 두 판독자도 회의에 참여하면 그들의 시간도 별도로 차감한다.

예상 산출물은 **train200개(보정 pilot20+본 검수180), dev60개, test120개**다. train/dev는 AI 초안을 이용한 human-checked 자료이며 test는 모델 답을 보지 않는 이중 판독 자료다.380개를 전수 전문가 gold로 부르지 않는다. 시간은 실측 전 가정이며 보장 물량이 아니다. 실제로 한 사람당12분이 필요하면 같은32인시에서 test는80개가 된다.

pilot 결과로 물량과 표집을 최종 고정하되 최종 모델의 성능을 보고 쉬운 사례만 선택하지 않는다. 적어도 test는 여러 독립 지역을 포함하도록 먼저 분할하며, 사이트 수·사건 수·crop 수를 별도 공개한다. 과제별 최소 지역 수와 허용 오차는 자료를 확인한 후 정한다.

## 5. AI를 활용할 작업

1. **기존 공개 정답을 먼저 연결한다.** 현장·지도 자료의 관측일·좌표·유효 영역을 감사한다. 원 라벨은 생성형 모델이 만든 라벨과 출처를 구분한다.
2. **AI가 영역과 짧은 구조화 답을 제안한다.** SAM 계열의 영역 초안, EO 분할 모델, VLM의 설명을 사용할 수 있다. SAM이 만든 영역이 산림인지 고사목인지까지 참이라고 가정하지 않는다. 면적은 검증된 좌표계와 유효 mask로 프로그램에서 계산한다.
3. **모델 비교로 학습용 검수 큐를 만든다.** 서로 다른 모델의 불일치·숫자와 mask의 모순·판독 불가 사례를 우선한다. 모델이 합의한 사례도 무작위로 검수해 공통 오류를 찾는다. 불일치 표본의 오류율을 전체 corpus 오류율로 보고하지 않는다.
4. **사람은 확인·수정·판단 유보를 기록한다.** 원 초안, 수정 내용, 작업 시간, reviewer, 정답 적용 범위를 남긴다. 긴 설명을 새로 쓰는 노동보다 위치·수치·관측 가능성을 검증하는 데 집중한다.
5. **평가용 자료에서는 모델 답을 숨긴다.** 두 사람은 각자 원 관측과 허용된 출처만 보고 판단한다. AI-generated answer/다른 판독자의 답/모델 이름은 보여주지 않는다. 공개 참조 라벨을 검증한 평가와 새로 독립 판독한 평가를 provenance에 구분한다.

[Label Studio 공식 문서](https://labelstud.io/guide/predictions)는 정적 AI 예측을 불러와 사람이 검수하는 작업을 지원한다. [Community 문서](https://labelstud.io/guide/ml)에 따라 직접 정렬한 큐를 사용할 수 있어 처음부터 유료 자동 active-learning 기능을 전제하지 않는다. 실제 설치·서비스 노출은 이번에 하지 않았다.

[EO에서 SAM을 평가한 WACV 연구](https://arxiv.org/html/2304.13000)는 대상·해상도에 따른 한계를 보여준다. 정답 mask로 생성한 모의 클릭 실험을 실제 검수자의 시간 절감률로 읽지 않는다. [SAMRS](https://proceedings.neurips.cc/paper_files/paper/2023/file/1be3843e534ee06d3a70c7f62b983b31-Paper-Datasets_and_Benchmarks.pdf)는 기존 탐지 라벨에서 많은 mask를 생성한 선행이며, 자동 확장의 가능성과 전문가 gold를 구분해야 함을 보여주는 사례다.

## 6. 연구 규모와 평가의 한계

공개 정답과 AI 보조 학습 corpus는10k→100k 이상으로 확장할 수 있는 설계를 유지한다. 사람 검수비100만 원이100k 학습의 총 연산비까지 충당한다는 뜻은 아니다. 최초10k는 준비 목표이며 아직 만든 corpus가 아니다.

추가 인간 검수의 효과는 같은 train 관측에서 **0/50/200개 추가 검수 라벨**로 비교한다.0도 기존 LUCAS/CEMS 등 공개 전문 감독은 사용할 수 있다. 동일한 공개 원천·AI teacher·질문 생성·지원 표본을 방법 사이에 공유하고, 제안법만 더 좋은 라벨을 받지 않게 한다. 기존0/300/1,000/3,000 계획은 이번 예산에 적용하지 않는다.

test120개만으로3–5%p 개선을 확증하겠다고 약속하지 않는다. 독립 표본이라고 가정해도 정확도75%의 단순 정규근사95% 구간 반폭은 약7.7%p이고, 지역 내 상관이 있으면 더 넓어질 수 있다. 방법 간 paired 비교의 불확실성은 실제 불일치 구조에 따라 별도 계산한다. 공개 대형 평가의 성능과 이 작은 이중 검수 평가의 근거 정확도를 함께 제시한다.

정답을 확정할 수 없는 항목은 사유·분포를 남긴다. 라벨 미정 항목을 모델 오류로 자동 처리하거나 조용히 분모에서 제거하지 않는다. 판독 가능한 부분의 성능과 전체 평가의 정답 확정률을 함께 보고한다. 처음부터 모델이 판단을 유보해야 하는 '관측 불가' 정답과, 사람 사이에 아직 조정이 안 된 '라벨 미정'을 구분한다.

사람이 모델별 문장을 전부 채점하는 대신 공통 공간·수치·관측 가능성 정답을 한 번 만들고 모든 모델을 같은 기준으로 채점한다. AI끼리의 동의율과 AI judge 점수는 보조 진단이며 인간 정답을 대체하지 않는다.

## 7. 다음 실제 작업

원 영상·좌표·기존 라벨이 검증된20개 train 사례로 판독 패키지를 만든다. 작업 범위는 근거 영역/상태/면적·비율의 정답 여부/관측 불가/짧은 설명이다. 원 좌표에서 신뢰할 면적을 계산할 수 없는 사례에는 임의 수치를 넣지 않는다. 사례 난도와 실제 분당 처리량으로100만 원 내 본 물량을 다시 계산한다.

아직 채용된 판독자나 확정된 전문 견적은 없다. 이번 완료는 공개 경로 조사, 예산 계산, AI 활용과 독립 평가 분리, 기존 연구 계획 갱신이다.
