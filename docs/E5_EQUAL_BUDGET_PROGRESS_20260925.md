**완료 갱신: [최종 결과](E5_EQUAL_BUDGET_RESULTS_20260925.md).** 07:47:56 UTC에12모델·26,325응답을 완료하고 CPU checkpoint를 포함한 독립 감사를 통과했다. 등록 주판정은 `mixed_or_inconclusive`다. 아래는 결과 전에 고정한 설계와 실행 이력이다. 이 실험은 E3/E4 이후 이미 노출된 개발 사건에서 수행하는 탐색적 후속 실험이다. 시간 이해·새 사건 일반화·기억 방법의 효과를 검증하는 확증 실험으로 부르지 않는다.

E3에서는 학습이 끝난 reader에 `[A,B,0]`을 넣으면 전부 `no`가 됐다. E4에서는 차이 `D=B−A`만 남겨도 원 답의 95.76–96.36%를 유지했지만, 사전 충분성 기준은 1/3시드만 통과했다. 따라서 다음 질문은 **차이가 없으면 정보가 부족한지, 차이가 없는 형식으로 학습하지 않아 실패한 것인지**다.

## 결과 전 고정한 비교

| 학습 입력 | 조건 |
|---|---|
| `[A,B,D]` | 새 전체 입력 기준선 |
| `[A,B,0]` | 두 관측은 유지하고 명시적 차이만 제외 |
| `[0,B,0]` | 이후 관측 기준선 |
| `[0,0,D]` | 두 관측에서 계산한 차이만 사용 |

모든 조건은 192개 토큰 위치와 타입을 유지한다. 0 입력도 projector의 bias·정규화·타입 임베딩을 거치므로 토큰 위치 삭제와 다르다. D는 A와 B 두 관측으로 계산한 차이다. 두 관측의 절대 정보를 모두 보존한다는 뜻은 아니다.

세 시드마다 동일 초기 가중치를 네 조건에 복제하고, 같은 4,234개 학습 문항·배치 순서·AdamW·3epoch를 사용한다. 모델당 1,590회 업데이트/12,702회 문항 노출, 총 12회 학습이다. 세 초기 가중치와 전체 배치 순서를 최초 학습 전에 저장한다. 마지막 epoch만 평가하며 조기 종료나 좋은 시드 선택은 없다.

12개 모델은 전체 1,755개 평가 문항을 판독한다. 새 전체 입력 모델 세 개는 학습 후 `[A,B,0]`도 판독한다. 합계 26,325개 응답이다. 평가 입력에는 정답 토큰을 넣지 않는다.

## 주 평가와 판정

주 평가는 C1에서 고정한 같은 사건·문구·날짜·슬롯, 양쪽 라벨 피복률 ≥ .90인 902개 문항(양성 445/음성 457, 8사건)이다. 층 안 균형 정확도 → 사건 안 층 평균 → 사건 동일 가중 평균 순으로 집계한다. 시드는 새로운 독립 사건으로 세지 않는다.

유일한 주 대비는 **두 관측 학습 − 전체 입력 학습**이다. 사건 단위 paired bootstrap 5,000회(시드 20260925)를 사용한다.

- 같은 시드에서 두 모델 BA ≥ .60이고 차이 구간 하한 ≥ −.05인 경우가 2/3 이상이면, 이 예산에서 원 라벨 구분 능력 유지로 판정한다.
- 위 조건이 아니고 전체 입력 BA ≥ .60, 차이 ≤ −.10, 구간 상한 < 0인 시드가 2/3 이상이면 이 예산에서 명시적 차이의 이점으로 판정한다.
- 나머지는 mixed/inconclusive다. 실행·입력·응답 무결성 위반은 과학적 음성과 구분해 invalid로 보존한다.

.05/.10은 앞선 탐색 진단에서 이어받은 운영 기준이며 실제 재난 의사결정 비용에서 정한 값이 아니다. 이후 관측·차이 단독·학습 후 제거·재학습 회복은 기술적 보조 비교다.
