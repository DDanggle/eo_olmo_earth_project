# 저비용 EO VLM 연구 경로: 전문가 주석 없이 정답 계약부터 맞춘다

작성일: 2026-09-22. **현재 방법 우위·기억 필요성·CVPR 채택 가능성은 입증되지 않았다.**
이 문서는 v0.5 목표와 이후 실행 조건을 정리한 설계이며, 사람 gold 확보·GPU 학습 완료 보고가 아니다.
MS-155 v0.4의 등록 gate 실패와 원본 코드·답·점수는 보존한다. 실패를 새 정의로 재채점해 성공으로 바꾸지 않는다.

## 1. 비용을 줄여도 남겨야 하는 연구 질문

> 제한된 시각 입력·기억 비용에서, 관측 시각과 영역이 연결된 근거를 보존하는 학습이
> 답만 학습하거나 일반 기억을 쓰는 방법보다 미지 지역의 변화 판단과 근거 정확도를 높이는가?

OlmoEarth 연결, LoRA, 긴 설명 생성 자체가 기여는 아니다. 우선 읽을 수 있는 과제를 만들고,
reader가 실제 영상 내용을 사용하는지 확인한 뒤에만 기억 방법의 필요성을 시험한다.
전문가 인터뷰는 선택적인 문제·용어 설계 보조이며, 반복 주석이나 전문가 지식 전이 효과를 전제하지 않는다.

## 2. v0.5에서 사람이 실제로 판단할 대상

단위는 **같은 ROI의 episode × 공개된 관측 prefix**다. 미래 프레임은 보여주지 않는다.
현재 pilot은 **AOI당 cutoff 하나**이며, ROI는 사분면으로 고정한다. 세부 영역 그리기나 자유 서술 시각 단서 입력 UI는 아직 없다.
질문은 “episode 첫 기준영상과 비교해 새 구조적 변화가 분명히 보이는 첫 제공 관측은 무엇인가?”다.
‘제공 관측’은 검수자에게 실제로 제시한 영상이다. 보지 않은 날짜·월을 답하게 하지 않는다.
월 합성영상의 표시는 관측 묶음의 시간 표지이며, 정확한 물리적 변화 발생일이 아니다.

- **변화 확인:** 첫 확인 관측 ID와 기준 관측 ID를 고정 사분면 ROI에 연결한다. 세부 영역/자유 서술 근거 수집은 후속 확장이지 현재 구현 기능이 아니다.
- **`no_visible_change`:** 해당 prefix의 모든 제공 프레임에서 ROI를 판독할 수 있고 목표 변화가 보이지 않아야 한다.
  “실제로 아무 변화도 없었다” 또는 가린 곳까지 무변화라는 뜻이 아니다.
- **`unreadable`:** 기준/비교 영역을 구름·해상도·입력 결손 등으로 판단할 수 없다.
- **`ambiguous`:** 영상은 볼 수 있지만 목표 변화인지 판별하기 어렵다.
- 작업 시간 초과·UI 오류는 별도 작업 상태다. 이를 `unreadable` gold로 바꾸지 않는다.

**누적 신축 8동 도달 월, 물리적 발생 월, 최초 판독 가능한 변화 관측을 혼용하지 않는다.**
기준영상 자체가 판독 불가하면 기준을 몰래 다른 날짜로 바꾸지 말고 해당 계약의 한계로 기록한다.
이전에 변화가 확인된 뒤 구름 영상이 와도 과거 변화 근거를 삭제하지 않는다.
`과거 변화 확인됨`과 `현재 상태는 알 수 없음`은 동시에 참일 수 있으므로 별도 항목으로 기록한다.

## 3. 공개 데이터와 저비용 사람 검수의 역할

SpaceNet 7의 공개 건물 polygon은 변화 후보 선정·보조 학습용 **silver(자동 파생 참고 정답)**다.
polygon의 출현 시점이 해당 prefix 영상에서 사람이 확인할 수 있는 첫 시점이라고 가정하지 않는다.
목표 장면이 너무 작거나 흐리면 건물 수를 늘려 억지 양성을 만들지 않고 과제 적합성을 다시 본다.

먼저 개발용 소량 episode를 사용자/비전문가가 명시적인 지침으로 검수한다.
검수·교육·재검수·불일치 정리의 합계는 **최대 20인·시간**으로 제한하고, 처리 시간 실측 후 건수를 정한다.
이 예산은 대규모 gold나 방법 우위의 통계적 입증을 보장하지 않는다. 고용·지급·인터뷰는 자동 실행하지 않는다.
양성만이 아니라 무변화·판독 불가·애매한 사례를 포함하고, 모델 정답을 숨긴 상태로 독립 판정한다.
현재 AOI당 cutoff 하나에서 해당 prefix만 공개한다. 향후 다중 cutoff로 확장하면 시간순 공개로 미래 관측의 소급 영향을 막는다.
소량 중복 검수로 지침의 모호함을 찾아 남기며, 합의만으로 현실 정답이 확정됐다고 주장하지 않는다.
개발 검수와 최종 봉인 평가를 분리한다. 문항 수·prefix 수를 독립 AOI/사건 수로 세지 않는다.

## 4. 단계별 실행 조건

1. **계약 확인:** 질문·정답·제공 프레임·ROI가 같은 것을 의미하고, 근거 ID가 실제 prefix 안에 존재한다.
2. **시각 내용 확인:** 동일 항목의 text-only/blank와, 자체 정답을 따로 검수한 영상 교체 쌍을 비교한다.
   다른 영상에 원래 정답을 재사용하지 않는다. 날짜·위치 대조에서도 항목 구성과 실제 내용을 고정한다.
3. **필요할 때만 reader 학습:** 사람이 판독 가능한 사례에서 reader의 실패가 확인된 뒤 진행한다.
   답-only SFT와 답+관측 ID/영역 근거 감독을 동일 영상·문항·모델·학습 자원 상한에서 비교한다.
   학습 step뿐 아니라 총 토큰·GPU 시간·추가 감독 비용도 보고한다. 독립 AOI 검증은 학습에 쓰지 않는다.
4. **그다음 기억 진단:** 내용 통제를 통과한 동일 reader로 full-prefix, latest-K/단순 선택,
   generic memory, 제안 근거 기억을 비교한다. archive 재검색·I/O·초기 인코딩 비용도 계산한다.
5. **언어의 효용 확인:** detector/구조화 기록+단순 템플릿을 필수 비교한다.
   이 기준선으로 충분하면 VLM의 필수성이나 복잡한 기억 모듈의 기여를 주장하지 않는다.

각 단계의 수치 gate·실패 조건·split·예산은 **v0.5 별도 실행 사전등록**에서 실행 전에 고정한다.
이 메모 자체를 사전등록 완료나 실행 승인으로 취급하지 않는다. v0.4 기준을 낮추거나 덮어쓰지 않는다.
gold 계약이 안 맞으면 GPU 확대보다 계약을 고친다. reader 성공과 memory headroom 성공은 별개다.

## 5. 선택적 인터뷰와 공개 범위

인터뷰에서는 사용자가 실제로 묻는 질문, 혼동되는 용어, 어떤 정보가 부족한지를 듣는다.
장면별 반복 판독·긴 사고과정 전사·전문가 정답 제작을 필수 노동으로 요구하지 않는다.
현장 가이드의 전문성과 위성영상 판독 전문성은 구분한다. 실제 경로·눈사태·해상 운항 안전 판단은 제외한다.
녹음·인용·학습 사용·공개 범위의 동의를 각각 확인하고 이름·위치 등 식별정보는 필요한 범위에서 익명화한다.
인터뷰만으로 expert transfer를 주장하지 않는다. 테스트 때 전문가 문서를 주는 RAG와 학습된 전이는 다르다.

## 6. 선행과 산출물의 경계

[HINT](https://arxiv.org/abs/1902.03751)와 [Visual CoT](https://arxiv.org/abs/2403.16999)는
사람의 중요 영역·시각 근거 감독의 직접 선행이다. 그 구성요소를 가져온 것만으로 신규성은 없다.
첫 산출물은 정합된 질문/정답 계약, 소량 visible reference, 재현 가능한 내용 통제다.
그 이후에만 관측 시각·영역 보존의 독립적 효과를 검증한다. 논문 성공이나 학습 이득은 보장하지 않는다.
