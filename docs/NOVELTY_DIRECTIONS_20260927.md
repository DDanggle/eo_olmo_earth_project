## 2. 판단 (교수 의견)

**주 기여: 반사실 증거 학습. 평가 틀: 지금까지 만든 통제 프로토콜. 보조 기여: 효율 frontier. 에이전틱은 다음 단계로 미룬다.**

논문 한 문장 후보:
> *"같은 장소의 서로 다른 날짜는 정답이 공짜인 실제 반사실이다. 이를 음성 예로 써서 고정 EO 기반 모델 임베딩을 읽는 reader를 학습하면, (a) 증거 교체 통제에서 입력 의존이 유지·강화되고 (b) 학습에 없던 지역(italy)·사건에서의 판별이 같은 예산의 표준 학습보다 나아지는가? 그리고 이 reader는 픽셀 EO-VLM(EarthDial, TEOChat) 대비 어떤 비용으로 이를 달성하는가?"*

이유:
1. 방법(반사실 음성)은 일반 도메인에 있지만 **EO에서는 생성 편집 없이 물리적으로 실제인 반사실을 무료 라벨로 얻는다** — 이 점이 CF-VLM·CORAL 류와 다른 설득 지점이다.
2. 이미 만든 모든 것이 부품이 된다: 교체 통제(평가), Italy·홍수 보류 사건(새 지역), 작은 head(“왜 LLM” 대조), EarthDial·TEOChat(픽셀 VLM 대조와 비용 비교).
3. 결과가 음성이어도("지름길은 줄었지만 새 지역 성능은 그대로") 사전등록된 형태로 보고할 수 있다.

## 4. 사전등록할 실험 초안 (E9-CF, 결과 전 확정 예정)

- 팔(3 seed씩): A 표준 / B 표준 + 반사실 4종(같은 장소 교체, 같은 영상 쌍, 역순 — **산사태만**, 홍수는 방향 모호 / 엇갈린 질문) / C 같은 예산 대조(추가 실제 표본·스텝을 같게) / D 작은 head / E 작은 head + 반사실.
- 평가: italy 산사태(963 타일), KuroSiwo 보류 사건, **학습에 쓰지 않은 통제 유형**(다른 장소 교체, 날짜 이동, 사전 영상을 무관한 날짜로 대체, 임베딩 잡음). 학습에 쓴 통제로 평가하는 순환을 피한다.
- 주 판정 후보: B − C가 (a) held-out 통제 민감도에서 ≥ .05 [사건/지역 cluster bootstrap CI > 0], (b) italy BA에서 비열등(−.01 이내) 또는 우위.
- 라벨 감사: 엇갈린 질문 음성 50개 육안 확인(홍수→산사태처럼 실제로 yes일 수 있는 경우).
- 비용 측정(보조): 질의당 토큰·FLOPs·지연, km²당 저장(float32/int8, 패치 풀링), EarthDial·TEOChat과 같은 문항에서.

## 5. 에이전틱을 미루는 이유

AlphaEarth 에이전트와 OlmoEarth-Agent가 "임베딩 저장소 위 에이전트"를 이미 차지했고, 새로 만들 것(벤치·도구·픽셀 에이전트 기준선)이 많다. 반사실 학습 reader가 성공하면 그 reader가 에이전트의 **검증된 도구**가 되므로, 에이전틱은 그 다음 논문의 자연스러운 확장이다.

## 6. 갱신(같은 날) — 사용자 판단: "반사실 학습만으로는 의미가 약하다, 더 넓게 스케일업"

**채택: EO 기반 모델의 LLM 판독 가능성(language readability) 벤치마크 + 스케일링 (R-ZOO).** 반사실 학습은 이 벤치마크 안의 한 개입(팔)으로 내린다.

- 신규성 조사(약 18 질의): 가장 가까운 선행은 일반 도메인 **Cambrian-1**(LLM을 probe로 20+ 비전 인코더 비교), Prismatic, LLaVA-MORE, SAIL(고정 비전+고정 LLM 정렬 probe), Web-SSL(언어 없는 SSL 인코더의 VLM 스케일링). EO에서는 단일 인코더(BigEarthNet.txt, AlignJEPA)이거나 LLM 없는 목적함수 비교(GeoMeld)뿐 — **EO 기반 모델 여러 종을 LLM 판독으로 비교한 선행은 찾지 못함**(GeoChat·LHRS-Bot·SkySenseGPT·EarthGPT·Falcon의 부록 ablation은 미확인).
- 우리만의 것: (1) 다중분광·시계열 EO FM과 임베딩 제품을 LLM이 읽는다, (2) **판독 가능성 = 정확도 + 증거 의존**(교체 통제·같은 예산 blind — EO에서 없음), (3) 크기·언어 감독량 스케일링. EO에는 언어 정렬 다중분광 인코더가 거의 없으므로 "MAE vs 잠재예측(JEPA) vs 대조"가 LLM 판독에 어떻게 다른가는 **열린 질문**이다.
- **가장 큰 위험**: LLM 판독 순위 = 선형/MLP probe 순위이면 논문이 무너진다. → 모든 칸에 head(probe)를 같이 두고 순위 상관을 주 결과 중 하나로 보고.
