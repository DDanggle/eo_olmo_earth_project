# CVPR 한 편의 중심 주장 선택: A를 먼저 논문화하기보다 B를 좁혀 검증한다

검토일: 2026-09-22. 사용자 첨부 비평과 공개 선행을 대조한 **연구 방향 권고**다.
새 방법의 우위·신규성·채택 가능성이 입증된 것은 아니다. 새 학습, 서버 실행, 사전등록 변경 없음.
첨부 안의 R1 실행 제안은 인용된 제안이지 이번 사용자의 실행 지시가 아니다.

## 1. 권고

연구적 의미를 우선한다면 **B를 좁힌 관측 근거 기억**을 첫 번째 검증 대상으로 선택한다.
A의 BigEarthNet 언어 정렬은 필요한 경우의 부품 학습으로 남기고, A 논문 완성을 B의 선행 조건으로
두지 않는다. 직전 다중 현상 설계의 물리·예측·언어 전체는 장기 로드맵이며 한 편의 필수 사양이 아니다.

한 문장 가설:

> 불규칙하고 부분적으로 가려진 동일 지역의 관측 스트림에서, 지리적으로 대응되는 전후 증거를
> 보존하는 기억은 일반적인 영상 요약·검색보다 같은 예산에서 변화 질의의 답과 근거를 더 잘 유지한다.

학습할 핵심은 **어떤 영역의 어떤 전후 증거를 남기고 교체할지 결정하는 모듈 하나**다.
논문 가제는 `Grounded Change Memory for Earth Observation Streams`.
실제 오류 정정 gold가 충분히 확보되기 전에는 제목에서 belief revision을 강하게 주장하지 않는다.

이는 B가 A보다 채택 확률이 높다는 수치적 예측이 아니다. 사용자가 추구한 시간·지역·언어 연구에
더 맞고, 성공했을 때의 기여가 명확하다는 판단이다. B도 아래 작은 진단에서 중단될 수 있다.

## 2. 첨부 비평 중 동의하는 부분과 정정

동의: 슬럼/도시 형태를 동기로 쓰면서 유럽 10m 토지피복만 평가하는 불일치, encoder 교체의 약한
신규성, 독립 근거 gold 부족, A/B를 별개의 본체로 구분해야 한다는 지적은 타당하다.

그러나 A가 더 안전한 CVPR 경로라는 결론에는 다음 문제가 있다.

1. **42.7%의 의미.** 로컬 결과는 전체 MCQ 중 국가·계절·기후 문항의 비율과 해당 메타 필드를
   제공했을 때의 조회 정답률이다. 전체 annotation의 42.7%도, 기존 VLM 의존도도 아니다.
   저자는 Table 4에서 국가·계절·기후를 이미 별도 보고하며, §4.1 입력 설명은 영상과 instruction이다.
   정답 metadata를 추가 입력한 우리 설정의 위험을 데이터셋 저자의 결함으로 바꾸면 안 된다.
2. **가까운 선행.** RS-InternVL은 실제로 S1/S2 encoder·projector·LLM LoRA를 결합한다.
   과제별 train+validation 튜닝이므로 다른 split/국가 holdout의 수치와 동등 조건인 척 비교하지 않는다.
   [BigEarthNet.txt §4.1, Table 4, §4.2](https://arxiv.org/html/2603.29630).
3. **12-band 대 RGB는 진단이지 생사 판정이 아니다.** frozen encoder의 결손 밴드 처리, 정규화,
   학습 분포, adapter 최적화가 결과에 영향을 준다. 승리는 그 설정의 추가 밴드 효용이지 memory나
   source-aware 방법의 신규성이 아니며, 패배도 EO VLM 전체의 가치 부정이 아니다.
4. **메타정보 불변성만으로는 부족하다.** 명백한 영상 사실은 잘못된 맥락에 흔들리지 않아야 하나,
   유효한 계절·기후 정보가 애매한 해석을 돕는 것은 정상이다. 모든 맥락을 무시해도 통과하는 시험을 피한다.
5. **질문 유형으로 붙인 evidence_kind는 근거 사용의 정답이 아니다.** presence=관측으로 자동
   라벨링하면 질문만 보고 유형을 맞힐 수 있다. 지도 파생 정답의 출처와 모델이 실제 사용한 근거는 다르다.

A를 독립 논문으로 택하려면 ‘유용한 외부 맥락은 활용하면서 틀리거나 오래된 기록에는 저항한다’는
trade-off를 실제 모델 실패와 독립 사람 gold로 먼저 입증해야 한다. 단순 BEN VQA 학습의 비용이
작다고 이 문제의 gold 구축과 방법 검증도 작아지는 것은 아니다.

## 4. EO 밖의 선행까지 비교해야 한다

- **FluxMem, CVPR 2026**: 학습 없는 시공간 계층 압축. 공개 models/evaluation 코드 경로를
  확인했다. 단순 최근 K장보다 훨씬 강한 필수 기준선 후보다.
  [논문](https://arxiv.org/abs/2603.02096), [공식 코드](https://github.com/ShareLab-SII/FluxMem).
- **SelectStream, 2026 preprint**: 고정 예산, 동적 latent evidence graph, 선택적 쓰기/검색,
  frozen VLM에 근거 token 주입, 시간 근거 평가까지 이미 다룬다. ‘무엇을 기억할지 학습한다’는
  제목만으로는 차별화되지 않는다. [원문](https://arxiv.org/html/2606.16353).
- **LatentStream, 2026 preprint**: 질문 전의 고정 예산 기억과 질문 후 latent memory 갱신을 다룬다.
  query-agnostic이라는 속성만으로도 새롭지 않다. [원문](https://arxiv.org/html/2609.04131).
- **LongEarth-R1, 2026 preprint**: EO 장기 시계열의 프레임·영역 근거를 포함한다. 동일 시점까지의
  전체 관측을 넣어 재계산하는 기준선으로 중요하다. [원문](https://arxiv.org/html/2608.13344).

위 논문의 설명과 보고 결과를 확인했으나 이 환경에서 재현하지 않았다. 공개 코드 유무, 해당
기능의 실제 online 경로, metadata/encoder 지원 여부를 실행 전에 검증한다. 미공개 방법을
재구현하면 reference implementation이라고 정확히 표기하고 저자 공식 결과와 구분한다.

남아 있는 가설은 **시공간적으로 대응되는 전후 증거의 보존이 EO에서 특별히 필요하며,
일반 메모리 압축보다 낫다**는 것이다. EO는 다르다는 말로 비교를 면제받을 수 없다.
동일 encoder·reader·학습자료에서 일반 memory에 metadata만 준 강한 대조까지 포함한다.

## 5. 필요한 방법은 JSON schema가 아니라 시각 증거의 선택·교체 규칙

제안하는 기억 단위는 한 프레임의 평균 벡터보다 **동일 영역의 전후 관측 묶음**이다.
원관측 ID, 지리 영역, 날짜/관측 구간, 판독 가능 영역, visual feature를 연결한다.
현재 상태 feature와 과거 사실을 뒷받침하는 원관측 참조는 분리한다.

초기 학습 모듈은 이전 기억과 새 공간 token, 실제 시간 간격, 지역 대응, 품질을 받아
영역별 evidence unit의 유지/추가/교체 우선순위를 출력한다. 새 GNN/ODE/대형 LLM을 동시에 만들지 않는다.
LLM은 기억의 visual token과 근거 참조를 읽는다. detector 점수의 템플릿 문장만 받는 구성과 비교한다.

감독은 정답 문장만이 아니라 **필요한 전후 근거 집합과 영역의 보존**을 포함한다. 여러 관측이
서로 대체 가능한 근거라면 유효 집합들을 허용한다. 한 gold frame ID만 강제해 동일한 증거를 벌하지 않는다.
증거를 제거/교체할 때 답과 보류가 적절히 달라지는지도 시험한다.

질문 전 memory write는 미래 질문을 모르게 한다. 질문은 각 prefix에서 이후 주어지고,
동일 memory snapshot으로 여러 미리 보지 않은 조건·영역 질의를 평가한다.
query-aware search는 read 단계에서만 사용한다. 평가 정답으로 selector를 학습시키지 않는다.

### 가장 중요한 구분: 지표 변화, 지식 갱신, 가림

- 새 건물이 실제로 생김 → 현재 지역 상태 변화.
- 처음에는 판독 불가였으나 새 근거로 확인됨 → 지식/확신 갱신.
- 새 영상이 흐려짐 → 현재 판독 가능성 감소. 과거 관측 사실을 삭제할 이유는 아님.
- 이전 침수 뒤 물이 빠짐 → 실제 회복. ‘과거 침수가 없었다’는 반박이 아님.
- 같은 장소·같은 시간에 대한 이전 해석이 잘못됐다는 충분한 증거 → 진짜 오류 정정.

특히 ‘과거 사실을 보존한다’와 ‘현재도 그 상태라고 확신한다’는 다르다. 흐린 새 영상에서는
마지막 확인 시점을 유지하면서 현재 상태의 불확실성/정보 노후화를 표시해야 한다.
무조건 답을 안 바꾸는 모델을 안정적이라고 보상해서는 안 된다.

## 6. 최소 데이터 원칙

우선 **공개 시계열 한 종의 개발 pilot + 독립 출처 한 종의 확장**으로 시작한다. 권장 우선 후보는
SpaceNet 7의 월별 건물/영역 변화다. 공간 footprint와 시간별 주석으로 근거 후보를 만들기 쉽다.
다만 월별 mosaic이므로 월/제품 구간 수준의 순차 평가이며 실제 촬영일 단위 online 확인 지연이 아니다.
[SpaceNet 7 공식 자료](https://spacenet.ai/sn7-challenge/).

더 중요한 제약: SpaceNet 주석은 보조 고해상도 영상과 시계열 검토를 이용한 ‘omniscient labeling’이다.
따라서 building polygon의 존재가 그 prefix의 입력 영상에서 사람이 확인할 수 있다는 뜻은 아니다.
world-state 지도와 prefix-visible evidence gold를 분리하고 후자는 독립 검수한다.
공개 라벨 split의 AOI를 이용해 별도 지역 분할을 만들면 공식 challenge test 점수와 구분한다.
[원문 §3.3](https://arxiv.org/html/2102.04420).

두 번째 후보는 DynamicEarthNet의 다양한 토지피복 변화다. 미래 gap-fill과 월 composite의
가용 시점이 해결되지 않으면 회고적 평가만 하며, 원시 관측 replay로 바꾸기 전에는 real-time
수준 주장을 하지 않는다. [원문 Appendix A](https://arxiv.org/html/2203.12560).

SpaceNet의 건물 단위를 OlmoEarth 40m token에 억지로 맞추지 않는다. 적절한 VHR encoder 또는
집계 영역으로 pilot을 만들고, native S2의 효용은 센서 계약이 맞는 데이터에서 별도로 시험한다.
OlmoEarth의 필수 우월성을 증명하는 논문과 기억 방법 논문을 같은 필수 주장으로 만들지 않는다.

기존 4사건·15관측 자료는 개발 진단에 재사용하되 untouched 외부 검증으로 세지 않는다.
QFabric/TEOChat/LongEarth의 기존 QA는 reader sanity check에 쓸 수 있지만, 새 prefix의
유지/수정/보류 gold를 대신하지 않는다. 출처 중복과 AOI 중복도 검사해야 한다.

언어 train은 공개 mask/trajectory에서 생성하고, 평가에는 사람이 prefix만 본 독립 주석을 붙인다.
같은 장소의 최종 mask를 이전 모든 시점에 복사하지 않는다. 구름 합성 시험은 stress test로
표시하며 실제 흐린 관측 평가를 대체하지 않는다. human label 예산은 학습보다 먼저 확보한다.

## 7. 큰 학습 전에 해야 할 단 하나의 결정 실험

**같은 reader에서 어떤 근거를 주느냐가 정말 병목인가?**

소규모 독립 AOI/episode와 여러 cutoff에서 다음 조건을 비교한다. 첫 진단 기간을 7–10일로
제안하지만 데이터 접근·검수 인력·throughput을 측정하지 않았으므로 완료 보장이 아니다.

1. 현재까지의 전체 prefix.
2. latest/uniform/quality+diversity top-K.
3. 같은 reader와 budget을 쓰는 일반 streaming memory.
4. 사람이 지정한 충분한 근거 집합을 주는 **privileged evidence selector**.

4는 미래 관측을 사용하지 않지만 질문과 gold 근거를 알므로 배포 가능한 causal writer가 아니다.
고정 reader에서의 선택 개선 여지를 진단할 뿐 이론적 상한이나 학습 가능성 증명이 아니다.

판정:

- 충분한 근거를 줘도 답/영역이 틀림 → reader/시각 접지가 병목. memory 학습부터 하지 않는다.
- 충분한 근거와 단순/일반 memory가 동률 → 새로운 selector의 개선 여지가 작다. 이 방법 주장을 중단한다.
- 일반 memory가 근거를 잃고 privileged evidence에서 답과 근거가 회복됨 → learned selection의 검증 가치가 있다.
- 정상 budget에서는 차이가 없고 극단적으로 작은 K에서만 차이 → 운영 의미를 다시 검사한다.
- 사람끼리도 정정/근거 gold가 일치하지 않음 → 라벨/과제 정의를 먼저 고친다.

기억 크기만 줄인 인위적 문제를 만들지 않도록 실제 token/byte·질의 빈도·누적 관측 길이에 따른
비용을 보고한다. 외부 원본 archive에 공짜로 재접근하는 비교는 허용하지 않으며 모든 방법의
archive 접근권·I/O 비용을 동일하게 맞춘다.

## 8. 본 실험에서 필요한 네 가지 증거

1. **실패 메커니즘:** 일반 memory가 언제 전후 근거를 잃는지, 구름/registration/오래된 관측과
   관계가 있는지. ‘구름에 약할 것’이라는 추측이 아니라 baseline 실측이어야 한다.
2. **방법 이득:** 같은 encoder/reader/budget에서 제안 모듈이 generic memory와 deterministic
   top-K보다 답·근거·영역의 joint score를 개선. backbone 교체 이득과 분리한다.
3. **선택적 갱신:** 유효 증거에는 반응하고 무관/흐린 관측에는 부당한 철회를 줄인다.
   last-observed fact와 현재의 불확실성을 함께 평가한다. 진짜 오류 정정은 별도 subset이다.
4. **일반화·비용:** 지리적으로 분리된 출처에서 같은 공유 weights를 검사하고 정확도–비용 곡선을 낸다.
   단위는 AOI/event이고 paired 차이의 cluster CI를 사용한다. 초기 인코딩·원본 읽기·갱신·질의 모두 포함한다.

강한 구조화 대조도 둔다: 학습한 분할/추적 모델 → 변화 ledger → 질의 처리/템플릿.
정해진 변화 label을 자연어로 바꾸는 데만 VLM을 쓰지 않도록, 미리 공개한 평가 범위 안에서
학습에 없던 영역·시간 조건·관계의 조합 질의를 포함하고 동일 근거로 비교한다.

full-prefix가 높은 정확도를 내더라도 같은 정확도를 더 적은 비용으로 유지하면 의미가 있다.
반대로 비용은 비슷하고 QA만 작은 폭 올랐거나, 답은 맞지만 근거가 틀리면 주장 범위가 약하다.
LLM-judge의 유창함 점수보다 구조화 claim과 실제 시각 근거를 우선한다.

## 9. 일정·기존 실패·대안에 대한 현실적인 판단

공식 CVPR 2027 등록은 **2026-11-10 AoE**, 본문 제출은 **2026-11-16 AoE**다.
현재부터 약 8주라는 가정은 이번에 공식 확인했다. 그래도 A 또는 B가 완성된다는 보장은 아니다.
[공식 CFP](https://cvpr.thecvf.com/Conferences/2027/CallForPapers).

기존 실패를 ‘잘못된 버전’이라는 말로 무효화하지 않는다. 특정 프로토콜 결함을 고친 뒤에도
간단한 기준선을 이기는지 새로 입증해야 한다. 이전의 ‘관측 2개 필수’와 ‘규칙이 VLM보다 강건’도
9/20 감사에서 범위가 축소되었다. 보편 법칙이나 이번 방법의 양성 증거로 재사용하지 않는다.

현재 순서는 **B의 병목 진단 우선 → 통과하면 B 한 편에 집중**이다. 실패하면 자동으로 A가
CVPR 방법 논문이 되는 것이 아니다. A의 실제 source-conflict 실패를 별도로 검증하거나, 독립적으로
가치 있는 benchmark 결과를 충분히 확보했을 때만 그 기여로 방향을 바꾼다.
기한을 맞추려고 모든 실패를 묶어 큰 모델/벤치마크라는 이름으로 바꾸지 않는다.

이번 권고는 실행 사전등록이 아니다. 시작하기로 결정하면 데이터 contract·주요 metric·유의미한
개선 폭·CI·budget·중단 조건을 별도 등록하며 기존 실험의 문턱은 그대로 보존한다.
