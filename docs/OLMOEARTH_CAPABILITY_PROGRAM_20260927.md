# OlmoEarth의 응용 능력을 확장하는 모델·학습 연구

> 후속 상세 설계: [CVPR 2027 연구계획·독립 검토](CVPR_2027_OLMOEARTH_RESEARCH_PLAN_20260927.md). 이 문서는 초기 큰 방향의 이력이다. 최신 계획은 generic/specialist 대조, 실제 VLM primary, v1.2,21 core+12 보조 비용과 미실행 상태를 명시한다.

2026-09-27 사용자 방향 반영. **목표는 아직 구현·입증 전이다.** 기존 OE1 학습과 OE2 센서 비율 진단은 개발 근거로 보존한다. 이번 변경은 큰 연구 목표와 첫 실행 준비를 연결하며, 원 실험의 판정·사전등록을 바꾸지 않는다.

## 1. 최종 목표와 encoder 평가의 역할

최종 산출물은 **OlmoEarth의 원 관측 표현을 활용해 영역 찾기·측정·비교·설명을 수행하고, 새로운 대상에도 적은 교정으로 확장되는 모델과 학습법**이다. 사용자는 native EO 관측, 질문 또는 예시 영역을 넣고 결과 영역·수치·관측 근거가 연결된 답을 받는다.

예: 새 피복 유형의 예시 영역을 소량 제공했을 때, 그 유형이 있는 지역을 검색하고 위치를 표시하며 피복 비율을 구하고 다른 지역과 비교할 수 있는가? 시간 변화는 실제 관측 날짜와 정합된 변화 정답이 확보된 자료에서 같은 능력을 확장한다.

Encoder-only 평가는 학습의 효과가 OlmoEarth에 남는지와 재사용성을 확인하는 **기여 귀속 평가**다. 연구의 유일한 결과나 전체 모델 기여의 유일한 통과 조건으로 두지 않는다. 다음 결과를 구별해 보고한다.

- 전체 모델의 능력이 좋아지고 encoder만 새 판독기에 옮겨도 이득이 남으면 표현과 시스템 양쪽의 개선 근거다.
- 전체 모델의 능력은 좋아지지만 새 판독기 전이 이득이 없다면 공동 학습된 시스템의 개선이다. 이를 범용 encoder 개선으로 부르지는 않지만 결과를 무가치하게 취급하지 않는다.
- 학습한 QA 과제만 좋아지고 새 지역·개념·작업으로 이어지지 않으면 범용 모델 주장보다 해당 과제 적응으로 한정한다.

미세조정·지속 사전학습이라는 명칭이나 업데이트한 파라미터 수만으로 기여 규모가 결정되지는 않는다. 여러 과제에서 재사용되는 능력과 그 능력이 생긴 학습 설계를 보여야 한다.

## 2. 함께 설계할 세 부분

| 부분 | 우리가 만들어야 할 것 | 사용자가 얻는 가치 |
|---|---|---|
| 관측 표현과 읽기 구조 | OlmoEarth의 공간·분광·실제 시점·유효 관측 정보를 실제 pretrained VLM과 연결. 영역과 수치, 답변이 공통 관측 근거에 연결되도록 설계 | 한 관측에 서로 다른 질문을 해도 근거를 추적할 수 있음 |
| 여러 작업을 함께 배우는 학습법 | 공개 참조와 전문가 교정으로 확보한 영역·속성·측정 사실을 여러 과제에 공유. 관련 질문의 답과 측정이 일치하도록 학습 | 같은 라벨에서 검색·위치·측정·설명을 함께 배움 |
| 새로운 개념을 추가하는 적응 방식 | 새 대상의 예시·설명·소량 영역 라벨을 받아 기존 능력을 유지하며 적응하는 절차 | 매 응용마다 별도 대형 모델을 처음부터 개발하는 부담 감소 |

이는 제안된 설계 방향이다. 공통 영역 구조, 실제 연결부, 손실 수식은 아직 구현·동결 전이다. 단순히 head 네 개를 붙이거나 토큰 수를 늘리는 것을 신규성으로 삼지 않는다. 제안 방식과 같은 감독을 쓰는 강한 일반 공동학습을 비교해야 한다.

OlmoEarth는 이미 S1/S2/Landsat 및 토지피복·작물·수관 높이 등의 지도 정보를 학습한다. “EO에 처음 의미를 부여한다”는 주장은 하지 않는다. [공식 모델 설명](https://github.com/allenai/olmoearth_pretrain#model-summary). 이전 TerraScope/SPEX 비교와 같은 감독·입력의 통제는 [기존 선행 검토](OE2_TERRASCOPE_COMPARISON_AND_FIRST_VLM_20260926.md)를 따른다.

## 3. 학습과 평가를 두 단계로 연결한다

**A. EO 표현의 지속 사전학습.** 공식 EO 목적을 유지하면서 출처가 확인된 영역·언어·측정 감독을 결합한다. 같은 학습 영역에서 여러 공간 범위와 질문을 구성하되 새로운 사실을 AI가 만들어 넣지 않는다. 부분 판독 영역 밖을 음성으로 채우지 않는다. 모든 비교군에 같은 정답과 관측을 주고, 일반적인 map/measurement 지도학습 및 언어 정렬과 비교한다. 학습량·계산·용량을 함께 기록한다.

**B. 실제 VLM을 포함한 작업 학습.** RGB 시각 경로와 별도 EO 경로를 연결하고, 요청한 영역·수치·근거 설명을 출력하도록 적응한다. 공통 연결부 정렬 이후 encoder를 업데이트하는 조건을 비교하고 저장·복원 경로를 검증한다. B의 전후 checkpoint에서 A의 효과가 유지되거나 사라지는지 확인한다. 원 참조 mask·teacher 정답을 일반 판독 입력으로 넘기지 않는다.

주평가는 전체 모델의 실제 과제 수행이다. 검색 recall, 영역 IoU, 수치 오차, 근거와 맞지 않는 설명, 적은 라벨로 새 개념에 적응하는 성능을 과제별 적격 분모와 함께 보고한다. 요청하지 않은 출력까지 임의로 성공 처리한 통합 점수를 만들지 않는다.

확장성의 결정적 시험은 **같은 새 개념 교정으로 여러 작업이 함께 좋아지는가**이다. 이를 위해 원천 지역/사건을 나누고, 일부 개념×작업 조합을 학습에서 제외하는 평가를 별도로 둔다. 완전히 처음 보는 개념과 기존 개념의 미학습 작업 조합은 다른 설정으로 보고한다. 모든 시스템에 같은 적응 라벨·학습량을 주고, 특정 작업별 미세조정 모델과 총비용도 비교한다. 방법을 정한 뒤 held-out 조합과 성공 기준을 결과 전에 고정한다.

Encoder 단독 평가, 기존 EO 능력 유지, 새로운 VLM으로의 전이는 위 전체 모델 결과를 설명하는 추가 근거다. 외부 원인·기후 영향은 별도 관측과 정답이 필요한 확장이며 지금 공간 피복 라벨에서 생성하지 않는다.

## 4. 사용자가 동의한 첫 준비 작업의 실제 상태

### 원본 EO 기준선

공식 source commit `0497dfbb6711ded4e6bf10cf089fc1e4d58c186b`에서 우선 `sen1floods11`(S1 홍수 분할)과 `m_cashew_plant`(S2 토지피복 분할)의 경로를 확인했다. 이 둘은 기존 EO 능력의 출발점이며, 전체 응용 모델의 최종 benchmark를 대신하지 않는다. 개발은 기존 v1-Tiny를 사용하고 본 모델의 버전·규모는 별도로 고정한다.

공식 CLI parser의 인수만 검증했으며 전체 dry-run이나 baseline 추론은 아직 실행하지 않았다. 다음 호환성 항목이 남아 있다.

1. 기존 공개 `config.json + weights.pth` 형식은 공식 sweep의 distributed-checkpoint 인자와 구별해야 한다. 공식 로컬 loader를 이용하는 연결 코드 또는 검증된 export 후 tensor/출력 동등성을 확인한다.
2. `--defaults_only`는 cashew registry의 정규화 선택을 덮어쓴다. 실제 적용된 설정을 고정해 모든 조건에서 동일하게 사용한다.
3. 준비된 공식 데이터의 경로·split·전처리를 검증한다. 공식 wrapper의 고정 날짜·밴드 보완·tile filtering은 별도 계약으로 남긴다. 이 기준선으로 native-band 완전성이나 시간 추론을 주장하지 않는다.

개발 템플릿은 test 실행을 끄고 validation만 사용하도록 기록했다. [공식 평가 준비물](../artifacts/oe3_capability_program_20260927/official_eval_inventory.md), [기계 판독 설정](../artifacts/oe3_capability_program_20260927/official_eval_inventory.json).

### 원 목적 추가 학습의 공정 비교

현재 BEN S2+yes/no 자료에는 원 학습의 파생 지도 target이 갖춰져 있지 않다. 공식 사전학습 자료 일부의 실제 modality·날짜·target·mask를 감사한 뒤 작은 원 목적 배치를 재현해야 한다. missing target을 만들어 채우거나 원 목적을 바꿔 놓고 동일한 추가 학습 대조라고 부르지 않는다.

기준 비교는 원본 / 원 목적만 추가 학습 / 같은 정답의 일반 지도·언어 공동학습 / 제안 학습이다. 언어 감독 자체의 가치를 주장할 때는 같은 사실을 직접 공간·수치 정답으로 제공한 대조도 포함한다. 최종 연결부와 loss가 정해진 뒤 필요한 중복 대조를 합쳐 실행 수와 비용을 확정한다.

### 이번 서버 읽기 점검

26개 관련 경로와 `.venv-master`의 배포 패키지 metadata를 확인했다. Tiny config와 가중치는 기존 pin과 일치하고 기존 GEO-Bench2 폴더 및 VLM 모델 폴더가 존재한다. 폴더 존재는 데이터 완전성이나 모델 로드 성공을 뜻하지 않는다.

선택한 공식 평가의 예상 `geobench`, `floods`, `research_benchmarks` 경로와 예상 공식 사전학습 폴더는 이번 점검 범위에서 찾지 못했다. GEO-Bench2가 있다는 것만으로 GEO-Bench1 또는 준비된 Sen1Floods11 데이터가 있다고 간주하지 않는다. master 환경에는 minimal 0.0.6 metadata가 있지만 full-pretrain/ai2-olmo-core/geobench metadata는 없었다. 다른 환경·다른 경로까지 모두 없다는 결론은 아니다.

[서버 점검 영수증](../artifacts/oe3_capability_program_20260927/server_inventory_v0.json). 읽기 점검만 완료했으며 이번에 새 모델 학습·대형 자료 다운로드·API 지출은 없다. 보호 대상 기존 네 파일의 해시·mtime이 유지됐다.

## 5. 바로 이어갈 작업과 완료물

1. 별도 실행 환경, 공개 checkpoint→공식 평가 연결, 두 기준선 데이터 계약을 준비한다. **완료물: 원본 모델의 실제 validation 성적표와 재실행 명령.**
2. 공식 사전학습 자료의 제한된 subset을 확보하고 원 목적의 forward/backward/저장 복원을 확인한다. **완료물: 검증된 작은 원 목적 추가 학습 실행.**
3. 같은 관측의 영역·속성·수치를 여러 질문으로 학습하는 방식과 실제 VLM 연결을 구현한다. **완료물: 동일 자료·용량의 일반 학습 대조와 제안 모델의 첫 전체 작업 비교.**
4. 새 개념·지역·작업 조합과 더 큰 자료에서 확장성을 검증한다. 기존 10k→100k→조건부1M 목표를 유지하되, 이는 확보량이나 즉시 실행 수가 아니다. 사람/API 100만 원 예산과 GPU 비용은 구별한다.

첫 두 작업은 큰 모델 연구를 판단할 기반이다. 최종 모델·학습법·평가를 모두 encoder-only 두 과제로 축소하지 않는다.
