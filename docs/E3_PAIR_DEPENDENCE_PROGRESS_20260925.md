## E3가 묻는 한 가지

**입력에 두 시점이 있으므로 모델이 실제로 두 시점을 비교한다고 말할 수 있는가?**

E2 입력은64토큰의A,64토큰의B,64토큰의B−A다. 한 프레임만 지워도 차이 토큰을 남기면 제거한 프레임의 정보가 남는다. 이를 함께 차단하고 token 수192개·type0/1/3·질문 문구·checkpoint는 고정한다.

| 조건 | 모델에 주는 토큰 | 확인할 점 |
|---|---|---|
| real | A, B, B−A | 기존 답 재현 |
| earlier_only | A, 0, 0 | 첫 슬롯만 남긴 민감도 |
| later_only | 0, B, 0 | 둘째 슬롯만으로 원 라벨과의 연관성 유지 여부 |
| repeat_earlier | A, A, 0 | 첫 슬롯 반복 |
| repeat_later | B, B, 0 | 둘째 슬롯 반복에서도 같은 현상이 나타나는지 |
| no_delta | A, B, 0 | 명시적 차이 토큰의 기여 |
| reverse | B, A, A−B | 역순에 대한 반응, 기술통계만 |

반복·역순의 `transformed_gold`는 null이다. 같은 영상이 두 번 보인다는 사실만으로 두 날짜 사이 물리적 사건이 없었다고 판정할 수 없다. 원 질문의 날짜 표현과 조작 내용이 모순될 수도 있다. **변환 입력의 새 정확도가 아니라 원 라벨과의 일치 및 답 변화**를 보고한다.

## 표본과 판정

기존 E2 평가 문항의 ID·metadata만으로 해시 정렬하여 홍수 각 사건 최대8개의 yes/no 타일 쌍, 산사태 각 지역 최대16쌍을 선택한다. Indonesia는 가용6쌍 전부가 상한이다. 기존 모델이 맞힌 항목으로 표본을 고르지 않는다. 홍수의 실제 무침수 hard-negative는 사건별 최대8개를 별도로 real/later_only/repeat_later에서 평가한다.

주 분석은 **홍수 양성 타일의 yes/no paired subset**이다. 사건별 BA를 동등하게 평균하고, 조건 간 차이를 같은 사건끼리 짝지어 사건 단위 bootstrap5,000회로 계산한다. hard-negative FPR는 별도 보고한다. 산사태는 두 지역 수치를 각각 기술하며, 타일 수를 독립적인 지역 수처럼 사용하지 않는다.

- 먼저3seed·2현상 모두에서 real 답이 기존 E2와99% 이상 일치해야 한다. 이 관문 전에는 변환 조건을 실행하지 않는다.
- 유효 입력·checkpoint·projected token, 생성 점수, 문항별 완결성을 확인하고 seed/현상/조건별 parse실패1% 초과는 실행 무효로 둔다.
- 최소5홍수사건과 real macro BA≥.60을 요구한다.
- **같은 seed에서** later_only와repeat_later가 모두 BA≥.60, ΔBA의95%구간 하한≥−.05이고 이를2/3seed가 만족하면 `single_second_view_sufficient_under_intervention`이다.
- 위 조건을 만족하지 않고 **같은 seed에서** 두 조건 모두Δ≤−.10·구간상한<0이며2/3seed이면 `history_sensitive_under_intervention`이다.
- 그 외는 `mixed_or_inconclusive`. 불확실성을 동등함으로 해석하지 않는다.

두 결과 모두 해석 범위는 제한된다. 첫째는 이 고정 reader와 노출된 표본에서 둘째 슬롯만으로 원 라벨을 상당 부분 재현한다는 뜻이다. 둘째도 입력 분포 변화에 대한 민감도일 수 있으므로 시간 추론의 증명은 아니다.
