# CVPR 기여 결정 — 관측 근거를 이용한 교정을 새 환경에 재사용하는 OlmoEarth

> **09/29 실행 갱신: §11 및 [OE11 실행 기록](OE11_REGION_EXPANSION_20260929.md).** 세 지역288입력, 네 대상 통합목록, 실제 로더와 새 비교 head 구현까지 완료했다. 새 성능은 아직 없다.

> **09/28 우선순위: §10.** 사용자 요청에 따라 겨울밀은 별도 실패 분석으로 두고 포도밭·콩과 학습과 네 대상/새 지역 확장을 우선한다. §9의 겨울밀 우선 복구 순서는 대체됐으며 원 P2 결과와 프로토콜은 보존한다.

2026-09-28. **수동 연구 갱신이며 방법 성능·신규성 확정·동결 사전등록이 아니다.** 예약은 PAUSED다. 이번에는 선행 조사, 기존 metadata의 CPU 감사, 세 독립 검토와 결정 설계를 수행했다. GPU·서버 실행·새 평가자료 개봉은 하지 않았고, 기존 P2의 조건·상한·판정을 변경하지 않았다.

## 1. 논문의 중심으로 남길 것

**전문가가 알려준 “이것과 저것을 무엇으로 구별하는가”를 학습해, 새 지역에서도 적은 교정으로 원하는 대상을 찾는 OlmoEarth.** 이 이점이 원래 연결부를 버리고 다른 VLM에 연결해도 남는 것이 목표다.

방법 후보는 **교정과 그 교정을 뒷받침하는 관측의 관계를 함께 학습하는 것**이다. 예를 들어 두 필지의 실제 시계열에서 전문가가 관찰한 차이를 알려주면, 다른 지역의 필지에서도 해당 구별이 가능한지 관측을 확인한다. 홍수에서는 신규 침수와 기존 수역을 구분하는 전후 관측이 대응하는 예다. 후자의 정답과 전후 입력은 아직 확보되지 않았다. 지역 상식이나 작물의 연간 라벨이 특정 생육·수확 사건의 정답을 대신해서는 안 된다.

이것은 연구할 가치가 있는 가설이며 **아직 새로운 방법을 확보한 것은 아니다.** 일반 소수 예제 학습·관계 학습·선택적 예측의 조합으로 설명될 위험이 있다. 동일 정보의 강한 일반 방법을 이기고, 효과가 OlmoEarth에 남는 것을 보여야 CVPR 방법 기여로 논의할 근거가 생긴다. 채택 확률을 계산할 근거는 없다.

## 2. 이미 존재하는 것과 남는 질문

저자 논문·공식 자료를 확인한 비교다. 보고 성능을 우리 환경에서 재현한 것은 아니며, 검색에서 못 찾은 것을 최초성의 증거로 쓰지 않는다.

| 확인한 선행 | 이미 있는 내용 | 단독 기여로 쓰기 어려운 주장 |
|---|---|---|
| [TerraScope v1, 2026-03-19](https://arxiv.org/html/2603.19039v1) | 영역·언어·측정과 다중시점/센서 활용 | 위치와 설명을 함께 내는 EO–VLM |

| [MS-CLIP v3](https://arxiv.org/html/2503.15969v3), [DOFA-CLIP v2](https://arxiv.org/html/2503.06312v2) | 다중분광/센서 언어 정렬, 지역정보 또는 공간 표현 보강 | 센서와 언어 정렬·표현 보존의 결합 |

| [SegEarth-R2](https://arxiv.org/html/2512.20013v1) / [CVPR 2026 저자 저장소](https://github.com/earth-insights/SegEarth-R2) | 복잡한 지시·다중 대상·추론을 포함한 언어 분할 | 질문 종류를 늘렸다는 주장 |
| [Geo-R1: Few-Shot Referring](https://arxiv.org/html/2509.21976v1) | 소수 라벨 referring/segmentation 및 cross-dataset 평가 | 적은 라벨로 VLM 적응 |
| [Rußwurm·Sherrie Wang 등, 2020](https://arxiv.org/html/2004.13390v1) | EO 지역 다양성에 대한 MAML 소수 예제 적응 | 지역별 episode 자체. 다만 같은 지역 support/query와 A→B 무추가교정 전이는 구분 |
| [QMTN, 2026](https://doi.org/10.1016/j.patcog.2025.112331) | hyperspectral few-shot과 관측 조건 모사 meta-task | EO 관측 변화와 meta-learning의 결합. publisher 색인 확인이며 전체 PDF 검증은 아님 |

OlmoEarth도 [공식 embedding 활용 예](https://allenai.org/blog/olmoearth-embeddings)에서 검색과 소수 pixel 분류를 보여준다. 따라서 **OlmoEarth에 few-shot과 VLM을 붙인 것만으로는 부족하다.** TerraScope보다 모듈이 많은 것이 차별점도 아니다. 남길 질문은 *교정으로 배운 구별이 얼마나 잘 전이하고, 그 효과가 어디에 저장되는가*다.

## 3. 이번에 실제 확인한 입력 문제

[CPU 감사 코드](../code/audit_oe10_context_identifiability.py)와 [해시 포함 결과](../artifacts/cvpr_direction_update_20260928/context_identifiability_audit.json)를 만들었고 독립 재실행 결과가 일치했다. 기존 회수 metadata만 사용했다.

| 확인 | 의미 |
|---|---|
| 384항목 = 48 query × 2방향 × 4K | 독립 영상/사람 교정 384개가 아님 |
| Qwen 고유 입력 문구 7개 | 현재 고정 텍스트 벡터를 7개 lookup으로 대체 가능. 의미가 쓸모없다는 뜻이 아니라 class code와 지식 이해를 식별하기 어려움 |
| 두 source parent마다 날짜 일정 고정 | 날짜쌍으로 지역 식별 가능. 실제 모델의 이용 여부는 미측정 |
| 포도밭/콩과 동시 존재9/48, 둘 다 부재23/48 | 양성 구별과 대상 부재를 별도로 평가해야 함 |
| K1 support96행 중83행이 같은 parent | support의 지역별 수·다양성 불균형 |
| 현재 v2 Qwen은 텍스트만 읽음 | 일반 텍스트 조건 분할 baseline이며 EO 관측을 읽는 VLM 방법은 아직 아님 |

EO 특징의 날짜/그룹 평균, support 객체 평균도 확인했다. 그러나 native encoder가 이미 시간 정보를 섞을 수 있으므로 평균이 시간 정보를 완전히 파괴한다거나 현재 성능의 원인이라고 단정하지 않는다.

기존 P2는5/6완료·12시간 상한 종료, 완료5회 모두 안정성 미충족이다. 두 완료쌍 평균 +0.047228은 기술 통계다. 설명 연결 검사는 한 사례·optimizer update0이다. **제안 방법 효과·사람 교정 효율·새 reader 전이는 아직 측정되지 않았다.** [종료 결과와 위치](RESEARCH_STATUS_AND_LOCATIONS_20260928.md).

## 4. 방법 후보 하나와 학습 경로

**학습 단위:** 교정 C = (대상 영역, 혼동 영역, 실제 관찰한 차이, 참조 관측/날짜, 판독 가능 범위). 일반 지역 설명과 그 영상에서 확인된 사실은 별도 필드다. source에서 참인 차이가 모든 target에서도 참이라고 가정하지 않는다.

**공통 구조:** OlmoEarth의 관측 특징을 바로 평균하지 않고 위치·관측별로 참조하게 한다. 표준 attention/head/VLM connector는 기준선과 제안군에 동일하게 제공한다. 이것만으로 해결되면 연결부는 ablation 결과로 남긴다. 새 tokenizer·KV cache·시뮬레이터·RL loop를 추가하지 않는다.

**제안 규칙:** 동일 query에서 교정의 의미와 근거를 바꾼 쌍 사이의 관계를 학습한다.

- 같은 뜻의 재서술, 판단을 바꾸지 않는 배경 정보에는 답을 유지한다.
- 대상/혼동 역할이 바뀌면 새 대상의 정답 mask로 바뀐다. 전체 mask의 반전이 아니다.
- 같은 작물명·문체라도 현재 support 관측과 맞지 않는 설명은 영상 증거를 덮어쓰지 않게 한다.
- 구별 근거를 제거했고 대체 관측도 부족하다는 검수가 있으면 단정을 줄인다. 무관한 날짜 제거에도 무조건 보류하면 안 된다.
- source 환경 사이에서 교정을 재사용하는 episode로 특정 이름/지역보다 관측에 맞는 구별을 학습한다. 최종 평가 지역 정답은 학습에 들어가지 않는다.

구현 가설은 기존 mask·근거 손실에 위 쌍의 출력 관계 항을 추가하는 것이다: L_mask + λL_evidence + γL_pair. 이 수식이나 loss 개수는 신규성이 아니다. **일반 대조에도 모든 쌍·정답·근거·보류 라벨을 주고**, 표준 contrastive·domain meta-learning·calibration/gating과 비교한다. 추가 감독의 효과를 새 규칙 효과로 오인하면 안 된다.

gradient는 OlmoEarth에 들어간다. 학습 후 인코더만 export하고 원 head·connector를 버린 뒤 새 head/reader에 붙인다. 이점이 사라지면 OlmoEarth 재사용성 개선을 주장하지 않는다. 공개 라벨을 쓰는 이 단계는 **사전학습 모델의 추가 학습**이며 처음부터 새 자기지도 사전학습을 한 것으로 부르지 않는다.

**실제 VLM:** 후속 모델은 EO 관측 token과 교정을 함께 받아 영역·날짜를 참조하는 답을 생성해야 한다. 현재 text-only v2와 구분한다. 작은 text encoder+동일 head, 전문 시계열 모델+측정 도구+동일 Qwen을 비교한다. 동등하면 자연어 인터페이스의 가치는 있어도 VLM 고유 시각추론 기여는 미입증이다.

## 5. 방법보다 먼저 필요한 자료

**20개 교정 쌍을 두 사람이 독립 검수하는 pilot**이 다음 산출물이다. 기존20개 품질 PNG는 출발 자료일 뿐 새 교정 과업이 완료된 것이 아니다. 실제 사람 응답0을 유지한다. “관측이 지지/반박/판단 불가”, 근거 영역·날짜, 작성/검수 시간을 기록한다.

같은 작물명·비슷한 문체인데 관측에 따라 참/거짓이 달라지는 사례가 필요하다. 작물명만 읽고 틀렸음을 알 수 있는 설명 교환은 부족하다. 동일 query/support에서 다음을 비교한다.

1. 정확한 관측 설명 / 같은 작물의 다른 사례에서 온 틀린 설명 / 맞지만 구별과 무관한 설명.
2. 이름만 / 익명 class code / 엄격한 무언어 / 의미 보존 재서술.
3. 지역명·좌표·날짜·출처 ID만으로 답하는 대조와, 실제 EO 입력을 사용하는 대조.

여섯 기존 후보와 겨울밀 실패를 유지하고 클래스×지역×support 수×판독 가능성 가용표로 구성한다. 점수로 대상을 선택하지 않는다. source-support를 B지역에 그대로 재사용하는 조건과 B지역 K개 추가 적응은 별도다. 새 지역과 새 개념도 다르다. class/정의 조합을 episodic 학습에서 제외해야 후자를 시험할 수 있으며, 원본 pretraining 미노출까지 보장하는 것은 아니다.

20건 합의만으로 전체 데이터 타당성을 확정하지 않는다. 검수 전에 범주별 수·합의 기준을 기록하고, 합의율·판독 불가율·범주별 혼동과 시간을 함께 본다. 과업이 불안정하면 원인을 수정한다. 설명을 많이 생성해 독립 표본을 늘렸다고 세지 않는다.

**근거 제거의 계약:** 인코딩 뒤 날짜 token만 지우면 다른 token에 정보가 남는다. 원관측을 제외/마스킹해 재인코딩하고 cache를 분리한다. 동일 수의 무관한 관측 제거와 비교하고, 제거→복원 시 교정 효과의 회복도 본다. attention weight나 참조 ID만으로 근거 정확성을 판정하지 않는다. 연간 작물 mask로 시점별 사건·관측 부족 정답을 만들지 않는다.

## 6. 결정 실험과 주장을 접는 조건

아래는 다음 결과 전에 manifest·코드 hash·수치·예산으로 동결할 설계다. **아직 launch-ready protocol이 아니다.** 기존 미완료 P2를 재시작하거나 기준을 바꾸지 않는다.

| 순서 | 비교 / 산출물 | 판정 대상 |
|---|---|---|
| A | 완료한 metadata 감사 →20개 이중 검수·같은 class 내 참/거짓 설명·footprint 독립성 | 과업과 관측 근거의 타당성 |
| B | frozen EO prototype/logistic/MLP, 충분히 학습한 일반 joint, 전문 시계열 모델 | 강한 baseline으로 해결되는 문제인지 |
| C | 동일 관측·구조·감독에서 일반 SFT/contrastive/domain meta-learning 대 제안 paired 규칙 | 추가 자료를 넘는 규칙 효과 |
| D | EO 고정/갱신 × 일반/제안 규칙 네 칸. 주 비교는 갱신 EO의 제안 대 일반 | head와 EO의 효과 귀속 |
| E | EO만 이전, 새 head/다른 reader를 동일 예산으로 학습, 독립 EO 평가 | 인코더에 남는 재사용성 |
| F | 동일 checkpoint·공통 교정 규칙으로 농업과 물/침수의 분리된 환경 | 한 모델의 응용 범위 |

같은 입력·support·라벨·튜닝 기회를 준다. 관측/업데이트를 맞춘 비교와 실제 GPU 비용을 맞춘 비교를 구별한다. 제안만 추가 forward를 받는 비용은 숨기지 않는다. 상한 종료나 불안정 학습은 동등성 증거가 아니다.

주평가는 지역별 target/confuser의 K별 IoU와 곡선 요약이다. 반복 K/문구 행이나 pixel을 독립 표본으로 bootstrap하지 않고 지역/사건 및 support-library 의존성을 반영한다. 겨울밀·대상 부재 오탐·잘못된 설명 피해·비관련 EO 손상을 별도 공개한다. mask에서 계산한 면적과 설명을 세 개 독립 능력으로 세지 않는다.

다음은 확장 투자에 필요한 실용 효과의 **초안 목표**다. CVPR 기준·예상 결과·원 P2의 새 통과 기준은 아니다.

- 새 평가의 강한 일반 대조 대비 K-IoU 곡선 요약 **절대 +0.05 이상**을 목표로 삼고 지역별 불확실성을 함께 본다. 작은 차이는 작은 기여로 해석하고 정밀도 부족은 미정으로 남긴다.
- 보조 목표는 같은 품질의 **교정 수 또는 실제 작성 시간1/2 이하**다. 유리한 정확도 목표를 사후 선택하지 않고 전체 곡선을 보고한다.
- 독립 EO 보존의 예시 허용폭은 0–1 점수 기준 **-0.01**이다. task별 허용폭은 본 평가 전에 근거와 함께 정한다. 비열등+새 reader 재사용과 독립 EO 자체 향상은 다른 크기의 주장이다.
- 보류로 오답을 감추지 않도록 전체 query 품질·응답률·동일 응답률 오류를 함께 본다. 생성문은 실제 근거 영역/날짜와 새 조건 조합의 성공으로 평가한다.

표본 수·지역 수·seed·상한은 개발 분산과 실제 속도를 측정한 뒤 최종 지역 개봉 전에 정한다. 예비 범위 목표는 분야별 미관찰 환경3개 이상이지만 숫자만으로 일반화를 보장하지 않는다. 이미 본 t31tfm은 개발용이다. t30uxv 하나의 성공도 광범위 전이의 증거가 아니다.

**폐기/축소:** 충분학습 일반 방법과 동등하면 새 규칙 주장 철회. class code와 동등하면 지식 이해 미입증. 원 head에만 효과가 남으면 인코더 개선 주장 철회. 관측 쌍을 받은 일반 meta-learning+augmentation+gating과 같은 전이/거절 곡선이면 새 관측 학습 원리라고 포장하지 않는다. 일반 B0≈B2만으로 아직 시험하지 않은 제안 규칙까지 기각하지도 않는다.

## 9. 09/28 수동 갱신: 실제 평균과 언어 기여를 높일 다음 개입

사용자 요청에 따라 완료 로그·점수를 재분해하고 코드/문헌을 독립 검토했다. 새 모델 성능은 없지만 다음 개입의 근거는 구체화됐다. **우선순위는 양성 사례의 학습 확인 → 위치별 개별 교정 비교 → 같은 구조에서 설명의 추가 효과 → 필요한 경우 날짜 확대다.** 아래는 개발 실험 제안이며 동결된 P2의 수정·재시작이나 새로운 launch protocol이 아니다.

### 9.1 평균을 어디에서 잃고 있는가

두 완료 seed의 클래스별 IoU K-AUC 평균을 100배한 값이다. B0는 EO 고정, B2는 기존 일반 공동학습이다. 다섯 완료 실행의 30개 평가창에서 원 주지표가 세 클래스의 산술평균과 일치함을 재검산했다.

| 기존 주평가 | B0 | B2 | 전체 평균 변화에 기여한 %p |
|---|---:|---:|---:|
| 초지 | 52.87 | 58.47 | +1.87 |
| 겨울밀 | 1.45 | 0.94 | −0.17 |
| 옥수수 | 35.24 | 44.31 | +3.03 |
| 세 클래스 평균 | 29.85 | 34.57 | +4.72 |

이는 원래 불완전 비교의 기술 통계다. 전체 5/6 완료·학습 안정성 0/5 충족 상태는 변하지 않았다. 겨울밀을 빼거나 잘 나오는 새 작물로 평균을 바꾸지 않는다. 산술적으로 한 클래스의 K-AUC가 15점 회복되고 나머지가 같으면 평균은 5점 오른다. 이는 예상 상승폭이 아니라 현재 실패를 개선할 가치가 큰 이유다.

겨울밀 양성 train patch 수는 22, 옥수수는 23으로 비슷하다. 반면 양성 픽셀은 35,076 대 75,716이며 B2 마지막 384 update의 겨울밀 양성 mask loss는 두 seed에서 0.575/0.736, 옥수수는 0.176/0.195였다. 겨울밀 부재 loss는 0.001/0.044로 작다. 쉬운 부재 사례·픽셀 불균형·양성 구별 실패를 먼저 분리해야 한다. 이 online loss는 고정 train 정확도가 아니며 원인을 확정하지 않는다. 다른 클래스 양성도 대부분 gradient clipping되어 clipping만으로 겨울밀 실패를 설명할 수 없다.

**첫 개입:** 원 구조·관측·support를 고정한 새 실험에서 사전에 고른 소수 train 양성/혼동/부재 사례를 맞출 수 있는지 검사한다. 이전 두 사례 head fit 통과를 모든 클래스 학습의 증명으로 쓰지 않는다. 원 BCE+Dice와 양성/부재·픽셀 기여를 명시한 균형 loss를 하나씩 비교하고 native/mask/language별 gradient를 측정한다. 표준 multiclass CE용 logit-adjustment를 현재 binary BCE+Dice에 그대로 붙이지 않는다. 원 threshold 0.5와 원 점수는 보존하며 출력 보정은 train 내 별도 calibration 자료와 부재 오탐까지 포함하는 신규 대조로만 검토한다.

### 9.2 설명이 위치 예측에 직접 도움이 되는 경로

현재 P2는 mask를 먼저 계산하고 Qwen이 면적/고정 참조 문장을 학습한다. 후속 v2는 설명→mask 의존성과 EO 기울기만 한 사례에서 확인했다. 긴 설명이나 Qwen 전체 미세조정의 효과는 아직 없다. 현재 head는 양성/혼동 support를 각각 평균하므로 위치마다 어떤 예시가 맞는지 선택할 수 없다.

**최소 구조 변경:** query의 각 위치가 개별 양성·혼동 support와 비교하도록 한다. 역할별 작물명/판별 설명은 이 비교의 query/key 또는 위치별 text 점수에 들어가고, mask 정답으로 함께 감독한다. 영상·support 경로에 텍스트 기여를 더하는 작은 head부터 시작한다. 비정렬 EO와 언어 벡터를 학습 없이 cosine으로 비교하지 않는다. 모든 support에 같은 텍스트 상수만 더하면 softmax에서 소거되므로 문구가 실제 비교 가중치를 바꾸는지도 검사한다.

이는 [DenseCLIP의 위치별 텍스트 감독](https://arxiv.org/html/2112.01518v2), [HDMNet의 query–support 대응](https://arxiv.org/html/2303.14652v1)에서 가져올 수 있는 강한 일반 기준선이다. 이 조합 자체를 새 원리라고 주장하지 않는다. 첫 비교는 query 2날짜·support 영상당 8날짜와 현재 시간 평균을 그대로 두고 개별 support 비교의 효과만 본다. Qwen은 고정해도 head와 OlmoEarth로 기울기가 흐를 수 있다.

| 같은 구조에서 제공할 조건 | 분리할 효과 |
|---|---|
| 무언어 / 같은 차원의 익명 class code | 영상 교정만으로 가능한지, 이름 식별만으로 가능한지 |
| 작물명만 | 이름의 사전 지식 |
| 작물명 + 출처 있는 판별 설명 | 설명의 추가 효과: 반드시 작물명만 조건과 비교 |
| 위 조건 + 검증된 지역·계절 사실 | 일반 작물 설명을 넘는 지역 정보의 추가 효과 |
| 같은 클래스의 틀린/무관한 설명, 의미 보존 재서술 | 실제 관측과 맞는 설명을 쓰고 틀린 설명의 피해를 줄이는지 |

지역명·월·수확 달력을 문장에 길게 넣는 것보다, 실제 제공된 관측의 차이와 설명을 연결한다. 예를 들어 특정 생육 변화가 영상에서 확인된다면 그 날짜·영역을 교정 근거로 붙인다. 연간 작물 mask만으로 수확/고사/가뭄 시점을 생성하지 않는다. 현재 입력에는 검증된 지역 기후/작물 달력이 없으므로 unknown을 유지한다. 지역 사실을 확보하면 같은 정보를 숫자·범주로 제공하는 대조도 둔다. 프랑스 자료에 한국 장마/네팔 몬순 설명을 임의로 넣지 않는다. 사람 교정은 현재 0이다.

**논문 방법 검증:** 위 일반 attention/위치별 텍스트 모델에도 같은 정확/오류/무관 설명과 모든 감독을 준다. 그 위에서 제안한 관측 근거 기반 교정 규칙이 새 환경의 정답률·잘못된 설명 피해·필요 교정 수를 더 개선하는지 비교한다. EO만 새 head/reader로 옮긴 뒤에도 이득이 남아야 OlmoEarth 재사용성 개선 주장으로 연결된다.

### 9.3 시간·지역 정보와 계산 예산

OlmoEarth는 이미 날짜를 사용한다. 현재 head의 시간 평균이 모든 시간 정보를 없앴다고 단정하지 않는다. 개별 support 비교 후에도 시간별 오류가 남으면 같은 두 query 날짜에서 평균, `[z1,z2,z2−z1]`의 일반 MLP, 날짜별 attention을 비교한다. [U-TAE](https://arxiv.org/html/2107.07933v4)는 관측별 집계의 근거가 된다. 그다음 query 2/4/8날짜를 따로 비교하며 추가 관측 효과를 새 구조 효과로 세지 않는다. 각 날짜 수에서도 모든 모델에 같은 관측을 준다.

[TimeMatch](https://arxiv.org/abs/2111.02682)는 지역마다 생육 시기가 어긋날 수 있음을 다루는 구체적 참고다. 실제 시계열 유사도를 중심에 놓고 달력 차이는 부드러운 조건으로 시험할 수 있다. 날짜를 생육 단계 정답으로 취급하지 않는다. 원 TimeMatch처럼 target의 무라벨 자료 전체로 적응하면 그 접근 권한을 명시하고 대조군에도 동일하게 제공해야 한다.

**확인한 비용 개선 후보:** K8의 support 16개는 원 훈련 목록에서 평균 11.990개의 서로 다른 영상·날짜 입력으로 구성된다. 한 forward 내 같은 영상 인코딩을 공유하면 support 호출 수의 25.07%가 중복 대상이다(확장 목록은 27.21%). 서로 다른 mask pooling은 유지한다. 이는 호출 수 감사이며 GPU 속도 향상 실측이 아니다. B0에는 이미 feature cache가 있다. B2는 autograd를 유지한 같은 forward 안에서만 공유하며 optimizer update 사이의 stale cache나 detach를 사용하지 않는다. 실제 가중치의 forward·gradient·한 optimizer step 동치와 시간/메모리를 확인한 뒤 모든 대조군에 공통 적용한다. 방법 신규성으로 세지 않는다.

### 9.4 실행 순서와 이번 완료 범위

1. 고정 train 소집합의 양성/혼동/부재 학습 및 손실별 gradient 진단. 공통 중복 계산 최적화는 실제 동치 검사를 먼저 한다.

3. 통과한 공통 구조에서 이름/판별 설명/지역 사실의 추가 효과, 같은 클래스 안의 틀린 설명 피해를 비교한다. 20개 독립 사람 검수는 학습과 병행 준비하되 사람 입력을 AI 생성으로 대체하지 않는다.
4. 남은 날짜 오류에 대해서만 같은 관측의 시간별 집계, 이후 별도 2/4/8관측 비교. 강한 일반 모델 대비 효과가 남을 때 제안 교정 규칙·새 지역·다른 reader 검증으로 진행한다.

현재 제안 모델 훈련과 생성 설명 평가는 0이다. 정량 비교의 다음 실행 전에는 신규 표본·학습 충분성·예산·중단 기준을 별도 동결한다. 30분 연결 pilot을 충분 학습한 성능 비교로 부르지 않는다. 원 P2 상한을 우회하지 않으며 예약 PAUSED와 기존 예산 장부를 유지했다.

## 10. 사용자 정정 반영: 겨울밀은 별도 분석, 확장을 우선한다

**이 절이 §9의 실행 우선순위를 대체한다.** 겨울밀을 먼저 고쳐야 확장할 수 있다는 순서는 사용자 의도와 달랐다. 겨울밀의 기존 결과·실패 분석은 남기되 복구를 다음 실험의 선행 조건으로 두지 않는다. §9의 양성 학습·개별 support·설명 비교 진단은 새 대상에 공통 적용한다. 예약 중지는 유지하며 여기서 GPU 실행을 시작하지 않았다.

### 바로 사용할 자료와 확장 범위

첫 학습 대상은 이미 준비한 **포도밭·사료용 콩과**다. [runtime_v2](../artifacts/oe10_expansion_catalog_20260928/oe10_expansion_catalog_v0/runtime_v2)는 48개 훈련 query의 대상 방향·K 변형 384행이며, 입력·loader·설명→mask 연결까지 확인했다. 아직 새 대상의 학습 성능은 없다. 20개 품질 검토 그림과 빈 응답 양식도 준비됐으나 사람이 작성한 교정은 0이다.

후속 개발 비교의 범위는 **초지·옥수수·포도밭·사료용 콩과의 네 대상**으로 잡는다. 원 P2 결과를 본 뒤 정한 새 개발 범위임을 명시한다. 두 신규 대상은 이미 train/support 가용량으로 선정했으며 성능으로 골라낸 것이 아니다. 네 대상의 통합 episode 목록·새 평가 query/가중치는 아직 구축/동결 전이다. 겨울밀은 새 주 비교의 요청 대상·명시적 혼동 역할에서 분리하되 영상에 함께 존재하는 겨울밀/다른 배경을 지우거나 그런 영상을 자동 제외하지 않는다.

보고는 (a) 원래 겨울밀 포함 P2 결과 그대로, (b) 네 대상 동일 표본의 신규 기준선 대 제안 결과, (c) 겨울밀 별도 실패표로 구성한다. 신규 네 대상 평균은 원 세 대상 평균과 직접 비교하지 않는다. 새 범위 안의 기준선 대비 차이가 실제 개선이다. 클래스/지역별 값과 대상 부재 오탐을 함께 남기고, 낮은 클래스가 나와도 다시 빼지 않는다.

### 확장하면서 측정할 순서

| 단계 | 실제 추가 작업 | 확인할 것 |
|---|---|---|
| 1. 준비된 두 대상 학습 | 기존 포도밭/콩과 pack으로 한 모델의 학습·새 프로세스 optimizer/RNG 재개 확인, 같은 관측의 이름만 대 이름+판별 설명 | 연결 검사 다음의 실제 학습 가능성; 짧은 pilot은 일반화 결과 아님 |
| 2. 네 대상 공동학습 | 통합 train 목록과 공통 개발 평가를 결과 전에 고정하고 같은 구조·자료로 아래 네 조건을 학습 | 언어 추가 효과와 OlmoEarth 갱신 효과, 기존 초지/옥수수 성능 보존 |
| 3. 지역 확장 | 같은 대상·정의·source support를 다른 지역 query에 적용하고, 별도로 그 지역 K개 교정을 추가 | 원 지역 암기인지, 새 지역에서 적은 교정으로 적응하는지 |
| 4. 대상 확장 | 네 대상 중 하나를 추가 학습에서 제외하는 교차 실험; 이후 다음 대상군을 사전 기준으로 선정 | 처음 요청받은 개념에 설명/예시만으로 적응하는지 |
| 5. 분야 확장 | 적합한 공개 라벨이 있는 물/침수 등 한 분야에 같은 인터페이스 적용 | 작물별 전용 head/규칙 없이 공통 학습이 통하는지 |

단계1을 겨울밀 복구에 종속시키지 않는다. 단계2까지는 공개 연간 작물 mask와 출처 있는 설명으로 진행할 수 있다. 실제 사람 교정의 가치와 시점별 근거 설명 주장은 별도 검수 자료와 평가가 필요하다. 단계4의 미학습은 우리 추가 학습에서 제외했다는 뜻이며 OlmoEarth 사전학습에서의 미노출을 보장하지 않는다. 단계5에서 물 mask만으로 신규 침수/영구 수역 정답을 만들지 않고, 기존 Kuro는 노출 감사 전 사용하지 않는다.

### 확장의 첫 핵심 비교: 공통 구조의 네 조건

| 조건 | OlmoEarth | 언어 입력 |
|---|---|---|
| E0 | 고정 | 작물명 |
| E1 | 고정 | 작물명 + 출처 있는 판별 설명 |
| E2 | 공동학습 | 작물명 |
| E3 | 공동학습 | 작물명 + 같은 판별 설명 |

네 조건은 다음 구현 대상인 동일한 위치별 개별 support 비교 head, query/support 관측, 교정 목록, mask 감독을 받도록 설계한다. 현재 준비된 head가 이 개별 비교를 이미 구현·학습했다는 뜻은 아니다. head 규모·업데이트 수·튜닝 기회와 실제 GPU 비용을 기록한다. 고정 모델의 feature cache 이점을 숨기지 않는다. E3−E2가 설명의 추가 효과, E3−E1이 설명을 함께 사용하는 OlmoEarth 갱신 효과다. 구조의 효과는 별도 평균 head 대조로 분리하고, 표준 attention과 설명 결합 자체를 신규성으로 세지 않는다. 같은 클래스의 틀린 설명·무관 설명·재서술은 고정된 진단 조건으로 둔다. 익명 코드가 충분한지 비교하려면 같은 학습 기회를 준 코드 조건이 필요하며, 평가 때만 설명을 코드로 바꾸는 것은 입력 변화 진단으로 구분한다.

한 공통 모델이 네 대상을 다루게 하며 작물마다 최고인 checkpoint/threshold를 골라 평균내지 않는다. 새 평가 전에 공통 checkpoint 선택·K별 집계·대상/지역 가중치를 정한다. 첫 짧은 seed는 개발용이고, 충분 학습한 비교의 반복 수/시간은 처리량과 분산을 확인해 별도 고정한다. 원 12시간 P2를 이어 돌리거나 초기 2시간 pilot 예산을 충분한 비교 예산으로 간주하지 않는다.

### 지역 설명을 강화하려면 필요한 확장

현재 훈련에는 부모 타일 두 개가 있지만 포도밭 존재 patch는 14 대 2, 콩과는 13 대 5로 편중돼 있다. 이 수치는 클래스 존재 수이며 적격 support patch 수와 다르다. 날짜 두 개의 조합만으로도 부모 타일이 구분된다. 따라서 지금 pack에서 지역 문구 효과가 나와도 일반화로 해석할 수 없다.

다음 자료 확보는 새 작물을 계속 늘리는 것보다 **같은 네 대상의 서로 다른 지역 사례를 채우는 것**을 우선한다. 지역별 각 대상의 양성/실제 혼동/부재, 관측 품질과 source–query 지리적 독립성을 확인한다. 정확한 필지 ID·footprint가 확인되기 전 K8 객체를 독립 전문가 교정 8개로 부르지 않는다. 포도밭 bank는 4patch·한 부모 타일이고 콩과 경계 객체 제외 시 capacity가 줄어드는 제약도 유지한다.

기존 지역의 개발용 분할과 미개봉 최종 지역을 구분한다. 새 지역 평가의 표본·가중치를 성능 확인 전에 고정하고, 결과에 따라 지역을 교체하지 않는다. 검증된 지역·계절 사실을 확보한 뒤 E3에 추가하며 같은 정보를 구조화된 수치/범주로 받은 대조도 둔다. 원 support 재사용과 target에서 K개 교정을 얻는 적응은 별도 곡선으로 보고한다. 관측을 2→4→8날짜로 늘리는 효과 역시 모든 대조군에 같은 관측을 주는 별도 비교다.

**다음 실행 준비물:** 두 대상 runtime_v2를 사용하는 학습/재개 pilot, 네 대상의 통합 목록과 지원 가능한 클래스×지역×K 가용표, 공통 네 조건의 결과 전 실행 명세. 겨울밀 재학습은 이 준비물에 포함하지 않는다. 두 대상의 짧은 학습 pilot은 해당 입력·조건·예산을 동결한 뒤 진행하며 네 대상 전체 준비를 기다릴 필요가 없다. 네 대상의 본 성능 비교는 통합 cohort와 학습 충분성 기준을 동결한 뒤 시작한다.


## 11. 09/29 실제 구현·자료 확대

[OE11 실행 기록](OE11_REGION_EXPANSION_20260929.md)에 실제 완료 범위·해시 검증·남은 모델 학습을 정리했다. 정상 shard의 기존80개를 제외한 새288개를 변환했다. 훈련은2→3source지역·48→192영상으로 확대했고 포도밭/콩과 존재 영상은16/18→66/99다. t31tfm은 이전 개발지역을 source로 편입했으므로 독립 지역 평가가 아니다. t30uxv 영상·정답은 개봉하지 않았다.

네 대상12방향쌍×K1/2/4/8의 train9,216/dev2,304행을 pooled와 cross-parent 두 조건으로 생성·검산했고, 실제 로더72회와 별도24target검사가 통과했다. 위치·역할 언어로 개별 support 객체를 고르는 head와 둘 다 없는 배경 경로를 구현해 CPU13검사를 통과했다. 이름/설명24입력은 기존 카드 문장과 계약을 사용한다. 공개 설명은 전문가 교정 또는 필지별 지역 사실이 아니다.
