# CVPR 기여 결정 — 관측 근거를 이용한 교정을 새 환경에 재사용하는 OlmoEarth

2026-09-28. **수동 연구 갱신이며 방법 성능·신규성 확정·동결 사전등록이 아니다.** 예약은 PAUSED다. 이번에는 선행 조사, 기존 metadata의 CPU 감사, 세 독립 검토와 결정 설계를 수행했다. GPU·서버 실행·새 평가자료 개봉은 하지 않았고, 기존 P2의 조건·상한·판정을 변경하지 않았다.

## 1. 논문의 중심으로 남길 것

**전문가가 알려준 “이것과 저것을 무엇으로 구별하는가”를 학습해, 새 지역에서도 적은 교정으로 원하는 대상을 찾는 OlmoEarth.** 이 이점이 원래 연결부를 버리고 다른 VLM에 연결해도 남는 것이 목표다.

방법 후보는 **교정과 그 교정을 뒷받침하는 관측의 관계를 함께 학습하는 것**이다. 예를 들어 두 필지의 실제 시계열에서 전문가가 관찰한 차이를 알려주면, 다른 지역의 필지에서도 해당 구별이 가능한지 관측을 확인한다. 홍수에서는 신규 침수와 기존 수역을 구분하는 전후 관측이 대응하는 예다. 후자의 정답과 전후 입력은 아직 확보되지 않았다. 지역 상식이나 작물의 연간 라벨이 특정 생육·수확 사건의 정답을 대신해서는 안 된다.

이것은 연구할 가치가 있는 가설이며 **아직 새로운 방법을 확보한 것은 아니다.** 일반 소수 예제 학습·관계 학습·선택적 예측의 조합으로 설명될 위험이 있다. 동일 정보의 강한 일반 방법을 이기고, 효과가 OlmoEarth에 남는 것을 보여야 CVPR 방법 기여로 논의할 근거가 생긴다. 채택 확률을 계산할 근거는 없다.

## 2. 이미 존재하는 것과 남는 질문

저자 논문·공식 자료를 확인한 비교다. 보고 성능을 우리 환경에서 재현한 것은 아니며, 검색에서 못 찾은 것을 최초성의 증거로 쓰지 않는다.

| 확인한 선행 | 이미 있는 내용 | 단독 기여로 쓰기 어려운 주장 |
|---|---|---|
| [TerraScope v1, 2026-03-19](https://arxiv.org/html/2603.19039v1) | 영역·언어·측정과 다중시점/센서 활용 | 위치와 설명을 함께 내는 EO–VLM |
| [SPEX v2, 2026-03-09](https://arxiv.org/html/2508.05202v2) | 분광 정보, 실제 visual encoder 학습, 언어·분할 | EO 인코더까지 언어로 학습한다는 주장 |
| [MS-CLIP v3](https://arxiv.org/html/2503.15969v3), [DOFA-CLIP v2](https://arxiv.org/html/2503.06312v2) | 다중분광/센서 언어 정렬, 지역정보 또는 공간 표현 보강 | 센서와 언어 정렬·표현 보존의 결합 |
| [MetaSegNet v3, 2024-10-30](https://arxiv.org/abs/2312.12735v3) | 기후 metadata를 지리 설명으로 바꿔 segmentation에 결합 | 지역의 몬순·장마 설명을 넣는 아이디어 |
| [TimeSenCLIP v3, 2026-03-27](https://arxiv.org/html/2508.11919v3) | Sentinel-2 시계열·분광과 지상 사진의 CLIP 표현 정렬 | 시간·분광 정보를 언어 공간에서 활용 |
| [SegEarth-R2](https://arxiv.org/html/2512.20013v1) / [CVPR 2026 저자 저장소](https://github.com/earth-insights/SegEarth-R2) | 복잡한 지시·다중 대상·추론을 포함한 언어 분할 | 질문 종류를 늘렸다는 주장 |
| [Geo-R1: Few-Shot Referring](https://arxiv.org/html/2509.21976v1) | 소수 라벨 referring/segmentation 및 cross-dataset 평가 | 적은 라벨로 VLM 적응 |
| [Rußwurm·Sherrie Wang 등, 2020](https://arxiv.org/html/2004.13390v1) | EO 지역 다양성에 대한 MAML 소수 예제 적응 | 지역별 episode 자체. 다만 같은 지역 support/query와 A→B 무추가교정 전이는 구분 |
| [QMTN, 2026](https://doi.org/10.1016/j.patcog.2025.112331) | hyperspectral few-shot과 관측 조건 모사 meta-task | EO 관측 변화와 meta-learning의 결합. publisher 색인 확인이며 전체 PDF 검증은 아님 |

OlmoEarth도 [공식 embedding 활용 예](https://allenai.org/blog/olmoearth-embeddings)에서 검색과 소수 pixel 분류를 보여준다. 따라서 **OlmoEarth에 few-shot과 VLM을 붙인 것만으로는 부족하다.** TerraScope보다 모듈이 많은 것이 차별점도 아니다. 남길 질문은 *교정으로 배운 구별이 얼마나 잘 전이하고, 그 효과가 어디에 저장되는가*다.

## 3. 이번에 실제 확인한 입력 문제

[CPU 감사 코드](../code/audit_oe10_context_identifiability.py)와 [해시 포함 결과](../artifacts/cvpr_direction_update_20260928/context_identifiability_audit.json)를 만들었고 독립 재실행 결과가 일치했다. 기존 회수 metadata만 사용했다.

| 확인 | 의미 |
|---|---|
| 384항목 = 48 query × 2방향 × 4K | 독립 영상/사람 교정 384개가 아님 |
| Qwen 고유 입력 문구 7개 | 현재 고정 텍스트 벡터를 7개 lookup으로 대체 가능. 의미가 쓸모없다는 뜻이 아니라 class code와 지식 이해를 식별하기 어려움 |
| 두 source parent마다 날짜 일정 고정 | 날짜쌍으로 지역 식별 가능. 실제 모델의 이용 여부는 미측정 |
| 포도밭/콩과 동시 존재9/48, 둘 다 부재23/48 | 양성 구별과 대상 부재를 별도로 평가해야 함 |
| K1 support96행 중83행이 같은 parent | support의 지역별 수·다양성 불균형 |
| 현재 v2 Qwen은 텍스트만 읽음 | 일반 텍스트 조건 분할 baseline이며 EO 관측을 읽는 VLM 방법은 아직 아님 |

EO 특징의 날짜/그룹 평균, support 객체 평균도 확인했다. 그러나 native encoder가 이미 시간 정보를 섞을 수 있으므로 평균이 시간 정보를 완전히 파괴한다거나 현재 성능의 원인이라고 단정하지 않는다.

기존 P2는5/6완료·12시간 상한 종료, 완료5회 모두 안정성 미충족이다. 두 완료쌍 평균 +0.047228은 기술 통계다. 설명 연결 검사는 한 사례·optimizer update0이다. **제안 방법 효과·사람 교정 효율·새 reader 전이는 아직 측정되지 않았다.** [종료 결과와 위치](RESEARCH_STATUS_AND_LOCATIONS_20260928.md).

## 4. 방법 후보 하나와 학습 경로

**학습 단위:** 교정 C = (대상 영역, 혼동 영역, 실제 관찰한 차이, 참조 관측/날짜, 판독 가능 범위). 일반 지역 설명과 그 영상에서 확인된 사실은 별도 필드다. source에서 참인 차이가 모든 target에서도 참이라고 가정하지 않는다.

**공통 구조:** OlmoEarth의 관측 특징을 바로 평균하지 않고 위치·관측별로 참조하게 한다. 표준 attention/head/VLM connector는 기준선과 제안군에 동일하게 제공한다. 이것만으로 해결되면 연결부는 ablation 결과로 남긴다. 새 tokenizer·KV cache·시뮬레이터·RL loop를 추가하지 않는다.

**제안 규칙:** 동일 query에서 교정의 의미와 근거를 바꾼 쌍 사이의 관계를 학습한다.

- 같은 뜻의 재서술, 판단을 바꾸지 않는 배경 정보에는 답을 유지한다.
- 대상/혼동 역할이 바뀌면 새 대상의 정답 mask로 바뀐다. 전체 mask의 반전이 아니다.
- 같은 작물명·문체라도 현재 support 관측과 맞지 않는 설명은 영상 증거를 덮어쓰지 않게 한다.
- 구별 근거를 제거했고 대체 관측도 부족하다는 검수가 있으면 단정을 줄인다. 무관한 날짜 제거에도 무조건 보류하면 안 된다.
- source 환경 사이에서 교정을 재사용하는 episode로 특정 이름/지역보다 관측에 맞는 구별을 학습한다. 최종 평가 지역 정답은 학습에 들어가지 않는다.

구현 가설은 기존 mask·근거 손실에 위 쌍의 출력 관계 항을 추가하는 것이다: L_mask + λL_evidence + γL_pair. 이 수식이나 loss 개수는 신규성이 아니다. **일반 대조에도 모든 쌍·정답·근거·보류 라벨을 주고**, 표준 contrastive·domain meta-learning·calibration/gating과 비교한다. 추가 감독의 효과를 새 규칙 효과로 오인하면 안 된다.

gradient는 OlmoEarth에 들어간다. 학습 후 인코더만 export하고 원 head·connector를 버린 뒤 새 head/reader에 붙인다. 이점이 사라지면 OlmoEarth 재사용성 개선을 주장하지 않는다. 공개 라벨을 쓰는 이 단계는 **사전학습 모델의 추가 학습**이며 처음부터 새 자기지도 사전학습을 한 것으로 부르지 않는다.

**실제 VLM:** 후속 모델은 EO 관측 token과 교정을 함께 받아 영역·날짜를 참조하는 답을 생성해야 한다. 현재 text-only v2와 구분한다. 작은 text encoder+동일 head, 전문 시계열 모델+측정 도구+동일 Qwen을 비교한다. 동등하면 자연어 인터페이스의 가치는 있어도 VLM 고유 시각추론 기여는 미입증이다.

## 5. 방법보다 먼저 필요한 자료

**20개 교정 쌍을 두 사람이 독립 검수하는 pilot**이 다음 산출물이다. 기존20개 품질 PNG는 출발 자료일 뿐 새 교정 과업이 완료된 것이 아니다. 실제 사람 응답0을 유지한다. “관측이 지지/반박/판단 불가”, 근거 영역·날짜, 작성/검수 시간을 기록한다.

같은 작물명·비슷한 문체인데 관측에 따라 참/거짓이 달라지는 사례가 필요하다. 작물명만 읽고 틀렸음을 알 수 있는 설명 교환은 부족하다. 동일 query/support에서 다음을 비교한다.

1. 정확한 관측 설명 / 같은 작물의 다른 사례에서 온 틀린 설명 / 맞지만 구별과 무관한 설명.
2. 이름만 / 익명 class code / 엄격한 무언어 / 의미 보존 재서술.
3. 지역명·좌표·날짜·출처 ID만으로 답하는 대조와, 실제 EO 입력을 사용하는 대조.

여섯 기존 후보와 겨울밀 실패를 유지하고 클래스×지역×support 수×판독 가능성 가용표로 구성한다. 점수로 대상을 선택하지 않는다. source-support를 B지역에 그대로 재사용하는 조건과 B지역 K개 추가 적응은 별도다. 새 지역과 새 개념도 다르다. class/정의 조합을 episodic 학습에서 제외해야 후자를 시험할 수 있으며, 원본 pretraining 미노출까지 보장하는 것은 아니다.

20건 합의만으로 전체 데이터 타당성을 확정하지 않는다. 검수 전에 범주별 수·합의 기준을 기록하고, 합의율·판독 불가율·범주별 혼동과 시간을 함께 본다. 과업이 불안정하면 원인을 수정한다. 설명을 많이 생성해 독립 표본을 늘렸다고 세지 않는다.

**근거 제거의 계약:** 인코딩 뒤 날짜 token만 지우면 다른 token에 정보가 남는다. 원관측을 제외/마스킹해 재인코딩하고 cache를 분리한다. 동일 수의 무관한 관측 제거와 비교하고, 제거→복원 시 교정 효과의 회복도 본다. attention weight나 참조 ID만으로 근거 정확성을 판정하지 않는다. 연간 작물 mask로 시점별 사건·관측 부족 정답을 만들지 않는다.

## 6. 결정 실험과 주장을 접는 조건

아래는 다음 결과 전에 manifest·코드 hash·수치·예산으로 동결할 설계다. **아직 launch-ready protocol이 아니다.** 기존 미완료 P2를 재시작하거나 기준을 바꾸지 않는다.

| 순서 | 비교 / 산출물 | 판정 대상 |
|---|---|---|
| A | 완료한 metadata 감사 →20개 이중 검수·같은 class 내 참/거짓 설명·footprint 독립성 | 과업과 관측 근거의 타당성 |
| B | frozen EO prototype/logistic/MLP, 충분히 학습한 일반 joint, 전문 시계열 모델 | 강한 baseline으로 해결되는 문제인지 |
| C | 동일 관측·구조·감독에서 일반 SFT/contrastive/domain meta-learning 대 제안 paired 규칙 | 추가 자료를 넘는 규칙 효과 |
| D | EO 고정/갱신 × 일반/제안 규칙 네 칸. 주 비교는 갱신 EO의 제안 대 일반 | head와 EO의 효과 귀속 |
| E | EO만 이전, 새 head/다른 reader를 동일 예산으로 학습, 독립 EO 평가 | 인코더에 남는 재사용성 |
| F | 동일 checkpoint·공통 교정 규칙으로 농업과 물/침수의 분리된 환경 | 한 모델의 응용 범위 |

같은 입력·support·라벨·튜닝 기회를 준다. 관측/업데이트를 맞춘 비교와 실제 GPU 비용을 맞춘 비교를 구별한다. 제안만 추가 forward를 받는 비용은 숨기지 않는다. 상한 종료나 불안정 학습은 동등성 증거가 아니다.

주평가는 지역별 target/confuser의 K별 IoU와 곡선 요약이다. 반복 K/문구 행이나 pixel을 독립 표본으로 bootstrap하지 않고 지역/사건 및 support-library 의존성을 반영한다. 겨울밀·대상 부재 오탐·잘못된 설명 피해·비관련 EO 손상을 별도 공개한다. mask에서 계산한 면적과 설명을 세 개 독립 능력으로 세지 않는다.

다음은 확장 투자에 필요한 실용 효과의 **초안 목표**다. CVPR 기준·예상 결과·원 P2의 새 통과 기준은 아니다.

- 새 평가의 강한 일반 대조 대비 K-IoU 곡선 요약 **절대 +0.05 이상**을 목표로 삼고 지역별 불확실성을 함께 본다. 작은 차이는 작은 기여로 해석하고 정밀도 부족은 미정으로 남긴다.
- 보조 목표는 같은 품질의 **교정 수 또는 실제 작성 시간1/2 이하**다. 유리한 정확도 목표를 사후 선택하지 않고 전체 곡선을 보고한다.
- 독립 EO 보존의 예시 허용폭은 0–1 점수 기준 **-0.01**이다. task별 허용폭은 본 평가 전에 근거와 함께 정한다. 비열등+새 reader 재사용과 독립 EO 자체 향상은 다른 크기의 주장이다.
- 보류로 오답을 감추지 않도록 전체 query 품질·응답률·동일 응답률 오류를 함께 본다. 생성문은 실제 근거 영역/날짜와 새 조건 조합의 성공으로 평가한다.

표본 수·지역 수·seed·상한은 개발 분산과 실제 속도를 측정한 뒤 최종 지역 개봉 전에 정한다. 예비 범위 목표는 분야별 미관찰 환경3개 이상이지만 숫자만으로 일반화를 보장하지 않는다. 이미 본 t31tfm은 개발용이다. t30uxv 하나의 성공도 광범위 전이의 증거가 아니다.

**폐기/축소:** 충분학습 일반 방법과 동등하면 새 규칙 주장 철회. class code와 동등하면 지식 이해 미입증. 원 head에만 효과가 남으면 인코더 개선 주장 철회. 관측 쌍을 받은 일반 meta-learning+augmentation+gating과 같은 전이/거절 곡선이면 새 관측 학습 원리라고 포장하지 않는다. 일반 B0≈B2만으로 아직 시험하지 않은 제안 규칙까지 기각하지도 않는다.

## 7. 규모와 사람 예산

| 자료 | 역할과 한계 |
|---|---|
| [PASTIS 공식 자료](https://github.com/VSainteuf/pastis-benchmark) | 2,433시계열·124,422필지·18작물의 위치 라벨. 현재 준비분80패치. 연간 class와 날짜별 사건은 다르며 공식 fold와 custom split 점수를 섞지 않음 |
| [Sen4Map 저자 기관 기록](https://juser.fz-juelich.de/record/1029392/) / LUCAS | 국가별 환경·조사 라벨 후보. TimeSenCLIP과 겹치는 강한 비교 대상. point 라벨을 dense mask로 늘리지 않음. 이번 다운로드·노출 감사 없음 |
| [Sen1Floods11 라벨 정의](https://github.com/cloudtostreet/Sen1Floods11#dataset-information) | 독립 물 분할 후보. QC는 water/not-water/invalid이며 이것만으로 신규 침수/영구 수역 정답을 만들 수 없음 |
| 기존 Kuro | 사건 노출 감사 전 실행 금지. 이미 본 사건은 개발용, 자동 개봉 금지 |

공개 라벨이 학습 규모를 담당하고 사람은 교정의 의미와 관측의 타당성을 검수한다. **100인시를 가정한 계획:** pilot/가이드10시간, 이중 검수60시간, 불일치 조정·품질20시간, 예비10시간. 한 사람당 사례6–10분이면60시간에 이중 검수 약180–300개가 가능하다. 실제 속도는 pilot에서 확인한다. 이는 사용자가 제안한 시간 자원 배분이지100만원으로 전문 검수100시간을 확보한다는 보장이 아니다. 일반 검수자를 전문가라고 부르지 않는다.

AI 설명은 후보 생성에 쓸 수 있으나 정답이나 사람 교정 수로 세지 않는다. 외부 연락·채용·유료 API 호출은 하지 않았다.
