# OE1 — 실제 Sentinel-2 입력으로 OlmoEarth–VLM 학습 가능성 확인

## 현재 범위

한 seed·개발셋 256문항의 결과다. 공동학습의 관측 이득은 고정 모델 대비 10문항이며, 지역별로 개선과 악화가 섞여 있다. 이것으로 새 사전학습 방법의 우월성이나 CVPR 논문 기여가 입증됐다고 판단하지 않는다.

**실제 Sentinel-2 입력으로 OlmoEarth encoder를 언어 답변까지 연결해 학습하는 것은 확인했다.** 공개 OlmoEarth-v1-Tiny와 고정 Olmo-3-7B-Instruct를 사용한 세 조건의 GPU 학습·평가가 완료됐고, 응답 1,740개를 독립 코드로 다시 채점했다. 결과를 보고 기준이나 데이터·checkpoint를 바꾸지 않았다.

이 실험은 기존 가중치에서 시작하는 질의응답 공동 미세조정이다. 새 사전학습 목적의 우월성, scratch 사전학습, 정량 면적 추정, 공간 근거 제시, 시계열·기후변화 이해를 입증하는 실험은 아니다.

## 결과

주지표는 전체 어휘에서 선택한 첫 답변 토큰의 균형정확도(yes와 no의 재현율 평균)다. 실제 관측 256문항은 두 답이 각 128개여서 일반 정확도와 같다.

| 학습 조건 | 실제 관측 정답 수 | 실제 관측 주지표 | 평가 때 특징을 0으로 만든 경우 |
|---|---:|---:|---:|
| encoder 고정 + 연결부 학습 | 175/256 | 68.36% | 51.56% |
| encoder와 연결부 공동학습 | 185/256 | 72.27% | 49.61% |
| 처음부터 영상 없이 연결부 학습 | 171/256 | 66.80% | 66.80% |

공동학습은 고정 조건보다 **+3.91%p**, 영상 없는 학습보다 **+5.47%p** 높았다. 같은 문항에서 고정 모델의 오답 28개를 맞히는 대신 정답 18개를 놓쳤다. 11개 MGRS 그룹에서 고정 모델보다 나은 곳 6개, 같은 곳 2개, 낮은 곳 3개다. 독립 반복이나 미사용 시험셋에서 확인한 차이는 아니다.

특징 제거 때의 하락은 입력 의존성 진단이다. 학습 중 보지 않은 0 특징을 넣은 영향도 포함하므로 이것만으로 올바른 영상 이해를 입증하지 않는다. 영상 없는 조건도 66.8%인 만큼 질문 편향이 상당하다.

같은 질문에 대해 정답이 반대인 관측을 찾을 수 있었던 **동일한 68문항**은 다음과 같다. 교체 후에는 새로 제시한 영상의 정답으로 평가한다.

| 조건 | 원 관측 BA | 교체 관측 BA | 응답 변경 수 | 원 관측·교체 관측 모두 정답 |
|---|---:|---:|---:|---:|
| encoder 고정 | 59.96% | 57.71% | 16/68 | 14/68 |
| 공동학습 | 67.62% | 61.82% | 26/68 | 23/68 |
| 영상 없이 학습 | 49.13% | 50.87% | 0/68 | 0/68 |

공동학습 모델은 관측을 바꾸면 답도 바꾸지만 두 관측을 모두 맞히는 경우는 23/68이다. 영상과 날짜를 함께 바꿨고 donor 재사용도 있으므로 픽셀만의 인과 효과나 독립 표본 68개로 해석하지 않는다. 전체 256문항 점수와 교체 68문항 점수의 차이를 직접 효과량으로 쓰지 않는다.

### 점수 동률에서 발견한 차이

실제 관측에서 yes/no로 제한한 보조 점수는 고정 69.14%, 공동 75.00%, blind 65.63%다. 하지만 주지표와 답이 달라진 8/13/13문항은 **전부 BF16으로 기록된 yes/no logit 동률**이다. 전체 어휘 argmax는 작은 token ID인 `no`를, 보조 규칙 `p_yes >= 0.5`는 `yes`를 선택했다. 따라서 75%를 더 강한 결과로 내세우지 않는다. 원 주지표와 모든 응답을 보존하고 다음 실험 전에 정밀도와 동률 규칙을 통일한다. 평가 때 특징을 제거한 조건에는 대문자 응답 차이도 있고, 공동학습의 `**` 3개는 오답으로 분모에 포함됐다.

## 실제로 사용하는 자료

- 원 영상: 서버에 있던 GEO-Bench-2 BigEarthNet v2 Sentinel-2 묶음. 12개 L2A 원 밴드를 120×120으로 재표본화한 DN 값을 사용하고 OlmoEarth 공식 밴드 순서·정규화를 한 번 적용한다.
- 언어 지도: 기존 BigEarthNet.txt의 원문 presence yes/no 질문·정답. 패치당 yes/no 질문 하나씩 사용한다. 새 답을 LLM으로 생성하지 않는다.
- 학습: 공식 train에서 512패치·1,024문항·43 MGRS 타일 그룹.
- 개발 검증: 공식 validation에서 128패치·256문항·11 MGRS 그룹. train과 MGRS가 겹치지 않고 최소 패치 중심 거리는 7.6248km다.
- 공식 test·수동검수 benchmark는 이번 모델 학습·평가에 사용하지 않는다. 공개 사전학습 corpus에서의 과거 노출까지 배제된 집합은 아니다.
- 날짜는 각 패치의 실제 취득 시각을 사용한다. 질문에는 국가·좌표·계절·기후대·정답 caption·파일명을 넣지 않는다.
- 원 archive는 9,099,097,346바이트이며 공식 핀 SHA256은 `821c2f429c3e85c158c758bbb215bf61170a2451a11284efaf0f89cef97e468a`다. 실행 launcher가 전체 SHA를 확인한 뒤 학습한다.

## 비교 조건

| 조건 | OlmoEarth encoder | 영상 연결부 | Olmo 3 7B |
|---|---|---|---|
| frozen | 고정 | 학습 | 고정, 입력 gradient 유지 |
| joint | 학습 | 학습 | 고정, 입력 gradient 유지 |
| blind | 입력을 0 특징으로 대체 | 학습 | 고정, 입력 gradient 유지 |

모든 조건은 같은 초기 연결부, seed 17, 같은 질문 배치 순서, 256 optimizer update, batch 8, 조건당 2,048문항 노출을 사용한다. 원래 encoder의 초기 가중치도 같다. joint 조건의 encoder 역전파로 연산량은 더 많으므로 같은 노출 횟수를 같은 FLOPs라고 부르지 않는다.

입력은 16개 영상 토큰이며 정답 yes/no 토큰의 전체 어휘 교차엔트로피로 학습한다. encoder learning rate는 1e-5, 연결부는 1e-3이다. Tiny 모델 버전은 이미 실제 원영상 역전파를 확인한 v1로 고정했다. v1.2나 다른 encoder로 바꾼 결과를 같은 실험으로 섞지 않는다.

## 실행 및 검증

- 세 조건의 학습을 모두 끝낸 후 개발 검증을 한 번 수행한다. 중간 validation 점수로 checkpoint를 선택하지 않는다.
- 일차 지표는 전체 어휘에서 선택된 첫 응답 토큰의 yes/no 균형정확도다. yes/no가 아닌 응답은 오답이며 별도 집계한다. 두 토큰으로 제한한 점수는 보조 지표다.
- 원 관측, 영상 특징 0, 동일 질문의 반대 정답 관측 교체를 평가한다. 교체 조건은 영상과 날짜를 함께 바꾼다. 따라서 픽셀만의 기여와 날짜의 기여를 분리하는 통제는 아니다.
- 비교 가능한 donor는 68/256문항, 서로 다른 제시 패치는 48개다. 원 관측과의 비교도 같은 68문항으로 맞추며 반복 donor를 독립 관측으로 취급하지 않는다.
- 저장 직전 train 질문 8개의 logits를 보관하고, 저장 모델을 복원한 뒤 원래 logits와 비교한다. 원 encoder 고정, 공동학습 encoder 변화, LLM 가중치 불변을 각각 검사한다.
- h200-dev 기존 세션의 물리 GPU1을 사용하며 유휴 확인과 협조 잠금을 거친다. `/home/work/data/olmoearth/oe1_bentxt_v0/runs/pilot_v1/code_snapshot`의 봉인된 코드를 실행한다. 본 runner의 전체 시간 상한은 3,600초다.

실제 실행은 **2026-09-26 19:43:00–19:48:26 KST**에 완료됐다. 자료 해시 검증 등 실행 준비 포함 325.88초, trainer 202.00초, 학습 중 최대 PyTorch 할당 메모리 19.62GiB다. 세 조건 총 768 update·6,144문항 노출이며 각 조건에서 1,024개의 원 질문을 정확히 두 번 사용했다. 종료 후 GPU 계산 프로세스가 없음을 확인했다.

공동학습 encoder는 **203개 parameter tensor가 변경**됐고 고정·blind encoder는 0개였다. LLM 가중치 해시는 불변이다. 각 조건에서 저장 직전 실제 모델의 train 8문항 logits와 저장 후 복원 logits가 bit-exact로 일치했다. 개발 8문항 반복 로딩 검사도 별도로 일치했다. 이 테스트는 CPU에서 변조 encoder를 놓치는 기존 반복 로딩 검사의 결함을 잡도록 보완했으며 CPU 테스트 3개가 로컬·서버에서 통과했다.

독립 receipt 감사는 1,740개 응답의 원 토큰 파싱·정답/영상/날짜 연결·분모·통제별 점수·자료 해시·배치 노출 기록·학습 gradient 기록을 검산했다. 별도 감사기 테스트 4개도 통과했다. 실행 소스 snapshot 5개 해시와 보호 대상 서버 코드 4개의 실행 전후 크기·mtime·해시가 같았다. 로컬 감사는 모델 tensor와 원영상 전체를 다시 추론한 검사가 아니며, 원영상 배열 및 공개 corpus 해시는 서버 실행에서 검사했다.

## 결과 해석에 필요한 데이터 진단

전체 yes/no 수가 같아도 질문 종류별 답 분포는 균형이 아니다. train에서 질문 문구별 다수 답만 외운 간단한 기준선은 dev 균형정확도 0.59765625, 추출 가능한 토지피복 종류별 다수 답 기준선은 0.6484375다. 따라서 0.5를 넘는 것만으로 영상 활용을 주장하지 않는다. 이 기준선들은 모델 결과를 보기 전에 계산한 개발 자료 진단이며 독립 최종 시험 점수가 아니다.

종류 이름을 정확한 부분문자열로 찾지 못한 문항은 train 200개, dev 52개다. 문항 자체는 원문 그대로 유지하고 종류별 표에는 미파싱 그룹으로 남긴다.

GEO-Bench 묶음의 내부 S2 TIFF는 재표본화 후 원 B01의 60m affine이 남아 있다. 이번 존재 여부 실험은 외부 색인과 패치 ID를 사용하지만, 해당 내부 affine으로 면적·좌표를 계산하면 안 된다. 공식 변환 소스의 밴드·재표본화 방식은 확인했으며 원본 개별 밴드와 archive 픽셀의 직접 대조는 별도 미검증이다.

개발 미리보기의 일부 장면에는 눈처럼 보이는 밝은 영역이 있다. metadata의 cloud/snow 필터가 완전한 무구름·무설경을 보장한다고 해석하지 않는다. 보고서를 위해 해당 표본을 사후 제외하지 않는다.

## 다음 실험에서 구분해야 할 것

이번 결과는 **공동학습한 encoder와 연결부의 조합**이다. encoder 자체가 다른 VLM에도 읽기 쉬운 표현으로 변했는지는 분리하지 못했다. 바로 다음 단계는 원 encoder와 이번 encoder를 각각 고정하고 **동일한 새 연결부**를 처음부터 학습해 비교하는 것이다. 여러 seed를 결과 전에 고정하고 질문 종류별 yes/no 균형, 지역 분리, 동일 질문 관측 교체를 유지한다. 새 encoder의 이득이 공동학습 연결부를 버린 뒤에도 남는지와 기존 EO 판별 성능이 유지되는지를 함께 본다. 이번 dev는 이미 봤으므로 새 최종 시험셋으로 부르지 않는다.

사용자가 제안한 사전학습 연구로 가려면 그 다음 비교의 감독량도 같아야 한다. **기존 EO 목적**, **언어 정렬 추가**, **같은 영역·피복 감독을 일반 보조 head로 추가**, **제안하는 영역 측정·변화 목적**을 구분해야 한다. 현재 단일 시점 presence 자료에는 실제 변화·복구·관측 부족의 정답이 없으므로 이 파일럿으로 그 능력을 학습했다고 할 수 없다. 면적·공간 근거 단계는 먼저 원 마스크의 좌표를 확인하고, 변화 단계는 실제 시계열 자료를 별도로 확보해야 한다. 다음 GPU 실행은 이 보고서에 포함돼 있지 않다.
