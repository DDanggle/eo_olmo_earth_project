## 1. 한 문장과 현재 위치

> **이미 계산한 지구 임베딩에 새 위성 관측만 반영하여, 과거 전체를 다시 읽지 않고도
> 유용한 지도를 유지할 수 있는가?**

현재는 **Sen12 개발 결과 + KuroSiwo의 조건부 외부 재현**이다. OLMoEarth encoder는 고정하고
작은 updater를 train split의 teacher embedding에 맞춰 학습한다. 모델의 사후 증류/적응에
가깝고, 추론 때 라벨이나 가중치 학습 없이 상태를 바꾼다. RL·LLM post-training이 아니다.

| 축 | 실제로 한 일 | 현재 범위 |
|---|---|---|
| 기존 지역/few-shot | 저장 캐시 위 판독기 재사용·소량 라벨 적응 | 기존 Sen12/Solar 자산 유지, 이탈리아에서 무라벨 성능 한계 발견 |
| 시간 갱신 MS-116 | S2 임베딩 상태를 새 S2 관측으로 4단계 갱신 | 4노출 지역; GRU 유용성, 새 구조 승격 없음 |
| 외부 재현 MS-117 | S1 홍수 데이터에서 updater/decoder를 새로 학습해 10 test 사건 평가 | 수치상 양성. NaN 제외·기존 판독기 선택 절차의 검증 조건 남음 |
| 교차센서 MS-118 | S2 상태를 날짜가 가까운 S1 관측으로 갱신 | 2지역 음성 + 2지역 실행 불가; 인과적 도착/정렬 통제가 없음 |
| 한국 shared-cache 3-task | 동일 갱신 상태를 여러 과업이 공유 | 여전히 후속 검증, 이번에 라벨을 열지 않음 |
| release bridge/FoldRefresh | 모델 버전 변경의 호환성/복구 | 시간 갱신과 구분하는 기존 자산 |

KuroSiwo 성공은 **같은 방법을 S1에 재학습한 외부 재현**이지 Sen12의 S2 가중치를 그대로
홍수에 이식한 zero-shot이 아니다. 현재 하나의 updater로 세 과업을 갱신한 결과도 없다.

같은 표본에서 분모가 같다는 전제하에 보고 방향은 AP와 오경보의 동시 우월성을 지지하지 않는다.

### NaN은 어떻게 처리됐나

- 새 실행은 원시/캐시를 복구한 것이 아니라 입력 finite 검사로 **val `ks_04357` 1개와
  test `ks_05418` 1개를 모든 arm에서 제외**했다. train은 제외0, test는 1,999개다.
- 라벨/점수를 보고 선택한 제외라는 증거는 없다. 동일 입력 품질 기준을 쓴 점은 구분해서
  인정한다. 하지만 원 공식 split 및 유효 영역 복구와 동등하지 않으므로 편차·coverage를 병기한다.
- 판독기 파일 수정 시각은 9/8 **13:43:59 / 14:01:00 / 14:15:47 KST**로 초기 학습 시각이다.
  `kurosiwo_chain2.sh`는 updater와 eval만 실행했고, decoder 로그도 NaN 제외 전 것과 일치한다.
  **깨끗한 validation으로 epoch 선택을 다시 검증했다는 산출물이 없다.**
- 이는 모든 test AP가 NaN이라는 뜻도, 개선이 허구라는 뜻도 아니다. 유한한 입력 부분집합에서
  같은 판독기를 사용한 양성 결과는 남지만, 선택 절차까지 정상인 확증으로 인증할 수는 없다.
- 이전 “bf16 gradient가 원인”이라는 코드 주석은 이번 증거로 확정하지 않는다. 어제 확인된
  val 입력 NaN 경로와 오늘의 fp32/clip/lr 변경은 서로 다른 문제다.

**허용 문장:** “KuroSiwo의 유한 캐시 1,999타일에서 frozen decoder를 적용했을 때, 학습된
S1 갱신 상태가 재인코딩보다 높은 pooled flood AP를 보였다. 입력 제외 및 판독기 선택 재검증은
프로토콜 한계로 남는다.” 현재 평가는 GEO-Bench-2의 공식 multiclass leaderboard 결과가 아니라
데이터를 사용한 자체 binary flood/중앙 crop/3seed 프로토콜이다.

### 운영상 남은 결함

`kurosiwo_pipeline.py`에 best-state assert/finite loss·gradient 처리는 추가됐지만,
`kurosiwo_chain2.sh`는 실패 rc를 기록한 뒤 진행하고 파일 존재만으로 skip한다. eval은 누락
checkpoint를 조용히 생략한다. **이번 12-arm 표는 실제로 완성됐으나 다음 실행의 완결성을
보장하는 코드는 아니다.** 보존된 현재 소스 SHA는 실행 전 snapshot의 대체물이 아니다.

## 3. 노벨티를 가르는 미측정 대조: 새 관측의 필요성과 과거 기억의 필요성

현재 `GRU(m_pre, u_post)`와 `GRU(m_pre, 0)`의 차이는 **새 영상이 필요하다**는 증거다.
그러나 `u_post`만 변환하는 모델도 똑같이 잘한다면 **과거 캐시를 보존할 가치**는 아직 증명되지 않는다.

| 다음 대조(제안, 미실행) | 무엇을 고정/제거하는가 | 답할 질문 |
|---|---|---|
| POST_ONLY → 기존 frozen decoder | 과거 없음, 학습 없음 | post 단일 표현을 바로 읽어도 충분한가 |
| POST_ONLY adapter → 기존 decoder | 과거 없음; train의 동일 teacher MSE·동등 예산 | GRU가 실제로는 단일 영상 표현 변환기인가 |
| GRU_NO_MEMORY(0, post), train부터 같은 제약 | 새 관측만, recurrent cell 구조/예산 유지 | 상태 입력의 기여가 있는가 |
| 단일 임베딩 running mean + 자기 입력으로 학습한 head | 정확한 무학습 상태 갱신, 동일 라벨 예산 | 저렴한 분해 가능한 표현으로도 목적을 달성하는가 |
| GRU(pre, post) | 현재 방법 | 기억과 새 관측을 함께 쓰는 추가 이득 |

추론 때만 상태를 0으로 바꾸면 OOD 교란이 섞인다. 처음부터 같은 정보 제한으로 학습하는
대조가 필요하다. 자기 head를 학습하는 baseline과 frozen teacher-head 호환성 비교는 서로 다른
표로 보고한다. 현재 `singles_mean`을 teacher-head에 넣은 약한 결과가 전자를 대체하지 못한다.

이 추가 분석은 이미 관찰한 KuroSiwo에 대한 **후속 기전 분석**이다. 새 사전등록 확증으로
소급하지 않는다. 이를 개발한 뒤 실제 시점 라벨을 갖춘 다음 데이터에서 규칙을 동결한다.

## 7. 선행연구 확인 후 수정할 신규성 문장

1. [Recursive Bayesian Classifier](https://arxiv.org/html/2301.01796v4)는 위성 시계열에서
   분류 사후확률을 재귀적으로 갱신하며 시점당 계산량을 유지한다. **EO 온라인 갱신 자체는 신규가 아니다.**
2. [Tessera 시간 민감도 분석](https://arxiv.org/html/2608.27175v1)은 encoder를 고정하고
   관측창을 줄여 재계산한다. 현재 방향과 구분할 수 있는 것은 창 단축이 아니라 **기존 상태의
   재사용 및 시간별 정확도–비용 평가**다. 이 논문만으로 모든 EO 문헌에 선점이 없다고 증명할 수 없다.
3. [GEO-Bench-2 §3.5](https://arxiv.org/html/2511.15658v2)는 시점별 인코딩을 평균하는 baseline을
   기술한다. 평균은 `m_new=(n*m_old+u_new)/(n+1)`로 정확히 증분 갱신 가능하다(산술적 추론).
   따라서 “기존 benchmark는 반드시 과거를 재인코딩한다”는 동기는 부정확하다. 우리가 다루는
   병목은 **창 전체의 상호작용으로 만든 OLMoEarth 표현**이며, 그 품질이 단순 평균보다 얼마나
   유용한지도 공정한 head와 비교해야 한다.
4. [OLMoEarth v1.2](https://arxiv.org/abs/2605.20804) 현 abstract에는 inference MACs2.9배,
   [HTML v3](https://arxiv.org/html/2605.20804v3)에는5.3배가 남아 있어 원문 표시가 불일치한다.
   관련연구의5.3배를 검증 완료 사실로 재인용하지 않는다. 정확한 revision/PDF 대조 전 계수 인용 보류.

## 8. 다음 실행 순서 — 새 구조를 늘리기 전에 결정적 빈칸부터

1. **Kuro 검증 정리:** 제외 전/후 manifest와 input policy를 별도 revision으로 기록.
   원자료/캐시 복구 후 clean validation으로 decoder 선택을 재검증한다. epoch별 checkpoint가
   없으면 고정 recipe 재실행이 필요하다. test 점수로 선택하지 않는다. 기존 결과는 보존한다.
2. **기억 기여 분리:** POST_ONLY 즉시 readout → 동등예산 post-only adapter/NO_MEMORY →
   현재 GRU 비교. 먼저 싸고 설명력이 큰 대조를 닫는다. 결과로 gate를 소급 변경하지 않는다.
3. **온라인 비용:** 같은 시각에 도착한 관측·동일 타일 batch·초기 비용 포함. 인코딩/업데이트/
   판독/I/O를 분리. 현2.3배는 batch-compute,4.5배는 논리 update 입력량이며 새 계측은 아직 없다.
4. **시간별 과업 검증:** DEN 등에서 실제 취득일·월별 라벨의 정렬을 감사하고, 각 cutoff의

5. **한국 공유 상태:** 위 규칙을 고정한 뒤3task 공동 효용/비용을 본다. 현재 봉인은 유지한다.

조건을 대신하지 않으며, 교차센서/새 architecture를 한꺼번에 확대할 이유도 아니다.
