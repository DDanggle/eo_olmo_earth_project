# 위성사진 변화 판독 안내 (D1 단계 H)

작성 2026-09-24. 판독자에게 그대로 전달하는 문서입니다. 연구 가설과 모델 결과는 일부러 적지 않았습니다.

## 하는 일

한 지역을 매달 찍은 위성사진을 순서대로 봅니다. 첫 번째 사진(기준영상)과 비교해서
**새 건물이나 공사 흔적이 분명히 보이는지**를 사진마다 표시합니다.

- 실전: 12묶음, 사진 172장. 한 묶음은 한 지역의 13~21개월치 사진입니다.
- 예상 시간: 연습 20~30분, 실전 1~2시간. 전체 상한은 5시간이고, 다 채울 필요는 없습니다.
- 전문 지식은 필요 없습니다. 사진에서 직접 보이는 것만 표시합니다.

## 사진마다 고르는 네 가지

| 선택 | 언제 고르나 |
|---|---|
| 변화 없음 | 비교할 부분을 **읽을 수 있고**, 기준영상 대비 새 구조물·공사 형태가 **관찰되지 않음** |
| 변화 보임 | 기준영상(첫 사진) 대비 새 구조물·공사 형태가 **분명히** 보임. 직전 달이 아니라 항상 첫 사진과 비교 |
| 판독 불가 | 가림·검은 자료 없음·흐림 때문에 비교할 부분을 **평가할 수 없음** |
| 애매함 | 볼 수는 있지만 변화인지, 또는 무엇인지 **확신할 수 없음** |

(2026-09-25 판독 전 보완: "변화 없음"과 "애매함"이 겹치지 않도록 정의를 분명히 했다. 두 판독자 모두 이 정의로 판독한다.)
공간 단위는 사분면 전체다. 일부만 가려졌으면 보이는 부분으로 판단하고, 비교할 부분 대부분을 볼 수 없을 때만 "판독 불가"를 고른다.

## 헷갈리기 쉬운 것

- **계절 때문에 색이 바뀐 것은 변화가 아닙니다.** 논밭이 초록에서 갈색으로 바뀌거나 전체 색조가 달라지는 것은 해당하지 않습니다.
- **한 번 확인한 변화는 지우지 않습니다.** 5월에 건물이 보였는데 6월에 구름이 끼었다면, 6월은 "판독 불가"로 표시하되 5월의 "변화 보임"은 그대로 둡니다.
- **확신이 없으면 "애매함"을 고르세요.** 억지로 "변화 보임"이나 "변화 없음"을 고를 필요가 없습니다. 애매함도 정당한 답입니다.
- 사진을 클릭하면 확대됩니다. 작은 건물은 확대해서 보세요.
- **맞추기 단계에서 정할 것**: 건물 없이 땅만 파헤친 흔적(맨흙 정리)이나 새 도로만 생긴 경우를
  "변화 보임"으로 볼지 "애매함"으로 볼지는 원 규약에 적혀 있지 않습니다. 연습 결과를 보고 두 사람이 정해
  기록한 뒤 실전에 들어갑니다.

## 순서

1. **연습(교육 패키지, 3묶음 39장)**: 두 사람이 따로 판독합니다.
2. **맞추기**: 연습 결과를 나란히 놓고, 서로 다르게 고른 사진에 대해 이야기합니다.
   합의한 기준은 `config/d1_H_rater_record_20260924.json`의 `calibration_decisions`에 적습니다.
3. **실전(12묶음 172장)**: 다시 따로 판독합니다. **실전이 끝날 때까지 서로 답이나 사진 이야기를 하지 않습니다.**
4. 끝나면 "현재 기록 내려받기"로 JSON 파일을 받아 연구자에게 전달합니다.

실전 사진은 연습에 쓰지 않습니다. 실전 사진을 한 번이라도 열면 그것이 정식 판독입니다.

## 열기 (연구자가 준비)

```bash
# 연습
python3 -m http.server 8767 --bind 127.0.0.1 \
  --directory labeling_pack/visible_contract_v05_training_20260924/annotator_pack
# 실전 (연습과 맞추기가 끝난 뒤에만)
python3 -m http.server 8766 --bind 127.0.0.1 \
  --directory labeling_pack/visible_contract_v05_20260922/annotator_pack
```

브라우저에서 `http://127.0.0.1:8767`(연습) 또는 `:8766`(실전)을 엽니다. 실명 대신 본인만의
검수자 코드(예: `rater_b`)를 쓰고, 연습과 실전에서 같은 코드를 씁니다. 기록은 그 브라우저에만
저장되므로 중간에 한 번씩 내려받아 두세요.

두 사람이 같은 컴퓨터를 쓰면 브라우저 저장소를 공유하게 됩니다. 되도록 각자 다른 컴퓨터나
다른 브라우저 프로필을 쓰세요.
