# 시나리오 — "재난 D+3, 어디부터 가야 하나?" (라벨 없는 촬영일 임베딩 변화 탐지)

2026-09-27. 근거 결과: MS-163(A1). 이 문서는 시나리오와 검증 흐름이며, 각 단계의 실험은 별도 사전등록으로 결과 전에 고정한다.

## 1. 장면

- **D0**: 홍수(또는 산불·산사태) 발생. 지자체·구호기관 담당자는 **재난 종류·범위를 아직 모른다.** 현장 라벨·전용 모델도 없다.
- **D+1~3**: 첫 Sentinel-1(구름 무관) 또는 Sentinel-2 촬영 도착.
- 담당자의 질문: **"내 관할 수백 km² 중 어디가 평소와 다르게 변했나? 어디부터 인력을 보내야 하나?"**
- 필요한 답: 변화가 큰 순서의 구역 목록 + 근거(어느 날짜와 비교해 무엇이 변했나) + 신뢰도.

## 3. 흐름 (도구의 네 단계 — 각 단계가 하나의 검증 대상)

```
입력: 관심 지역(AOI) + 사건 날짜
 ① 촬영일 임베딩   : 사건 직후 첫 촬영 + 직전 촬영들을 OlmoEarth로 임베딩 (고정 모델, 학습 없음)
 ② 평소 변화 보정  : 같은 장소의 '사건 전 촬영끼리의 변화'(= 그 장소의 평소 흔들림)로 나눠
                     잡음·계절·원래 물처럼 늘 변하는 곳의 오경보를 줄인다
                     (확장: 전년도 같은 달 촬영으로 계절 보정 — MS-148 계절 기준선의 일반화)
 ③ 필요한 곳만 확대 : 전체는 40 m 토큰으로 훑고, 상위 k% 구역만 패치를 줄여 20 m 토큰으로 다시 읽는다
 ④ 결과 전달      : 변화 순위 지도 + 구역별 근거(비교 날짜, 변화량, 평소 대비 배수) → 이후 에이전트가 말로 전달
출력: 우선순위 구역 목록, 근거, 처리 시간
```

"상대가 빠르게": 공개 OlmoEarth 가중치 + 공개 Sentinel(Planetary Computer/Element84) + 이 네 단계. 학습·라벨 없음. 한 AOI 처리 시간을 함께 보고한다.

## 5. 이 시나리오가 논문에 주는 것

- **문제가 분명하다**: "D+3, 라벨 없음, 재난 종류 모름"에서 쓸 수 있는 신호가 없다.
- **실측 격차**: 연간 제품은 이 시점에 없고, 있어도 일시적 재난을 놓친다(A1).
- **방법 기여**: ② 평소 변화 보정 + ③ 증거 기반 확대 — 둘 다 학습 없이 붙인다.
- **재현성**: 공개 가중치·공개 영상·학습 없음 → 누구나 같은 날 적용.
