# OlmoEarth에 지역·계절 맥락을 학습시키는 방향

> **통합 연구 방향 v2:** [환경이 달라져도 전문가 교정을 재사용하는 OlmoEarth](OLMOEARTH_UNIFIED_CONTRIBUTION_20260927.md). 아래 문서의 개별 요소를 하나의 모델 목표와 결정 실험으로 연결했다. 제안 설계이며 기존 실행·판정·사전등록은 보존한다.


2026-09-27. 사용자 제안에 대한 문헌 조사와 실험 설계 메모. 실제 지역 맥락 수집·학습·성능 검증은 아직 수행하지 않았다. 기존 OE4 학습 큐와 source는 수정하지 않았다.

## 판단

가능하며, 지역 특성을 이용한 검색·소량 라벨 적응·계절 해석을 OlmoEarth의 응용 목표로 묶을 수 있다. 다만 Wikipedia·기후·위치 정보를 더하는 것만으로 신규성은 성립하지 않는다. 아래는 기존 방법을 넘어서는지 검증할 **후보 가설**이다.

> 지역의 기후·지형·생태 지식을 함께 학습하면, OlmoEarth가 국경을 넘어 비슷한 환경에 적응하고 지역의 평소 패턴과 다른 실제 관측도 더 잘 판독할 수 있는가?

국가 이름은 데이터 정리에는 유용하지만 학습의 충분한 단위가 아니다. 같은 국가 안에도 고도·강수·토지 이용 차이가 크다. 다른 국가의 지역이 일부 환경 속성에서는 더 가까울 수 있다. 지역 전체의 모든 영상 표현을 동일하게 만들지 않고, 질문에 필요한 속성의 유사성과 현지의 공간 구조를 함께 보존해야 한다.

## 가장 가까운 선행과 남은 차이

| 선행 | 직접 확인한 겹침 | 우리 연구에서 더 필요한 근거 |
|---|---|---|
| [WikiSatNet, 2019](https://arxiv.org/abs/1905.02506) | 위치가 있는 Wikipedia 기사와 위성영상 표현 학습 | Wikipedia 추가 자체는 신규성 아님 |
| [WildSAT, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Daroya_WildSAT_Learning_Satellite_Image_Representations_from_Wildlife_Observations_ICCV_2025_paper.html) | 종 관측과 Wikipedia 지식을 이용한 위성 표현 학습 | 생태 지식과 텍스트 지역 검색 이상의 학습 효과 |
| [EcoWikiRS, 2025](https://arxiv.org/html/2504.19742v1) | 영상·종 관측·서식지 문장 정렬, 문장 가중치를 통한 약한 감독 처리 | 단순 가중 contrastive 이상의 효과와 원인 |
| [GAMMA, 2026](https://arxiv.org/abs/2601.08750) | 공간 정보를 이용한 영상·종 관측·Wikipedia 융합, 환경변수 예측 | 지역·연도·환경 조합이 달라져도 유지되는 성능 |
| [AlphaEarth Foundations](https://arxiv.org/html/2507.22291v1) | Wikipedia/GBIF 텍스트 및 ERA5-Land 등을 학습 target으로 활용 | OlmoEarth에서 재현 가능한 학습 기여와 실제 VLM 출력 개선 |
| [SatCLIP](https://arxiv.org/abs/2311.17179) | 위성영상과 위치를 정렬해 환경 특성을 담은 위치 표현 학습 | 좌표만 학습한 이득보다 추가되는 맥락 활용 가치 |

논문별 입력과 감독 target의 역할을 섞어 설명하지 않는다. 예컨대 AlphaEarth의 기후·텍스트를 모두 inference 필수 입력이라고 해석하지 않는다. 선행의 보고 성과는 우리 환경에서 재현한 수치가 아니다. GAMMA와 EcoWikiRS는 서로 다른 연구이며 arXiv 번호를 혼용하지 않는다.

## 자료는 세 종류로 연결한다

| 종류 | 내용 | 적절한 용도 |
|---|---|---|
| 지역 배경 | Wikipedia 지리·기후·생태 문장, 고도·유역·생태구역 | 지역 특성, 환경 유사성, 해석의 배경 |
| 장기 계절 특성 | 월별 강수·기온 평년값, 계절성 곡선 | 그 시기 예상 조건과 비교 기준 |
| 해당 시점의 관측 | 위성 시계열, 당시 기상·강수 기록, 독립 참조 라벨 | 실제 상태·이상 여부 판독 |

[WorldClim 2.1](https://www.worldclim.org/data/worldclim21.html)은 1970–2000 월별 기후 값을 제공한다. 2020년 공개 자료이므로 과거 특정 시점에 실시간으로 이용 가능했다고 주장하면 안 된다. [한국 기상청 평년값](https://data.kma.go.kr/climate/average30Years/selectAverage30YearsList.do)과 [네팔 DHM의 평년·몬순 자료](https://old.dhm.gov.np/climate/)도 배경과 당해 관측을 구분해 연결하는 후보이다. 실제 좌표·날짜의 자료 확보 가능성은 별도 감사해야 한다.

Wikipedia는 문장별 URL, revision/작성 시점, 해당 공간 범위, 유효 시기, 원문과 정제 문장을 함께 저장한다. 배경 문장에 대상 사건의 사후 설명이 포함되면 정답 누출로 취급한다. country 문장을 10m 픽셀의 사실 라벨로 복제하지 않는다. 기후 grid의 해상도를 10m로 확대해도 근거의 실제 해상도는 바뀌지 않는다. retrospective 이해 실험과 당시 이용 가능 자료만 허용하는 operational 실험의 cutoff를 별도로 고정한다.

기존 999좌표 그룹은 자료 연결의 출발점이다. 원 부모 좌표와 실제 footprint, 시계열 길이를 먼저 확인한다. 좌표가 있다는 사실만으로 지역 문서가 그 crop을 기술하거나 새 평가 지역이라고 보장되지 않는다. 이번 1k corpus는 원 사전학습 corpus 일부이며 외부 평가로 쓰지 않는다.

## OlmoEarth의 가중치에 연결하는 방법

초기 구현 후보는 Sentinel/Landsat 등 EO 입력을 처리하는 OlmoEarth 경로와, 지역 문장·계절 수치를 처리하는 맥락 경로를 구분해 결합하는 방식이다. 실제 VLM은 관측 위치와 시점, 지역 배경을 함께 읽고 답한다. 학습 손실이 OlmoEarth encoder까지 도달하도록 공동 학습한다.

지역 정보는 인코더 학습의 보조 감독으로만 쓰는 방식과 추론 때도 입력하는 방식을 별도로 비교한다. 전자는 배경 지식이 EO 표현에 남았는지, 후자는 실제 서비스에서 추가 자료가 도움이 되는지를 묻는다. 외부 맥락을 제거한 독립 EO 평가 및 새 VLM 연결에서도 효과를 확인해야 OlmoEarth 자체의 재사용성 향상을 주장할 수 있다.

학습 내용 후보는 다음과 같다.

- **환경 유사성:** 다른 나라라도 기후·고도·피복 속성이 비슷한 사례를 연결한다. 계절 곡선만 비슷한 숲과 도시를 같은 공간 표현으로 압축하지 않도록 독립 EO 작업을 유지한다. 단순 contrastive 학습을 강한 기준선으로 둔다.
- **계절을 고려한 시계열 판독:** 실제 관측과 독립 참조자료가 있는 경우, 그 지역의 평소 변화와 다른 관측을 구별한다. 장기 평년만으로 현재 홍수·가뭄·고사 여부를 라벨링하지 않는다.
- **맥락의 적용 범위:** 어떤 질문에 지역 배경이 필요한지, 영상 증거가 충분한지, 아직 근거가 부족한지를 학습한다. 틀린 문맥 대조는 입력 신뢰성 검사이며 기후의 인과 효과를 증명하지 않는다.

어떤 연결층이나 가중치 함수도 현 단계에서 독립적인 신규 방법이라고 부르지 않는다. 맥락을 단순 결합하는 baseline이 같은 효과를 내면 그 이상의 방법 주장은 보류한다.

## 비교 설계

| 비교 | 식별하려는 효과 |
|---|---|
| A. 맥락 없이 학습한 EO–VLM | 영상·질문만의 기준 성능 |
| B. A에 추론 때만 같은 지역 자료 제공 | 검색/프롬프트만으로 얻는 효과 |
| C. 같은 자료를 단순 결합해 공동 학습 | 추가 데이터와 일반 학습의 효과 |
| D. 제안 학습: 맥락 필요·무관·충돌을 구분 | C 이상의 학습 방식 효과 |

C와 D에는 같은 감독·pair·질문·입력·총 forward 예산을 주고, D의 loss만 다르게 한다. A/B는 맥락의 유무 자체를 비교하므로 정보량이 완전히 같다고 주장하지 않는다. 파라미터·학습 연산량은 맞추거나 차이를 명시한다. text-only, 지역명/좌표/달력-only, 기후 수치-only, frozen OlmoEarth+학습된 connector, 공식 목적의 추가 학습도 대조에 포함한다.

첫 pilot은 독립 라벨을 확보한 계절성 식생·수면 중 한 과제에서 시작한다. 설명의 유창함을 주지표로 삼지 않는다. 지역 단위 held-out 성능, 적은 라벨 적응곡선, mask/측정 오차, 판독 불가 조건의 calibration을 본다. 예산과 유효 표본수는 자료 감사 후 결과를 보기 전에 고정한다.

필수 검사:

1. 국가명만 지워도 유용한 기후·지형 맥락의 효과가 남는가?
2. 다른 국가의 유사 환경으로 전이되고, 같은 국가의 다른 환경은 구별하는가?
3. 같은 장소에서 연도가 달라졌을 때 실제 관측에 맞춰 답이 바뀌는가?
4. 명확히 판독 가능한 영상에 부정확한 배경 문장을 붙여도 확인된 측정값을 유지하는가? 모호한 영상까지 모두 불변을 강제하지 않는다.
5. 외부 문맥이 없거나 불완전해도 원래 EO 기능이 유지되는가? 텍스트 제거 후 encoder 전이 개선이 있는가?
6. train/test의 원 지역·시기·문서·종 관측 중복이 결과를 설명하지 않는가?

## 지금 상태와 다음 작업

이번에 추가한 것은 선행 검토와 구현·비교 설계이다. 새로운 Wikipedia 데이터셋이나 지역 맥락 학습 결과가 생긴 것은 아니다. 기존 OE4 한정 실행은 그 자체의 명세를 유지한다.

다음 구현은 좌표별 출처와 시간 범위를 갖는 작은 지역 자료 manifest와, 같은 자료를 추론에만 주는 baseline부터 시작한다. 자료 연결이 맞고 기존 모델의 구체적인 오류가 확인되면 C/D 공동 학습으로 확장한다. 국가별 정답 암기로 이점이 사라지거나 단순 수치 모델로 모두 설명되면 별도 학습 방법의 주장을 낮춘다.
