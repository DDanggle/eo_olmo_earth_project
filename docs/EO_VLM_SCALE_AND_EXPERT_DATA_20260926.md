# EO 전문 관측을 읽는 VLM: 대규모 학습·전문가 라벨 확장안

> **OpenRouter·다중 AI와 논문 검증 설계는 [OE2 최신안](OE2_MULTIMODEL_SUPERVISION_AND_REPRESENTATION_PLAN_20260926.md)을 우선한다.** 동일 corpus의 2×2 비교·새 reader로 encoder 전이·독립 사람 평가를 구체화했다. 총100만 원 중 기존 예비12만 원을 API상한5만+예비7만 원으로 나눴으며 사람64인시 목표는 유지한다. 새 실행 결과나 동결 사전등록은 아니다.

> **현재 유료 라벨링 예산은100만 원이다.** [AI 보조 라벨링·국내 경로 조사](EO_VLM_LABELING_BUDGET_1MKRW_20260926.md)가 아래5,000개/1,500인시 및 추가 검수0/300/1,000/3,000의 초기 규모 제안을 대체한다. 현 계획은 검수자60인시+전문가4인시의 조건부 예산안이며, 학습 corpus 확대 목표는 유지한다.

2026-09-26. 상태: **사용자 요청에 따른 연구 설계 갱신. 새 학습 결과·확정 사전등록·데이터 확보 보고가 아니다.**

## 1. 연구의 크기와 중심

사용자는 소규모 벤치마크 진단에서 벗어나, 공간·측정 과제와 공정 비교를 유지하면서 큰 학습과 정밀 라벨링을 진행할 수 있는 연구를 요청했다. 따라서 작은 연결부 pilot을 최종 목표로 삼지 않는다. 목표 산출물은 **EO 관측과 전문 판독을 함께 학습한 공개 VLM checkpoint, 출처가 추적되는 학습 corpus, 독립적인 현장·전문가 평가, 규모별 학습 결과**다.

중심 질문:

> EO encoder와 VLM을 공간·수치 근거가 유지되도록 학습하면, 동일 관측·감독을 사용하는 일반 결합보다 새로운 지역과 새로운 질문에서 정확한 측정과 설명을 만드는가? 그 이점은 관측 수와 전문가 감독을 늘릴 때 어떻게 달라지는가?

큰 corpus와 정밀 라벨은 이 주장을 시험할 기반이다. 데이터 수 증가 자체, 두 encoder 연결, segmentation과 caption을 함께 출력하는 것만을 방법의 신규성으로 삼지 않는다. 현재 OE1은 실행 가능성 pilot이며, 새 사전학습 방식의 이점이나 전문가 감독의 가치는 아직 입증하지 않았다.

연구의 적용 범위는 (a) 식생·농경지·인공 피복의 상태와 면적, (b) 산불·침수 등 넓은 교란 영역과 전후 상태, (c) 현장 조사구의 생태 상태로 확장한다. 세 분야를 같은 관측·근거 기록 규격으로 다루되, 서로 다른 센서에서 보이지 않는 사실을 같은 정답으로 강제하지 않는다. 기후 원인 귀속은 별도 기상·장기 관측과 인과 분석이 필요한 후속 범위다.

## 3. 1만 → 10만 → 100만 관측 묶음

**모든 수치는 제안 목표이며 확보량·검정력 보장이 아니다.** 관측 묶음(episode)은 `site + 실제 관측 시점/기간 + footprint`로 정의한다. 여러 질문·crop·밴드·고도 지도 행은 독립 episode로 부풀리지 않는다. episode 수와 고유 site·사건 수를 별도 보고한다.

| 규모 | 학습 자료·주요 실행 | 목적 |
|---|---|---|
| 10,000 | 출처·라벨 감사가 끝난 공간 피복 중심 개발 corpus | 입력/감독/학습 동작과 비용 측정, 공통 recipe 선택 |
| 100,000 | 현장·전문 판독과 출처가 구분된 보조 감독 혼합 | 2×2 구조/학습 목적 본 비교, 전문가 감독 효과 |
| 최대 1,000,000 | 추가 EO 원관측과 검증 가능한 감독의 확장; 일부 무라벨 EO replay 포함 가능 | 데이터 규모가 커질 때 방법 이점·정보 보존·일반화의 변화 |

OlmoEarth [공식 사전학습 데이터](https://huggingface.co/datasets/allenai/olmoearth_pretrain_dataset)는 원관측 확장 후보다. HF viewer의 파일/행 수를 독립 장면 수로 읽지 않는다. 공개 corpus와 S2/Landsat 관측은 존재하지만, 전문가 근거가 붙은 100만 표본을 확보했다는 뜻은 아니다. 무라벨·지도 기반 감독·현장 감독·정밀 검수 각각의 실제 수량과 학습 손실 적용 여부를 공개한다.

단순 규모 효과를 볼 때는 원천·과제 혼합 비율과 전문가 표본 수를 고정하고 nested subset을 만든다. 큰 corpus에서 새로운 도메인을 추가하는 경우에는 별도의 다양성 확장 실험으로 보고한다. expert sample 반복 노출량도 맞추거나 별도 요인으로 보고한다. 서로 다른 라벨 수준의 자료를 하나의 고품질 corpus로 묶어 부르지 않는다.

같은 epoch로 corpus를 키우면 계산량도 증가한다. 기본 곡선은 **데이터와 계산을 함께 키운 결과**로 표기한다. 데이터 다양성 자체를 분리하기 위해100k 단계에서 `10k 고유 표본 반복 vs 100k 고유 표본`을 같은 관측 노출량·토큰/계산 예산으로 비교하는 대조를 추가한다. 이 추가 실행은 아래24회에 포함되지 않는다. 실제 FLOPs 차이는 기록하고 무조건 동일 계산이라고 부르지 않는다.

지리 전이에서는 같은 site/사건의 모든 시점·파생물을 한 split에 넣는다. temporal-forward 평가는 별도의 split 규칙으로 과거와 미래를 분리한다. 공간 완충 거리, 근접 사례 병합 규칙, 중복 사건 alias, 날짜 유효 범위를 manifest로 고정한다.

## 4. 전문가 정밀 라벨 5,000개

제안 1차 규모는 고유 관측 묶음 **5,000개 = train 3,000 + dev 500 + 잠금 test 1,500**이다. 기존 현장·매핑 라벨은 출발 자료이고, 우리가 추가하는 정밀 라벨은 위성 관측에서 어떤 판단이 가능한지를 검수한다. 독립 지역/사건 수와 클래스 분포를 먼저 보고 배분을 확정한다.

train은 다양성 표본과 어려운 사례를 섞을 수 있다. dev/test는 목표 사용 분포에서 미리 표집한 대표 집합과 별도 challenge 집합을 분리한다. 모델이 틀린 사례만 test로 선택하거나, 애매한 사례를 모두 지워서 성공률을 높이지 않는다.

첫 100개는 **train 쪽 라벨링 보정 pilot**으로 삼아 지침·시간·불일치 원인을 고친다. 이 100개는 이후 잠금 test로 이동하지 않는다. 본 판독은 독립 2인, 불일치 항목은 제3 판독/조정으로 처리하고 원 판독을 남긴다. 두 사람이 같은 모델 초안을 보고 동의한 것은 독립 판독으로 세지 않는다. 학습 자료의 초안 보조와 시험 자료의 독립 판독을 구별한다.

필수 기록:

| 항목 | 내용 |
|---|---|
| 관측 | sensor, acquisition timestamp, composite interval, raw asset ID/hash, band/resolution, footprint/CRS |
| 원천 정답 | 현장/전문 매핑/자동지도/합성문장 구별, 조사일·유효 기간·자료 revision |
| 사실 | 상태·변화 종류, 수치와 단위, 면적의 분모, 정답이 적용되는 geometry와 유효 영역 |
| 근거 | 관측 ID + 영역 ID + 검증 가능한 짧은 관측 설명 |
| 한계 | 구름·그림자·혼합 픽셀·라벨 누락·날짜 불일치·해상도 부족·서로 다른 판단 |
| 관측 가능성 | 해당 입력으로 판단 가능 / 부분 가능 / 불가능, 현장에서는 알려진 사실과 구별 |
| 판독 계보 | 익명 reviewer ID·전문 분야·시각·투입 분·원 판단·조정 결과 |

긴 내적 사고과정을 요구하지 않는다. 전문성은 주장·측정·근거·한계를 검증하는 데 사용한다. 예를 들어 “수관 피복이 감소한 영역 A”와 “가뭄 때문에 고사했다”는 서로 다른 주장이다. 후자는 현장·기상 근거가 있을 때만 별도 필드에 기록한다. 모델이 보는 입력에 없는 사실은 영상만으로 답해야 하는 정답에서 제외하거나 판단 불가로 다룬다.

공수 계획: 5,000 × 2인 × 8분 / 60 = 약1,333인시. 20% 불일치를 각10분 조정하면 약167인시, 합계 약1,500인시다. 지도 제작/영상 검색/교육/조정 회의는 제외한 계산 예시다. 숙련도와 복잡한 마스크 작업에 따라 더 커질 수 있으므로 100개 pilot의 실측으로 재산정한다. 시급과 채용·발주·외부 연락은 아직 정하지 않았다.

## 5. 학습할 구조와 방법의 구체적 후보

실제 pretrained VLM의 RGB 경로를 유지하고, OlmoEarth의 원 다중분광 공간 특징을 별도 경로로 입력한다. OlmoEarth는 Tiny를 최종 목표로 고정하지 않는다. Base 규모를 본 실험 후보로 프로파일링하고, 더 큰 EO 모델은 데이터 효과 확인 뒤 확장한다. VLM은 7–9B급 공개 모델 하나를 주축으로 삼고 두 번째 계열은 전이 검증에 쓴다. OlmoEarth release와 VLM revision을 비교군 사이에서 고정한다.

학생 모델 입력 allowlist와 교사 전용 자료를 별도로 둔다. 현장 정답·피복 지도·피해 마스크·정답을 포함한 보고서는 일반 영상 판독 실험의 입력이 아니다. 고해상도 항공영상·현장자료로 만든 감독이 S2에서 관측되지 않는 경우에는 낮은 해상도의 지원 가능한 목표로 집계하거나 별도 다중 입력 과제로 분리한다.

연구 모듈 후보는 **공간 구획을 추적할 수 있는 압축 토큰과, 그 토큰에서 수치·공간 근거를 회수하도록 하는 학습**이다. 전체 scene 의미와 작은 영역 정보를 함께 전달하되, 원래 위치를 잃는 일괄 평균만으로 압축하지 않는다. 배치마다 출처가 보장된 유효 라벨에만 감독을 적용한다.

학습 후보의 구성:

1. 구조화 답변·짧은 설명 감독: 위치·수치·관측 ID와 문장을 함께 학습한다.
2. 표현 보존 감독: 압축 후 토큰에서 지역별 피복/측정값을 판독한다. 정답이 있는 유효 영역에만 적용한다.
3. EO 지속 사전학습: 기존 EO 목적 또는 동등한 replay 대조로 encoder의 전문 판독 능력 보존을 확인한다.

전문 라벨의 유효 영역·불확실성을 사용하지만, 신뢰도 가중을 적용했다는 사실 자체가 신규성은 아니다. 동일 라벨을 사용하는 일반 보조 분할 head보다 무엇이 나은지 알고리즘과 실험으로 보여야 한다. 세 구성요소를 한꺼번에 켜고 좋아졌다고 각 요소의 공헌을 주장하지 않는다.

훈련 순서는 연결부 정렬 → 공통 VLM 적응 → OlmoEarth 일부/전체 공동학습이다. 초기 random connector 때문에 encoder가 불리해지는 효과를 줄이도록 모든 군에 같은 순서를 적용한다. 기존 pretraining 목적에서 출발해 encoder 가중치가 변하는 계속 사전학습 경로를 유지한다. 처음부터 7B VLM 전체를 새로 사전학습하는 범위는 아니다.

## 6. 비교 실험: 규모·방법·전문가 감독을 분리

100k 규모에서 다음 2×2를 수행한다.

| | 통상적인 동일 감독 학습 | 제안 보존 학습 |
|---|---|---|
| 강한 기존 공간 resampler | A | B |
| 제안 연결부 | C | D |

입력 관측/밴드/날짜, VLM·EO 초기 checkpoint, 토큰 수, 라벨·유효 영역, 데이터 노출, 학습 순서와 튜닝 예산을 맞춘다. 통상적 학습에도 같은 공간·수치 정답과 마스크를 실제 loss로 제공한다. D만 mask 감독을 받고 A가 yes/no만 받는 비교는 허용하지 않는다. FLOPs·GPU 시간·추가 head parameter도 기록하며 같은 step을 같은 계산량으로 부르지 않는다.

전체 실행은 분리한다.

- **규모 곡선:** 10k/100k/1M에서 A 대 D. 3 seed라면18회.
- **방법 분해:** 100k의 B/C 각3 seed를 추가. 위와 합쳐24회 핵심 학습이다. 데이터와 recipe를 고정한 본 학습만 세며 개발 실행은 따로 기록한다.
- **전문가 감독 효과:** 100k 관측을 고정하고 같은 train episode의 추가 정밀 라벨 공개량을 0/300/1,000/3,000으로 바꾼다. 0도 LUCAS/CEMS의 기존 현장·전문 감독은 사용하며, 추가 정밀 라벨이0개라는 뜻이다. A와 D 모두 같은 표본·감독을 받는다. 약한 원천 라벨 유지/교체 정책, 반복 노출량을 고정한다. 1 seed 탐색 후 사전에 정한 주대조만 반복하되 비용은24회에 포함되지 않는다.
- **encoder 효과:** 공통으로 정렬된 연결부에서 EO frozen/joint를 비교한다. 별도로 학습된 encoder에 새 연결부를 동일 조건으로 학습해 후단 적응만으로 설명되는지 확인한다.

동일 관측의 EO segmentation/measurement → 같은 LLM 설명은 필수 강한 비교군이다. RGB-only VLM은 실용 출발점으로 두되 입력 정보가 다른 비교라고 명시한다. 주장에 맞춰 두 번째 VLM과 별도 EO/공간 과제 전이를 추가한다. EO 안의 두 backbone만으로 모든 영상 분야에 일반화한다고 주장하지 않는다.

## 7. 남의 벤치마크를 넘어 검증할 것

최종 평가에는 개발에 쓰지 않은 지역/사건과 별도 전문가 판독을 사용한다. 공개 벤치마크는 외부 비교표로 유지하지만 주장의 전부로 삼지 않는다. 새로운 국가·기관·관측 연도와 새로운 질문 조합을 분리해 보고한다. 정답을 질문 표현·장소 이름·날짜만으로 맞히는 정도도 확인한다.

주평가 후보는 **상태/변화 종류, 근거 영역, 수치가 모두 맞는 답변의 비율**이다. mask IoU, 면적 오차, 공간 편향, 보류 정확도·답변 coverage, 기존 EO 분할 성능을 분해 보고한다. 항목별 허용 오차·주지표 가중·최소 유의미 효과는 라벨 pilot 뒤 test를 열기 전에 고정한다. 출력 오류와 부당한 미응답을 분모에서 빼지 않는다.

정보 보존은 원 EO 특징 → 압축 토큰 → 최종 답변에서 측정한다. fresh probe의 용량·튜닝 예산을 맞춰 해당 목표의 회수 가능성을 비교하며 총정보량 보존을 주장하지 않는다. 정답과 별개인 자기 일관성 점수만으로 grounding 성공을 판정하지 않는다.

RGB 경로가 EO 정보를 우회하는지 확인한다. RGB를 유지한 EO 제거/실제 관측 교체와 EO를 유지한 RGB 제거/교체를 진단에 포함한다. RGB에서는 비슷하지만 분광/공간 정답이 다른 사례를 dev에서 규칙으로 정의해 별도 평가한다. 제거·교체로 생긴 분포 밖 입력의 성능 저하만으로 EO 경로의 실용적 가치를 주장하지 않는다. 공통 modality-dropout 조건 또는 RGB-only/EO-only/both 입력에 맞춰 학습한 대조와 함께 해석한다.

실용 평가 제안: 고정된 지역 후보군에서 “면적 조건에 맞는 침수 농경지/피복 감소 지역”을 찾고 근거를 검토하게 한다. 후보군은 대표 부분과 hard 부분을 미리 고정하고, 전문가가 양성·음성·판단 불가를 판독한다. 후보 Recall/정밀도와 전문가 검토 시간을 함께 보고한다. 미판정 후보를 음성으로 취급하지 않는다. 이 결과로 통합 VLM이 단순 측정 파이프라인보다 실제 질문·검토 업무에 도움을 주는지 확인한다.

신뢰구간은 질문 수가 아닌 site/사건 단위로 계산한다. 여러 seed와 같은 지역의 paired 비교를 함께 보고한다. 공개 backbone의 과거 사전학습 노출을 완전히 확인할 수 없으면 '우리 추가 학습에 미사용'이라고 정확히 쓴다.

CEMS 최신 보고서는 사후 revision일 수 있다. 관측일·자료 공개일·보고서 revision 시각을 따로 저장한다. 과거 시점의 판단을 평가할 때 미래 보고서 내용을 입력이나 근거로 쓰지 않는다. 원문 보고서에서 추출한 정답과 원문을 함께 넣고 영상 이해라고 평가하지 않는다.

## 8. 자원과 실행 순서

기존 OE1의 수분 실행시간을 100k/1M 현대 VLM 학습시간으로 외삽하지 않는다. 이번에는 서버 상태를 확인하거나 GPU 작업을 시작하지 않았다. 먼저 실제 후보 VLM + OlmoEarth Base에서 정렬/공동학습 각각 처리량, peak memory, I/O, GPU-second/episode와 유효 토큰 수를 측정한다.

예산 산식은 `episode 수 × epoch × 관측된 GPU-second/episode`에 검증·checkpoint·I/O 비용을 더한다. 분산 효율은 실제 측정값을 쓴다. 한 번에24회를 발사하는 계획이 아니라, 고정된 단계별 최대 시간 내에서 운영할 실행안이다.

다음 산출물 순서:

1. LUCAS·CEMS/WF 원천 메타데이터와 소량 관측을 수집해 source ID/시간/좌표/라벨 범위 연결을 실제 파일로 검증한다. NEON 접근과 제품 revision도 확인한다.
2. train용100개 라벨 pilot 패키지와 annotator 가이드를 만든다. 전문가2인과 조정 역할, 시간 측정이 필요하다. 아직 인력을 확보한 상태가 아니다.
3. 지리·사건 중복을 제거한10k manifest, 별도 test 후보 지역, provenance·라이선스 요약을 만든다.
4. 실제 VLM·EO 규모에서 비용 측정 및 학습 동작을 확인하고100k recipe/평가 규칙을 고정한다.
5. 100k 본 비교와 전문가 감독 효과를 실행한다. 1M은 데이터·비용·개발 결과를 근거로 규모 가설을 명시한 뒤 진행한다.

100k에서 방법 효과가 작더라도 정확한 구현과 충분한 비용 계획 아래 규모 의존성을 시험할 수 있다. 단, 최종 test를 열고 유리한 loss·seed·지역을 찾는 방식으로 확대하지 않는다. 주대조가 지지되지 않으면 규모 효과·데이터 효과만 남는지 정직하게 보고한다.

## 9. 선행 대비 주장과 현재 완료 상태

[Cambrian-1](https://arxiv.org/abs/2406.16860)은 다중 encoder/공간 집계를, [TerraScope](https://arxiv.org/abs/2603.19039)는 EO 근거 마스크와 설명을, [GeoMeld](https://arxiv.org/abs/2604.10591)는 EO 다중 목적·언어 정렬을 다룬다. 따라서 본 연구의 방법 주장은 구체적인 보존 기전과 동일 감독 대조, 학습 규모와 전문가 감독의 상호작용, 새 지역에서의 효용으로 좁힌다. 신규성은 아직 검증 대상이다.

이번 완료: 공식 자료 조사, 출처 장부,5,000개 정밀 라벨 프로토콜,10k/100k/1M 규모 계획, 핵심24회 비교 구조, 비용 산식과 독립 평가 설계. 미완료: 새 corpus 다운로드·실물 정합 확인·인력 확보·새 VLM 학습·새 성능 결과. 원 실험 판정과 사전등록은 변경하지 않았다.
