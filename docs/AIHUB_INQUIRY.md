# AI-Hub 신청 및 파생물 재배포 서면 문의 (2026-08-25 작성)

## 왜 서면 확인이 필요한가

논문에서 AI-Hub 데이터를 쓸 때 우리가 공개하려는 것은 **원본이 아니라 파생물**이다.
임베딩, per-tile 지표, 라벨 통계, 혼동행렬. 40 m 768-d 임베딩에서 원영상을 복원하는 것은
사실상 불가능하므로 근거는 강하다. **그러나 이것을 가정하지 않는다.** 서면으로 확인받는다.
확인 없이 공개하면 심사 중에 문제가 되고, 그때는 되돌릴 수 없다.

## 사용자가 해야 하는 것 (내가 대신 할 수 없음)

| # | 항목 | 비고 |
|---|---|---|
| 1 | aihub.or.kr 회원가입 | 내국인 계정. 본인 인증 필요 |
| 2 | 데이터셋 상세페이지에서 **다운로드 신청** → 승인 대기 | **API key와 별개다.** 키가 있어도 승인 없으면 다운로드 불가. 승인 리드타임이 전체 일정의 병목 |
| 3 | 오픈 API 안내 페이지에서 **API key 발급** | 등록 이메일로 수신 |
| 4 | 아래 문의서 발송 | 승인 신청과 동시에 보내면 대기시간이 겹친다 |

키를 받으면:

```bash
# 로컬 (저장소에 커밋되지 않는다)
cp .env.example .env && $EDITOR .env          # AIHUB_API_KEY 입력

# 서버 (키를 인자·히스토리에 남기지 않는다)
printf "AIHUB_API_KEY=%s\n" '<키>' > /home/work/data/olmoearth/.env.aihub
chmod 600 /home/work/data/olmoearth/.env.aihub
set -a; . /home/work/data/olmoearth/.env.aihub; set +a
bash code/aihub_setup.sh check
```

**키를 대화창·커밋·로그에 붙여넣지 않는다.** `code/aihub_setup.sh`는 키를 인자로 받지 않고
환경변수로만 읽는다 (프로세스 목록 노출 방지).

## 문의서 초안

> 제목: 학술 연구 목적 이용 및 파생 결과물 공개 범위 문의
>
> 안녕하십니까.
>
> 저는 위성영상 기반 지구관측 모델의 재현성을 연구하고 있으며, 연구 결과를 국제 학술대회에
> 논문으로 제출할 예정입니다. 귀 기관의 「AI기반 국립공원 변화탐지 모니터링」 데이터셋
> (데이터셋 번호: ____) 이용을 신청하였고, 학술 논문 게재 시 재현성 확보를 위해 공개해야 하는
> 항목의 허용 범위를 사전에 확인하고자 문의드립니다.
>
> 원본 영상 및 라벨 파일 자체를 재배포할 의사는 전혀 없습니다. 아래 세 항목에 대해서만
> 가능 여부를 서면으로 확인받고자 합니다.
>
> **1. 임베딩 등 비가역 파생 표현의 공개**
> 원본 영상을 딥러닝 모델에 입력하여 얻은 저차원 특징 벡터(임베딩)를 공개할 수 있습니까.
> 구체적으로는 지상 약 40 m 격자 단위의 768차원 실수 벡터이며, 이로부터 원본 영상을
> 복원하는 것은 기술적으로 불가능합니다. 원본 픽셀값이나 판독 가능한 영상은 포함되지 않습니다.
>
> **2. 파일 목록(manifest)의 공개**
> 연구에 사용한 정확한 부분집합을 제3자가 재현할 수 있도록, 사용한 파일의 이름과 파일별
> 해시값(SHA-256), 그리고 학습·검증·평가 분할 정의를 공개할 수 있습니까.
> 이는 파일의 내용을 포함하지 않으며, 동일 데이터셋 이용 승인을 받은 이용자만이
> 이를 통해 동일한 부분집합을 구성할 수 있습니다.
>
> **3. 국외 공동연구자와의 결과 공유 범위**
> 본 연구는 국외 기관 소속 연구자와 공동으로 수행될 수 있습니다. 이 경우
> (a) 원본 데이터에 접근하지 않고 (b) 위 1항의 파생 표현과 집계된 성능 지표
> (정확도, 혼동행렬, 클래스별 통계)만을 공유하는 것이 이용 조건에 부합합니까.
> 국외 연구자가 원본 데이터를 필요로 하는 경우 별도의 절차가 있는지도 함께 안내 부탁드립니다.
>
> 위 세 항목 중 허용되지 않는 것이 있다면 해당 항목을 논문에서 제외하고 진행하겠습니다.
> 회신 내용을 논문의 데이터 이용 조건 항목에 인용하고자 하니, 가능하다면 서면(이메일)으로
> 회신해 주시면 감사하겠습니다.
>
> 감사합니다.

발송 전 채울 것: 데이터셋 번호(승인 신청 시 확인), 소속·연락처.

## 회신에 따른 분기 (사전 결정)

| 회신 | 조치 |
|---|---|
| 1·2·3 모두 가능 | 계획대로. 파생물 + manifest 공개, 국외 공저 가능 |
| 1 가능, 2 불가 | manifest 대신 신청 절차와 데이터셋 버전만 기술. 재현성 주장을 약화시켜 명시 |
| 1 불가 | AI-Hub 결과를 논문 본문에서 제외하고 **수치 없이** "확인했으나 공개 불가" 각주만 남긴다 |
| 3 불가 | 단독 저자로 진행하거나 AI-Hub 파트를 제외 |

**어느 경우에도 headline claim은 공개 benchmark(PhilEO·AvalCD·Sen12Landslides)에서 성립해야 한다.**
AI-Hub는 독립 확인용 2차 표다. 이 원칙 덕분에 회신이 최악이어도 논문은 살아남는다.
